# HarmonyOS Restricted Permissions List

## System Utilities & UI
* ohos.permission.SYSTEM_FLOAT_WINDOW
  Allows an application to be displayed in a floating window on top of other applications.
* ohos.permission.INTERCEPT_INPUT_EVENT
  Allows an application to intercept system-wide input events before they reach windows.
* ohos.permission.INPUT_MONITORING
  Allows an application to listen for and monitor input events during screen recording or sharing.
* ohos.permission.USE_FLOAT_BALL
  Allows an application to use the global floating ball for screen content processing and tracking.
* ohos.permission.AUTO_RESTORE_MAIN_WINDOW
  Allows vocational applications to automatically restore their main window through the global floating ball.

## User Data & Media Access
* ohos.permission.READ_CONTACTS
  Allows an application to read the user's Contacts data for cloning, backup, or syncing.
* ohos.permission.WRITE_CONTACTS
  Allows an application to add, remove, and modify the user's Contacts data.
* ohos.permission.READ_AUDIO
  Allows an application to access the audio files stored in a user's public directory.
* ohos.permission.WRITE_AUDIO
  Allows an application to modify or save audio files in a user's public directory.
* ohos.permission.READ_IMAGEVIDEO
  Allows an application to access the images and videos in a user's public directory.
* ohos.permission.WRITE_IMAGEVIDEO
  Allows an application to modify or save images and videos in a user's public directory.
* ohos.permission.SHORT_TERM_WRITE_IMAGEVIDEO
  Allows an application to save images and videos to the public directory within a temporary 30-minute window.
* ohos.permission.READ_WRITE_DESKTOP_DIRECTORY
  Allows an application to access the Desktop directory and its subdirectories on tablets and 2-in-1 devices.
* ohos.permission.READ_WRITE_USER_FILE
  Allows IDEs or debugging tools to read and write files directly within user directories on 2-in-1 devices.
* ohos.permission.ACCESS_USER_FULL_DISK
  Allows trusted applications to perform full-disk scans or access public directories without repeated dialogs.
* ohos.permission.READ_WHOLE_CALENDAR
  Allows an application to read all calendar events and information on the device.
* ohos.permission.WRITE_WHOLE_CALENDAR
  Allows an application to add, remove, or change all calendar events.

## Hardware & Driver Development (DDK)
* ohos.permission.ACCESS_DDK_USB
  Allows extended peripheral drivers to access USB DDK interfaces for developing USB device drivers.
* ohos.permission.ACCESS_DDK_HID
  Allows extended peripheral drivers to access HID DDK interfaces for devices like game controllers or tablets.
* ohos.permission.ACCESS_DDK_DRIVERS
  Allows a peripheral extension driver client to bind to its corresponding driver server.
* ohos.permission.ACCESS_DDK_SCSI_PERIPHERAL
  Allows a peripheral extension driver to access SCSI DDK APIs to develop transparent SCSI storage drivers.
* ohos.permission.READ_WRITE_USB_DEV
  Allows an IDE or debugging tool to connect to a device and read/write data via USB for profiling.
* ohos.permission.PRINTER_DRIVER
  Allows printer driver applications to manage the printing system, including adding or deleting printers.

## Connectivity & Networking
* ohos.permission.GET_WIFI_PEERS_MAC
  Allows an application to obtain the MAC address of peer Wi-Fi devices during scans.
* ohos.permission.GET_WIFI_LOCAL_MAC
  Allows an application to obtain the local MAC address of the device's Wi-Fi hardware.
* ohos.permission.GET_ETHERNET_LOCAL_MAC
  Allows an application to obtain the current local MAC address of the Ethernet hardware interface.
* ohos.permission.GET_IP_MAC_INFO
  Allows an application to obtain the network device's IP and MAC addresses for identification or connection.
* ohos.permission.PERSISTENT_BLUETOOTH_PEERS_MAC
  Allows an application to persist the virtual address of a peer Bluetooth device across system restarts.
* ohos.permission.ACCESS_VIRTUAL_SCREEN
  Allows an application to call APIs to manage virtual screens, including creation, usage, and destruction.
* ohos.permission.MANAGE_APN_SETTING
  Allows an application to read or configure Access Point Name (APN) settings for mobile data networks.
* ohos.permission.LINKTURBO
  Allows an application to initiate multi-network concurrency and multipath transmission to reduce latency.
* ohos.permission.ACCESS_NET_TRACE_INFO
  Allows an application to perform Traceroute operations to diagnose network link quality and latency causes.

## System Security & Kernel Adjustments
* ohos.permission.FILE_ACCESS_PERSIST
  Allows an application to support persistent access to file URIs (Restricted handling applies before API 12).
* ohos.permission.kernel.DISABLE_CODE_MEMORY_PROTECTION
  Allows an application to disable its runtime code integrity protection to modify instructions on the fly.
* ohos.permission.kernel.ALLOW_WRITABLE_CODE_MEMORY
  Allows an application to apply for anonymous memory spaces that are simultaneously writable and executable.
* ohos.permission.kernel.ALLOW_EXECUTABLE_FORT_MEMORY
  Allows the system JS engine to request MAP_FORT executable memory to boost Just-In-Time (JIT) compilation performance.
* ohos.permission.kernel.ALLOW_USE_JITFORT_INTERFACE
  Allows an application using its own script engine to call JITFort APIs to update content in MAP_FORT.
* ohos.permission.kernel.DISABLE_GOTPLT_RO_PROTECTION
  Allows an application to disable read-only protection on the `.got.plt` table to implement custom hooks.
* ohos.permission.kernel.LOAD_INDEPENDENT_LIBRARY
  Allows ecosystem development tools to load shared libraries that are signed with binary certificates.
* ohos.permission.kernel.SUPPORT_PLUGIN
  Allows an application to install external plugins in compliance with plugin market regulations.
* ohos.permission.CUSTOM_SANDBOX
  Allows whitelisted internal development tools to dynamically set or alter the application sandbox type.

## Data Sharing & Clipboard Management
* ohos.permission.READ_PASTEBOARD
  Allows an application to read text or data currently held in the system clipboard (Pasteboard).
* ohos.permission.MANAGE_PASTEBOARD_APP_SHARE_OPTION
  Allows an application to dynamically set or remove the allowed pasteable range of pasteboard data.
* ohos.permission.MANAGE_UDMF_APP_SHARE_OPTION
  Allows an application to adjust or remove the sharing scope of data supported by the Unified Data Management Framework.
* ohos.permission.SET_SYSTEMSHARE_APPLAUNCHTRUSTLIST
  Allows a host application to control and set the trustlist of target applications allowed for system sharing.
* ohos.permission.WEB_NATIVE_MESSAGING
  Allows browser-type applications to pass messages between browser extensions and local applications.

## Specialized Enterprise, Telephony & Fraud Prevention
* ohos.permission.SET_TELEPHONY_ESIM_STATE_OPEN
  Allows an authorized carrier application to add or configure eSIM profiles on the device.
* ohos.permission.ACCESS_DISK_PHY_INFO
  Allows securities and stock trading applications to obtain low-level disk hardware information.
* ohos.permission.PRELOAD_FILE
  Allows document editing applications to preload files into memory to improve subsequent opening speeds.
* ohos.permission.SET_PAC_URL
  Allows enterprise or government apps to configure the URL of a Proxy Auto-Config (PAC) script.
* ohos.permission.PERSONAL_MANAGE_RESTRICTIONS
  Allows a designated device administrator application to manage personal device usage restrictions.
* ohos.permission.START_PROVISIONING_MESSAGE
  Allows an application to trigger the deployment process to activate itself as a personal device administrator.
* ohos.permission.USE_FRAUD_CALL_LOG_PICKER
  Allows authorized anti-fraud applications to retrieve phone call history using a specialized picker interface.
* ohos.permission.USE_FRAUD_MESSAGES_PICKER
  Allows authorized anti-fraud applications to retrieve SMS messages using a specialized picker interface.
* ohos.permission.USE_FRAUD_APP_PICKER
  Allows anti-fraud applications to use a specialized picker to verify installed application information.
* ohos.permission.CRYPTO_EXTENSION_REGISTER
  Allows certified banking applications or UKey vendors to register and unregister crypto extensions.

## System Control, Device Management & Background Execution
* ohos.permission.MANAGE_SCREEN_TIME_GUARD
  Allows an application to use guardian APIs to restrict screen usage time and enforce access controls.
* ohos.permission.CUSTOMIZE_SAVE_BUTTON
  Allows an application to customize the visual icon and text formatting of the secure SaveButton component.
* ohos.permission.GET_ABILITY_INFO
  Allows browser apps on 2-in-1 devices to query system Ability details based on URIs or file types.
* ohos.permission.ACCESS_FIDO2_ONLINEAUTH
  Allows applications to complete password-free web authentication via the PassKey service NDK.
* ohos.permission.KEEP_BACKGROUND_RUNNING_SYSTEM
  Allows verified merchant or utility apps to request continuous background computing tasks like order processing.
* ohos.permission.SUBSCRIBE_NOTIFICATION
  Allows wearable companion apps to intercept and read system notifications to forward them via Bluetooth.
* ohos.permission.CUSTOM_SCREEN_RECORDING
  Allows trusted applications to record the display screen silently without showing repeated privacy pop-ups.
* ohos.permission.ALLOW_EXTERNAL_NATIVE_CODE
  Allows PC utility tools and IDEs to load external native programs, binary files, or dynamic libraries.
* ohos.permission.atomicService.MANAGE_AGING
  Allows HarmonyOS mini-games (Atomic Services) to request custom local data caching and aging policies.
* ohos.permission.MANAGE_MEDIA_RESOURCES_FOR_PUBLIC
  Allows smart watch or IoT controller apps to see and manage media assets currently playing on a device.
* ohos.permission.MANAGE_CALL_FOR_DEVICES
  Allows external controllers or wearables to retrieve incoming numbers, answer, reject, or end calls.
* ohos.permission.MANAGE_BLUETOOTH_ADVERTISER_NAME
  Allows an application to customize its BLE broadcast advertiser name when communicating with nearby nodes.
* ohos.permission.INPUT_DEVICE_CONFIGURATOR
  Allows driver utilities to map external USB/Bluetooth input device interactions to specific attached monitors.
* ohos.permission.REGISTER_OBJECTEDITOR_EXTENSION
  Allows document tools to register specialized embedded snippet editing capabilities for other applications.
* ohos.permission.CHECK_CALL_LOG
  Allows vocational apps (e.g., delivery drivers) to verify if a valid call occurred to a recipient within a time window.
* ohos.permission.KEEP_BACKGROUND_RUNNING_SPECIAL_SCENARIO
  Allows applications to request continuous background execution for tasks like media exporting, casting, or indoor workouts.
