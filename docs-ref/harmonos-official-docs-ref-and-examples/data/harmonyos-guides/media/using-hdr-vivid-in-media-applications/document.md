# Using HDR Vivid in Media Applications

[HDR Vivid](https://www.theuwa.com/standard?cate=3) is a dynamic HDR video standard certified by UWA. In HarmonyOS, you can utilize the HDR Vivid feature to develop media applications that deliver a visual experience with high dynamic range and wide color gamut. As a new generation of high dynamic range image standards, HDR Vivid covers content creation, platform support, and device display. It provides users with a broader color range, more delicate layering, more significant contrast between light and dark, and more intelligent dynamic metadata processing, helping users experience the true colors of the world.
