# About This Kit

Ringtone Kit is a tool library for setting ringtones. By using Ringtone Kit, you can provide the ringtone setting function in HarmonyOS apps, providing users with a simple, consistent, secure, and high-quality ringtone setting experience.

#### Use Cases

Ringtone Kit allows you to set audio files to multiple ringtone types to meet various requirements.

-   Multiple ringtone types: Users can set the ringtone for incoming calls, notifications, SMS messages, and alarms.
-   Ringtones for dual SIM cards: Ringtones for incoming calls and messages can be diverse for dual SIM cards.
-   Quick ringtone management: Users can tap **My ringtone** to go to **Settings** > **Sounds & vibration** on the mobile phone for ringtone management.

#### Restrictions

## Restrictions on Devices

The sample is only supported on Huawei phones and tablets with standard systems.

## Supported Countries/Regions

Ringtone Kit is now available only in the Chinese mainland.

#### Restrictions on Usage

If the required conditions are not met, some functions are unavailable.

-   If the HarmonyOS device does not support a SIM card, the ringtone settings for incoming calls and SMS messages will not be available.
-   The maximum duration of a ringtone is 5 minutes.
