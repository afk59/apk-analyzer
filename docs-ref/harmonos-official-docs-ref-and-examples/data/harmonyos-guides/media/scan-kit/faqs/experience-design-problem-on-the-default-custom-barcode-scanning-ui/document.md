# Experience Design Problem on the Default/Custom Barcode Scanning UI

**Problem**

After a user taps the scan button, no explicit indicator is displayed, indicating whether the scanning function is enabled.

**Solution**

After the default or custom barcode scanning UI is launched, dim the scan button to tell the user that the function has been started. The following uses the default barcode scanning UI as an example.
