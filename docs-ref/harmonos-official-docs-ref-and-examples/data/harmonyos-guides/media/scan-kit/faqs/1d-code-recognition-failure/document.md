# 1D Code Recognition Failure

**Problem**

During 1D code recognition, 1D codes are recognized incorrectly sometimes.

**Solution**

1D code recognition is realized by matching the formation pattern of black and white bars of different widths. Since all types of 1D codes look similar, 1D codes may be recognized incorrectly sometimes. We are striving to continuously optimize the barcode recognition algorithms of Scan Kit to improve the recognition accuracy.
