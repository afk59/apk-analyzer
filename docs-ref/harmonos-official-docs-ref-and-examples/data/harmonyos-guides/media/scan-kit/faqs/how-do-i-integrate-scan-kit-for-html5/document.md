# How Do I Integrate Scan Kit for HTML5

**Problem**

Scan Kit does not provide an integration solution for HTML5 scenarios.

**Solution**

You can call the barcode scanning API by referring to the [method of calling an app function on a page](../../../../application-framework/arkweb/using-frontend-page-javascript-code-on-the-application/invoking-application-functions-on-the-frontend-page/document.md) to implement barcode scanning on HTML5 pages.
