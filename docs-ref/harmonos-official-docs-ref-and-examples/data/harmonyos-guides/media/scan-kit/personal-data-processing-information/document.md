# Personal Data Processing Information

In personal data processing of Device Security Kit, Huawei serves as the end user data processor, and you serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

-   List of personal data processed by Huawei
-   Guidance for you to help the end user control personal data

#### List of Personal Data Processed by Huawei

Last modified: June 25, 2024

| 
Personal Data

 | 

Purpose of Use

 | 

Retention Period

 |
| :-- | :-- | :-- |
| 

Images that you submit

 | 

-   To read the image from the storage space in the scenario of scanning barcodes from images.
-   To take photos of barcodes in the scenario of scanning barcodes using the camera.

 | 

-   Images read for processing do not need to be stored.
-   Images captured with a camera containing a barcode value do not need to be stored.

 |
| 

Text that you submit

 | 

To read the text from which a barcode image needs to be generated.

 | 

The text for generating a barcode image does not need to be stored.

 |
| 

Sensor information (acceleration sensor and light sensor)

 | 

The acceleration sensor is used to detect the device orientation, so as to adjust the orientation of the code scanning UI. The light sensor information is used to turn on the flash light in a dim environment, delivering a better experience of barcode scanning. The personal data is used only on the user device.

 | 

Sensor information does not need to be stored.

 |

-   How to Clear the End User's Personal Data
    
    Scan Kit APIs do not involve data storage.
    
-   How to Export the End User's Personal Data
    
    Scan Kit APIs do not involve data storage.
