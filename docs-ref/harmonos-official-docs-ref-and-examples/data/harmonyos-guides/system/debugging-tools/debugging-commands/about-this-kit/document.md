# About This Kit

The SDK provides various tools for application development, including log viewing, application installation, and test startup.

#### Obtaining Command Line Tools

-   You can obtain the tool through the SDK, which is embedded in [DevEco Studio](../../../../environment-setup/downloading-and-installing-deveco-studio/document.md). The SDK is stored in the **sdk** directory in the DevEco Studio installation directory.
    
-   You can also obtain the tool from the **sdk** folder in [Command Line Tools](../../../../command-line-tools/obtaining-command-line-tools/document.md).
    

To obtain the latest version, update DevEco Studio or Command Line Tools.

Command line tools are stored in different directories. For details, see the tool guidelines.

#### Common Tools

| Tool | Description |
| :-- | :-- |
| [hdc](../../performance-analysis-kit/command-line-tools/hdc/document.md) | Used for interaction, data transmission, and log viewing with devices. |
| [aa](../ability-assistant/document.md) | Used to start applications and test cases and provide application debugging and test functionalities, such as starting components, forcibly stopping processes, and printing component information. |
| [bm](../bundle-manager/document.md) | Used to install, uninstall, update, and query applications, and provide basic installation package debugging capabilities. |
| [hilog](../../performance-analysis-kit/command-line-tools/hilog/document.md) | Used to print logs and record user operations and system running status. |
| [Packing tool](../packing-and-unpacking-tools/packing-tool/document.md) | Used to package compiled files for installation and release after program compilation is complete. |
| [Unpacking tool](../packing-and-unpacking-tools/unpacking-tool/document.md) | Used to unpack HAP, HSP, and APP files into folders. It also provides Java APIs for parsing HAP, HSP, and APP files. |
