# How do I obtain my app's identifiers when using **AppInfo**?

When using **AppInfo** during app development, app ID can be used as an app fingerprint. App ID is a unique ID allocated by AppGallery Connect when an app is created.

To find your app ID, sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html), click **Development and services**, find your desired app, click it to access the **Project settings** page, and select the **routine** tab.
