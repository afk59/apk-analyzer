# About This Kit

DeskTop Extension Kit provides a unified system-level entry, and allows apps to provide their shortcuts on the desktop.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/PeHrNDFNSHacqORncOlrxw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062021Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=884957981BEDD1C7AB272174618C36CFF570E2A9C8940CDA92C7104C5D10EEEB)

DeskTop Extension Kit is available only in the Chinese mainland.

#### Use Cases

When an app is started or running, the app can present their shortcuts in the status bar and quick bar through the APIs provided by this kit.
