# About This Kit

Telephony Kit provides the following APIs that help you develop communication applications:

-   Call module: Allows an application to directly make a call and display the call on the application screen. A third-party application can start the system call application and redirect to the dialing screen to make a call. For details, see [Telephony Call Development](../call-service-development/document.md). With the call module, the application can also format phone numbers and determine whether a number is an emergency number. For details, see [@ohos.telephony.call (Call)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-call).
    
-   SMS module: Allows an application to create and send SMS messages. For details, see [Telephony SMS Development](../sms-service-development/document.md). In addition, the application can obtain and set the SMS service center address, and check whether the current device can send and receive SMS messages. For details, see [@ohos.telephony.sms (SMS)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-sms).
    
-   Radio module: Allows an application to obtain the name of the currently registered network, network service status, and signal strength. For details, see [@ohos.telephony.radio (Network Search)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-radio).
    
-   Data module: Allows an application to access cellular data services. Cellular data is a wireless network communication standard that uses the packet switch technology throughout data transmission and switching to provide voice, data, and video services for mobile devices. It enables users to use applications on mobile devices or browse web pages on the mobile network. For details, see [@ohos.telephony.data (Cellular Data)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-telephony-data).
    
-   SIM module: Allows an application to obtain SIM card information, such as the service provider, International Organization for Standardization (ISO) country code, and home Public Land Mobile Network (PLMN) number. For details, see [@ohos.telephony.sim (SIM Management)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-sim).
    
-   eSIM module (eSIM card management): Implements eSIM card management and eSIM card services. For details, see [@ohos.telephony.esim (eSIM Management)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-esim).
    

#### Constraints

Before calling telephony service APIs, ensure that the device is equipped with a modem and SIM card capable of independent cellular communication.
