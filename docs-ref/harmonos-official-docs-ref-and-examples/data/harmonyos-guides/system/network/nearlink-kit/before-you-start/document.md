# Before You Start

1.  Ensure that your device supports NearLink. Method: Go to **Settings** > **More connectivity options** (or **Settings** > **NearLink & Bluetooth** for different products or OS versions) and confirm that the **NearLink** option exists. If the option does not exist, NearLink is not supported.
2.  Make [basic preparations](../../../../getting-prepared/application-development-preparations/document.md), including registering as a developer, creating an app, installing the development environment, and configuring signing information.
3.  You need to dynamically request the **ohos.permission.ACCESS\_NEARLINK** permission for your app, including declaring the permission in the configuration file and [requesting the permission authorization from users](../../../security/application-access-control/application-permission-management/requesting-application-permissions/requesting-user-authorization/document.md).
