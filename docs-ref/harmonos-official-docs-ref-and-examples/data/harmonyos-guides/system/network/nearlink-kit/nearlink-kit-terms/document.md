# NearLink Kit Terms

#### D

## Data Transfer

The data transfer capability is provided based on the application interaction port information management protocol.

#### S

## SSAP

SSAP refers to the SparkLink Service Access Protocol. It defines the discovery process and access process of the service structure, as well as the signaling required in the processes. Through service management, NearLink devices can communicate with each other at the service layer.

The NearLink basic service layer uses the server-client interaction model. The server provides service capabilities. The client obtains, understands, and accesses the services provided by the server through the signaling and processes defined by the SSAP.
