# About This Kit

NearLink Kit provides a low-power, high-speed short-range communication service that supports connection and data interaction between NearLink devices.

A central device can discover a peripheral device through scanning, and initiate a connection. A peripheral device can be discovered by a central device through advertising, and then perform data transfer after being connected to the central device.

Use scenarios:

-   A mouse functioning as a peripheral device can be paired and connected to a central device through NearLink and then used as the input device to control the central device.
-   A stylus functioning as a peripheral device can be paired and connected to a central device through NearLink and then used as the input device to perform operations on the central device.

#### Restrictions

NearLink Kit is supported on phones, PCs/2-in-1 devices, TVs, tablets, and wearables. Currently, NearLink Kit can run only on real devices, but cannot run on emulators.
