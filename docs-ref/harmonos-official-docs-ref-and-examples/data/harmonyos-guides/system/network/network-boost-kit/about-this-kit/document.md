# About This Kit

Network Boost Kit offers a comprehensive solution that enhances network performance through acceleration, awareness, and prediction capabilities. By coordinating software, hardware, chips, devices, pipes, and cloud resources, it optimizes network resource allocation for a more reliable, smoother, and faster Internet experience.

#### Applicable Scope and Scenarios

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/UAC2IwWcS2GvBQXAvx0Wmg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062016Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=546BF9C6E6998642552D85E7DC35C9C279CD591FEE64C9F366C4795ACF4E2FA2)

-   Network Boost Kit is compatible with **HarmonyOS NEXT 5.0** or later.
-   Network Boost Kit currently supports **phones**, **tablets**, and **PCs/2-in-1 devices** and **cannot run on the Emulator**.
-   Network Boost Kit is limited to Wi-Fi and cellular networks. Other network connection types, such as wired network and Bluetooth, are not supported.
-   Capabilities of network handover (multi-network concurrency) are available since version 6.0.0(20).
