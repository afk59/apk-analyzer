# Network Quality

This kit equips your app with network quality-related capabilities, including quality assessment, scenario identification, and weak signal prediction. By leveraging these capabilities, your app can swiftly adjust data transmission policies, such as caching and rate adaptation, to ensure optimal network performance. Additionally, your app can notify the device of transmission experience via the feedback API. The device will then accelerate the network based on this information for a better user experience.
