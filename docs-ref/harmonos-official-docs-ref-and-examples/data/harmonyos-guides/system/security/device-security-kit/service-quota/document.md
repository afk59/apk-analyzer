# Service Quota

| 
Function

 | 

Quota Description

 |
| :-- | :-- |
| 

DeviceVerify

 | 

API quota: By default, each app can call the DeviceVerify REST APIs for up to 100,000 times every day.

To change the service quota for your app, you can [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/).

We will send you the application result within five working days. Please check your phone and email for updates.

 |
| 

SafetyDetect

 | 

-   System integrity check API: Each app can call this API for up to 10,000 times per day and 5 times per minute on each device.
-   URL check API: Each app can call this API for up to 10,000 times per day on each device.
-   Enhanced system integrity check API: Each app can call this API for up to 10,000 times per day and 5 times per minute on each device.

 |
| 

BusinessRiskIntelligentDetection

 | 

-   Fraud detection API: Each app can call this API for up to 10 times per day on each device.
-   Simulated click detection API: Each app can call this API for up to 10 times every 30 seconds and up to 20 times per day on each device.
-   Enhanced simulated click detection API: Each app can call this API for up to 10 times every 30 seconds and up to 20 times per day on each device.

 |
| 

SecurityAudit

 | 

-   Notification event subscription: Each app can create up to two clients for notification event management on each device. A single device can have up to 16 clients for notification event management.
-   Authentication event subscription: Each app can create up to two clients for authentication event management on each device. A single device can have up to 16 clients for authentication event management.

 |
