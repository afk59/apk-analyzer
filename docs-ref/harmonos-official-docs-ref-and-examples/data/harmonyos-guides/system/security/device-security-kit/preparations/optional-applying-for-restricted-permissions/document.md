# (Optional) Applying for Restricted Permissions

-   To implement the function of reporting messages, an anti-fraud app needs to use a fraudulent message picker to obtain relevant message information. Before using the fraudulent message picker, you need to apply for the **ohos.permission.USE\_FRAUD\_MESSAGES\_PICKER** permission. For details about how to apply for a restricted permission, please refer to [Requesting Restricted Permissions](../../../application-access-control/application-permission-management/requesting-application-permissions/requesting-restricted-permissions/document.md).
-   To implement the function of reporting calls, an anti-fraud app needs to use a fraudulent call log picker to obtain relevant call log information. Before using the fraudulent call log picker, you need to apply for the **ohos.permission.USE\_FRAUD\_CALL\_LOG\_PICKER** permission. For details about how to apply for a restricted permission, please refer to [Requesting Restricted Permissions](../../../application-access-control/application-permission-management/requesting-application-permissions/requesting-restricted-permissions/document.md).
-   To implement the function of reporting apps, an anti-fraud app needs to use a fraudulent app picker to obtain relevant app information. Before using the fraudulent app picker, you need to apply for the **ohos.permission.USE\_FRAUD\_APP\_PICKER** permission. For details about how to apply for a restricted permission, please refer to [Requesting Restricted Permissions](../../../application-access-control/application-permission-management/requesting-application-permissions/requesting-restricted-permissions/document.md).
