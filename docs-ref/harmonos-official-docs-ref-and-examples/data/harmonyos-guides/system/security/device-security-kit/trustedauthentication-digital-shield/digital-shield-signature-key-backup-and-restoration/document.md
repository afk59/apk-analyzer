# Digital Shield Signature Key Backup and Restoration

#### Use Cases

Before activating the digital shield, an app needs to submit a key generation request to Universal Keystore Kit and specify the technical parameters (such as the algorithm and length) of the required key. The successfully generated key will be stored in Universal Keystore Kit. The app can request to use the key to sign or verify the signature of service data related to the digital shield. If the app is uninstalled, Universal Keystore Kit will automatically delete the corresponding key data. As a result, the digital shield function cannot be used after the app is reinstalled.

To restore the digital shield function using historical data after the app is reinstalled on the same device, perform the following operations after activating the digital shield:

1.  Send a request to Universal Keystore Kit to export the key ciphertext.
2.  Send a key backup request to the digital shield service and securely store the key ciphertext in the digital shield service.

After the app is uninstalled and reinstalled, if you want to continue to use the key data generated by Universal Keystore Kit before the app uninstallation to directly restore the historical digital shield function without reactivating the digital shield password, perform the following operations:

1.  Send a key restoration request to the digital shield service. After the digital shield password is successfully authenticated, export the key data backed up before the app uninstallation to the app.
2.  Send the key data to Universal Keystore Kit to complete key restoration.

-   Once the digital shield service is disabled, the digital shield service will automatically clear the corresponding password and key data. When the digital shield is enabled again, key data needs to be backed up again.
-   Repeated key imports to the digital shield service are not supported between key import and digital shield password disabling.

#### Restrictions

Currently, this function is supported only on phones.

#### Development Procedure

1.  Import the huks module, trustedAuthentication module, and dependent modules.
    
    import { resourceManager } from '@kit.LocalizationKit'
    import { huks } from '@kit.UniversalKeystoreKit';
    import { BusinessError } from '@kit.BasicServicesKit';
    import { trustedAuthentication } from '@kit.DeviceSecurityKit';
    import { hilog } from '@kit.PerformanceAnalysisKit';
    import { common } from '@kit.AbilityKit';
    
2.  Export the key by referring to the **wrapKeyItem** method provided by Universal Keystore Kit.
    
    // Key alias.
    let keyAlias = "testWrapKey"; 
    // Key property set.
    let properties: Array<huks.HuksParam> = \[
      {
        tag: huks.HuksTag.HUKS\_TAG\_ALGORITHM,
        value: huks.HuksKeyAlg.HUKS\_ALG\_AES
      },
      {
        tag: huks.HuksTag.HUKS\_TAG\_KEY\_SIZE,
        value: huks.HuksKeySize.HUKS\_AES\_KEY\_SIZE\_256
      },
      {
        tag: huks.HuksTag.HUKS\_TAG\_PURPOSE,
        value: huks.HuksKeyPurpose.HUKS\_KEY\_PURPOSE\_ENCRYPT | huks.HuksKeyPurpose.HUKS\_KEY\_PURPOSE\_DECRYPT
      },
      {
        tag: huks.HuksTag.HUKS\_TAG\_PADDING,
        value: huks.HuksKeyPadding.HUKS\_PADDING\_PKCS7
      },
      {
        tag: huks.HuksTag.HUKS\_TAG\_BLOCK\_MODE,
        value: huks.HuksCipherMode.HUKS\_MODE\_GCM
      },
      /\* Specify that encrypted export is allowed when generating a key.\*/
      {
        tag: huks.HuksTag.HUKS\_TAG\_IS\_ALLOWED\_WRAP,
        value: true
      }
    \];
    
    let options: huks.HuksOptions = {
      properties: properties,
    };
    
    let wrapKeyProperties: Array<huks.HuksParam> = \[
      {
        tag: huks.HuksTag.HUKS\_TAG\_KEY\_WRAP\_TYPE,
        value: huks.HuksKeyWrapType.HUKS\_KEY\_WRAP\_TYPE\_HUK\_BASED
      }
    \];
    
    let wrapKeyOptions: huks.HuksOptions = {
      properties: wrapKeyProperties,
    };
    
    let wrappedKey: Uint8Array | undefined = undefined;
    
    // Call the key generation API.
    await huks.generateKeyItem(keyAlias, options).then(() => {
      console.info(\`promise: generateKeyItem success\`);
    }).catch((error: Error) => {
      console.error(\`promise: generateKeyItem failed\`);
    });
    
    // Export the ciphertext of the generated key from Universal Keystore Kit.
    await huks.wrapKeyItem(keyAlias, wrapKeyOptions).then((data) => {
      wrappedKey = data.outData as Uint8Array;
      console.info(\`promise: wrapKeyItem success, data = ${JSON.stringify(data)}\`);
    }).catch((error: Error) => {
      console.error(\`promise: wrapKeyItem failed\`);
    });
    
3.  Retrieve the **authID** value obtained during [digital shield password setup](../digital-shield-password-management/setting-the-digital-shield-password/document.md) from the server for the current account, and send a data import request to the digital shield service using **authID** as the index.
    
      try {
        const authID: bigint = 11842183505170721246n; // In actual use, replace the value with the authID of the account obtained from the server.
        const buffer = new ArrayBuffer(8);
        const bufferArray = new Uint8Array(buffer);
        bufferArray.set(\[1, 2, 3, 4, 5, 6, 7, 8\]);// In actual use, replace the value with the backup key information obtained from Universal Keystore Kit.
        await trustedAuthentication.importData(buffer, authID);
      } catch (err) {  
        hilog.error(0x0000, 'testTag', \`Failed to importData, code:${err.code}, message:${err.message}\`);
        throw new Error('Import data failed:' + (err as BusinessError).message);
      }
    
4.  After the app is uninstalled and reinstalled, send a key restoration request from the app to the digital shield server.
    
    try {
      const authID: bigint = 11842183505170721246n; // In actual use, replace the value with the **authID** of the account obtained from the server.
      let context = this.getUIContext().getHostContext() as common.UIAbilityContext;
      const resourceMgr: resourceManager.ResourceManager = context.resourceManager;
      const fileData : Uint8Array = await resourceMgr.getRawFileContent('test\_logo\_rgba.png'); // In actual use, replace the value with the name of the app logo image to be displayed on the TUI.
      const buffer = fileData.buffer;
      const label:trustedAuthentication.TUILable = {
        image: buffer as ArrayBuffer,
        title: "Export Key Information",
      }
      const data = await trustedAuthentication.exportData(authID, label);
    } catch (err) {
        hilog.error(0x0000, 'testTag', \`Failed to exportData, code:${err.code}, message:${err.message}\`);
        throw new Error('Export data failed:' + (err as BusinessError).message);
    }
    
5.  Send the key data obtained from the digital shield service to Universal Keystore Kit for key import and restoration.
    
    // Import and restore the key in Universal Keystore Kit. The **keyAlias**, **wrapKeyOptions**, and **wrappedKey** parameters are defined in step 2.
    await huks.unwrapKeyItem(keyAlias, wrapKeyOptions, wrappedKey).then((data) => {
      console.info(\`promise: unwrapKeyItem success\`);
    }).catch((error: Error) => {
      console.error(\`promise: unwrapKeyItem failed\`);
    });
