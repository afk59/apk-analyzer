# Fraud Detection

#### Use Cases

Starting from version 5.0.0(12), fraud detection is supported.

Before users make transfers or payments with a finance app, the **detectFraudRisk** API of Device Security Kit will be called to check for potential fraud threats. This API returns a risk score and provides clues about fraudulent activities, such as receiving fraudulent messages or the device being vulnerable to manipulation. Based on the risk score and these clues, the app can effectively warn against or block such transactions.

#### Restrictions

Each app can call the API for up to 10 times per day on each device.

#### Service Process

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/XwAHZcg_R7efBdJ6gRbk7A/en-us_image_0000002515108419.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062008Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6C79C82763C010EC02951498B07FF14605F9F6A185627BAECD6702FD73D680B9)

The process is as follows:

1.  Your app obtains the nonce value.
    
    When calling the **detectFraudRisk** API, you must pass a randomly generated nonce value, which will be contained in the detection result. You can check the nonce value to verify that the returned result corresponds to your request and does not encounter replay attacks.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/hFviUfKCQ8W2K9F_DrK4lA/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062008Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=16A43544897B5471D29D4ADF3CAB79BCDF5EACF7CD472BE79BC74345EE701403)
    
    -   A nonce value must contain 24 to 80 bytes.
    -   It is recommended that a new nonce value be randomly generated by the app server for each request.
    
2.  Your app calls the **detectFraudRisk** API to initiate a fraud detection request.
    
    After receiving the request, Device Security Kit collects the fraud risk clue data of the current device, sends the clue data and nonce value to the Device Security server for detection, and passes the detection result to your app through the return value of the **detectFraudRisk** API.
    
3.  When your app initiates a service request, your app server verifies the integrity of the detection result.

#### Development Procedure

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/e3P3tigdS8GMa3GcwNvs2w/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062008Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8E9E7B28BEAC0E555BCC45BC03D630A8DC884146213F010D7A98C2D3E2A53178)

Ensure that you have enabled [Fraud detection](../../preparations/enabling-device-security-kit/document.md#li75651927145212) and [requested the profile](https://developer.huawei.com/consumer/en/doc/app/agc-help-debug-profile-0000002248181278).

1.  Import the Device Security Kit module and related public modules.
    
    import { hilog } from '@kit.PerformanceAnalysisKit';
    import { cryptoFramework } from '@kit.CryptoArchitectureKit';
    import { businessRiskIntelligentDetection } from '@kit.DeviceSecurityKit';
    import { BusinessError } from '@kit.BasicServicesKit';
    
2.  Call the **detectFraudRisk** API to obtain the fraud detection result.
    
    const TAG = "BusinessRiskIntelligentDetectionJsTest";
    
    let rand = cryptoFramework.createRandom();
    let len = 48;
    let randData = rand.generateRandomSync(len);
    let params = {
      nonce: randData.data,
      algorithm: businessRiskIntelligentDetection.SigningAlgorithm.ES256
    } as businessRiskIntelligentDetection.FraudDetectionRequest;
    try {
      hilog.info(0x0000, TAG, 'Detect fraud risk begin.');
      businessRiskIntelligentDetection.detectFraudRisk(params).then((result: string) => {
        hilog.info(0x0000, TAG, 'Detect fraud risk success: %{public}s', result);
      }).catch((error: Error) => {
        let e: BusinessError = error as BusinessError;
        hilog.error(0x0000, TAG, 'Detect fraud risk failed: %{public}d %{public}s', e.code, e.message);
      });
    } catch (error) {
      let e: BusinessError = error as BusinessError;
      hilog.error(0x0000, TAG, 'Detect fraud risk failed: %{public}d %{public}s', e.code, e.message);
    }
    
3.  Verify the fraud detection result on your app server.
    
    The result returned by the fraud detection API is a JWS string. To verify the detection result, perform the following steps:
    
    1.  Parse the JWS string to obtain **header**, **payload**, and **signature**.
    2.  Obtain the certificate chain from **header** and use the [Huawei CBG Root CA](https://pki.consumer.huawei.com/ca/cer/RootCaG2Ecdsa.cer) certificate to verify it.
    3.  Verify the domain name of the leaf certificate in the certificate chain. The correct domain name is **riskopenapi.platform.hicloud.com**.
    4.  Obtain the signature from **signature** and verify it.
    5.  Obtain the fraud detection result from **payload**. The format and example are as follows:
        
        {
            "timestampMs": 9xxxxxxxxx,
            "nonce": "Rxxxxxxxxx",
            "appId": "xxxxxxxxx",
            "version": 1,
            "riskScore": 90,
            "tags": \[
        	"phishing",
        	"malware",
        	"interdiction",
        	"control"
            \]
        }
        
        We've provided the [Java sample code](https://gitcode.com/HarmonyOS_Samples/device-security-kit-sample-code-business-risk-intelligent-detection-server-demo-java/blob/master/readme_en.md) for verifying the signature of the fraud detection result for your reference.
