# Creating a Project

This section uses the [Caffe SqueezeNet](https://github.com/forresti/SqueezeNet) model as an example to introduce the app integration process.

1.  Create a DevEco Studio project, select the **Native C++** template, and click **Next**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/27rro6FHR9qc4QFkQRYcrA/en-us_image_0000002496568528.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062125Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=72B2E5ED53167156FD10DBDE28D7FC9F724B5ECDD18203F9B1DAF36D65E9CE84 "Click to enlarge")
    
2.  Set **Project name**, **Save location**, and **Module name** as required, set **Compile SDK** to **5.1.0(18)** or a later version, and click **Finish**
