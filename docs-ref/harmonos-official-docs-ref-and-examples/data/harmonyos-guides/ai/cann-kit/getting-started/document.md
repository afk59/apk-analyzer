# Getting Started

#### Preparing the Environment

-   Use 64-bit Ubuntu to run the model conversion tool **tools\_omg** in [Downloading Tools](#section152959341125).
-   Install [DevEco Studio](https://developer.huawei.com/consumer/en/deveco-studio/) on [Ubuntu 22.04](https://mirrors.ustc.edu.cn/ubuntu-releases/22.04/) or later, macOS 10.14 or later, or Windows 10 or later.
-   Prepare a trained [offline model](../model-conversion/offline-model-conversion/omg-parameters/document.md) converted using **tools\_omg**, or select a proper model from [Model Zoo](../model-optimization/model-zoo/document.md).
