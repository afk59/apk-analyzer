# How to Obtain the Version

You can use either of the following methods to obtain the CANN Kit version.

-   Method 1: Use HDC commands.
    
    If your mobile phone is directly connected to a 2-in-1 computer, run the following command to obtain the **const.hiai.vendor.hiaiversion** attribute:
    
    hdc shell param get const.hiai.vendor.hiaiversion
    
-   Method 2: Use the open API of CANN Kit. For details, see [HMS\_HiAI\_GetVersion](https://developer.huawei.com/consumer/en/doc/harmonyos-references/cannkit#hms_hiai_getversion).
