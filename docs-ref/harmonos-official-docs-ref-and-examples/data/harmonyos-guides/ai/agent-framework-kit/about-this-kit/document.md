# About This Kit

Agent Framework Kit provides the capability of starting a specified agent.

After the agent for an app is launched on the [Celia open platform](https://developer.huawei.com/consumer/cn/hag/hagindex.html?isInFrame=true&amp;lang=zh_CN#/), users can enjoy the combined "app + agent" service. They can start the agent on demand through the UI control capability provided by Agent Framework Kit.

Agent Framework Kit provides Function components.

#### Use Cases

-   Agent Framework Kit provides apps with standard components that can start agents across various scenarios and UIs.

#### Restrictions

## Supported Devices

Currently, this kit is available only on phones and tablets.

## Supported Country/Region

Currently, this capability is available only in the Chinese mainland.

#### Emulator Support

Currently, this kit does not support emulators.
