Images

Core Vision Kit capability APIs: The basic functions of Core Vision Kit are to recognize related content in images. Developers need to provide the images to be analyzed. Here are the details:

OCR APIs: Developers provide images, and Core Vision Kit extracts text information from the images.

Face detection APIs: Developers provide images, and Core Vision Kit extracts facial information from the images, such as bounding box coordinates, facial landmark positions, facial orientation, and confidence scores.

Face verification APIs: Developers provide images, and Core Vision Kit compares two input images to determine whether the faces in the images are of the same person.

Subject segmentation APIs: Developers provide images, and Core Vision Kit identifies and isolates foreground objects or regions that are distinct from the background in images.

Multi-object detection APIs: Developers provide images, and Core Vision Kit detects specific objects in the images, such as animals, plants, and buildings.

Skeleton detection APIs: Developers provide images, and Core Vision Kit detects skeleton keypoints on the human body to describe skeletal information.

#### Guidance for You to Help the End User Control Personal Data

User data is not retained on the cloud. The data controller needs to provide related data subject rights and explanation for end users.

**We require you to inform users of how we will process their personal data in your privacy policy and obtain users' consent or other legal bases** before you integrate and use Core Vision Kit.
