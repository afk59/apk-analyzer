1.  Sigh in to [HUAWEI Developers](https://developer.huawei.com/consumer/en/) using the HUAWEI ID that needs to be added to the trustlist.

    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/Tw32yMxbQKyiGpQy9XC6_g/en-us_image_0000002380496858.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062127Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2621E99B81B7E3AD6120759C8407B98AC0251AB40464F240E8438E3ADABF77FD "Click to enlarge")
