# Overview

The skill call solution offers multiple integration options tailored to different scenarios, as outlined below:

1.  Task execution scenarios: This solution can be integrated via a configuration file or decorator.
    -   Configuration file: This method is primarily used in scenarios where you want to implement desired functions through predefined intents of Intents Kit.
    -   Decorator: This method is primarily used in scenarios where you need to integrate your already implemented functions with custom intents of Intents Kit.
2.  One-step function access scenarios: This solution can be integrated via a configuration file only. The associated intents are general ones among predefined intents of Intents Kit.
