# Use Cases

#### Typical Scenarios

Currently, habit-based recommendation is available through Celia Suggestions. The logic for providing detailed parameters or content varies across different vertical domains. Typical scenarios can be classified into three types: continuing frequently accessed content, returning to frequently used features, and recommending new content based on previous usage behavior.

For example, when it comes to continuing frequently watched videos, the system predicts a high probability that a user will use the video playback feature in HUAWEI Video. Then the system selects the video that the user has recently watched but not yet finished and provides relevant details. The content is recommended and displayed as a template widget in Celia Suggestions. After tapping the widget, the user will be redirected to the video playback page within the app.

#### Widget Display Effect

Intents Kit provides standard template widgets for the habit-based recommendation feature for each vertical domain. You do not need to develop the widgets yourself. A template widget displays the app or atomic service name, logo, and necessary content information, such as the music name and image. These parameters need to be shared by you with the system.
