# Use Cases

#### Typical Scenarios

**Typical scenarios for event-based notifications include:**

-   Follow-up reminders: such as price drops on items in a shopping cart or updates to content followed by users.
-   Order fulfillment reminders: such as reminders for tickets, flights, rides, food delivery, and medical appointments.
-   Redemption conversion reminders: including reminders to use memberships, coupons, or phone credit.

For different vertical domains, you can define your own events based on particular needs.

For example, with movie showtime reminders, when a user purchases a movie ticket within an app or atomic service, they will see a ticket collection reminder widget in Celia Suggestions about 30 minutes before the movie starts (the exact timing will be based on the vertical domain and user experience). Tapping the widget will redirect the user to the order details page within the app or atomic service, where they can complete the movie ticket collection process.

#### Widget Display Effect

Intents Kit provides system-level standard event template widgets, eliminating the need for development. You only need to push events to the server of the smart distribution platform based on the intent schema of events in a specific vertical domain.
