# About This Kit

Core Speech Kit integrates basic AI voice capabilities, including text-to-speech (supported by the TextToSpeech module) and speech recognition (supported by the SpeechRecognizer module). It facilitates user interaction with devices by enabling real-time conversion between spoken language and written text.

#### Use Case

-   Text-to-speech: Synthesizes a text containing a maximum of 10,000 characters into speech and plays the speech.
-   Speech recognition: Converts a piece of audio information (no more than 60s in short speech mode and no more than 8 hours in long speech mode) into text. You can convert a PCM audio file or real-time audio into text.

#### Restrictions

## Supported Devices

Phones, tablets, and PCs/2-in-1 devices.

## Supported Countries/Regions

Currently, this kit is available only in the Chinese mainland.
