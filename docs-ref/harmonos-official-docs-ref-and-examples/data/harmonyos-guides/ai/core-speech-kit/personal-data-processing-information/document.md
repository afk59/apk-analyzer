#### Guidance for You to Help the End User Control Personal Data

User data is not retained on the cloud. The data controller needs to provide related data subject rights and explanation for end users.

**We require you to inform users of how we will process their personal data in your privacy policy and obtain users' consent or other legal bases** before you integrate and use Core Speech Kit.
