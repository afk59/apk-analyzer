# Importing a Sample Project

DevEco Studio allows you to import sample projects from the Gitee open-source community in one-click mode. The following describes how to import a sample.

#### Constraints

## Supported Countries/Regions

Currently, this feature is available only in the Chinese mainland.

#### Procedure

1.  On the DevEco Studio welcome page, go to **Customize** > **All Settings...** > **Version Control** > **Git** and click **Test** to check whether the Git tool is installed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/kZIj3AGdSzK35HOe_s28uQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E1474A25FFF9614E8EAF7876A7432F8FCF8F8759EC5CFACF16D5069933773E2D)
    
    When a project is open, you can choose **File** > **Settings** (**DevEco Studio** > **Preferences**/**Settings** on macOS) to access the settings.
    
    -   If the tool has been installed, import a sample by following instructions in [2](#li1599692216194).
        
        ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/UAkMYz8rTiqQruz3lHmFKg/en-us_image_0000002501070074.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8A03E1D6632D0F61DE01197EB5D165F327861B911C6F6BA307F781AC43ECE168)
        
    -   If the tool hasn't been installed, click **Download and Install**. DevEco Studio will automatically download and install it. Then import a sample by referring to [2](#li1599692216194).
        
        ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/xKfSnQ24Qd-r9nP2gxlh8A/en-us_image_0000002532670147.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B313ABE5F1B5F29D064F8CF4AE1826C1FA28C34C04B1EE07397F3F39AE6E2364)
        
    
2.  On the DevEco Studio welcome page, click the **Projects** tab, and choose **More Actions** > **Import Sample** to import a sample.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/DHgF_2hFSt-NAJR72k4xSg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8E9ED926DB7E9AF83F741983559AB9225D8F05328064B00D12B4CF67EFEBD68D)
    
    When on a project page, choose **File** > **New** > **Import** > **Import Sample** to import a sample.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/1JMRVbeOSTC7p5qUG-wYdg/en-us_image_0000002532670149.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=ADE54D38493C25F428FCA3F2237D79013647851CE2D7B9F52AE3489CFEFDEE23)
    
3.  Select the sample project to be imported, and click **Next**.
4.  Configure **Project name** and **Project location** and click **Finish**. Wait until the sample project is imported.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/PCDToSWmTfKI6vzPJbbIyw/en-us_image_0000002501070072.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3FF1C522B0640E793C604309752B1EE3932A925FF62C19B7F33892E0E3A167B4)
    
5.  Wait until the project sync is complete.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/7xz0WTaFRzW74S4tJFvAFg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062139Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=14A2D953936BC2CC47B56BED8761687A4674FC0E5F1A55ED9411D9E203C0039D)
    
    A network restriction may cause a timeout error "Failed to connect to gitee.com port 443: Time out" during import. To fix this, [configure your Git proxy settings](https://developer.huawei.com/consumer/en/doc/harmonyos-faqs/faqs-development-environment-2).
