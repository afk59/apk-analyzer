# ohpm-repo deploy

Uses the backup file to deploy a new ohpm-repo instance.

#### Prerequisites

The .zip file packed by running the [pack](../ohpm-repo-pack/document.md) command has been obtained.

#### Command Format

ohpm-repo deploy <file\_path> \[options\]

#### Description

Deploys a new ohpm-repo instance using the package generated by **ohpm-repo pack**. The command requires that MySQL be used for data storage and SFTP or a custom solution be used for file storage. When the command is executed, the system checks whether the ohpm-repo instance list stored in the MySQL database is consistent with that in the configured SFTP or custom storage directory. If they are inconsistent, the command fails to be executed.

#### Parameters

## <file\_path>

-   Type: string
-   Mandatory parameter

You must append the **_<file\_path>_** parameter to the **deploy** command to specify the package path.

#### Options

## deploy\_root

-   Default value for Windows: **~/AppData/Roaming/Huawei/ohpm-repo**
-   Default value for other systems: **~/ohpm-repo**
-   Type: string

You can append the **\--deploy\_root <_string_\>** parameter to the **deploy** command. If this parameter is not set, the default value is used. The value can be a relative path or an absolute path. When the value is set to a relative path, the current working path of the command line is used as the root directory.

## logs

-   Type: string

You can append the **\--logs <_string_\>** parameter to the **deploy** command to specify the log directory. The priority of this parameter is higher than that of the configuration in **config.yaml**. The value can be a relative or absolute path. If a relative path is used, it is resolved based on the current working path of the command line.

## uplinkCachePath

-   Type: string

You can append the **\--uplinkCachePath <_string_\>** parameter to the **deploy** command to specify the path for caching the remote package. The priority of this parameter is higher than that of the configuration in **config.yaml**. The value can be a relative or absolute path. If a relative path is used, it is resolved based on the current working path of the command line.

After the instance is successfully deployed, **deploy\_root**, **logs**, and **uplinkCachePath** configured in the command line are written to the runtime configuration file. You can view them in the **config.yaml** configuration file in the **<_deploy\_root_\>/conf** directory.

## skip-db

-   Default value: **false**
-   Type: Boolean
-   Alias: sd

Configure **\-sd** or **\--skip-db** after the **deploy** command to specify whether to skip the initialization of data tables in the MySQL database. By default, the **schema.sql** file in the directory where the ohpm-repo package is decompressed is read to initialize tables in the MySQL database.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/jDs0w48KSUmdS1-8mFhjUg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=7E23EF34AF8A10DE0C566816653A069664255FC2D6152C2A49D701EC0C367F2B)

1\. In the ohpm-repo configuration file **config.yaml**, this parameter takes effect only when **db.type** is set to **mysql**.

2\. Since ohpm-repo 5.2.0, **\-sd** has been deprecated. You can use **\-s** instead.

#### Example

Run the following command:

ohpm-repo deploy D:\\ohpm-repo\\bin\\pack\_1695805599689.zip --deploy\_root D:\\new-ohpm-repo\\ohpm-repo-deploy
