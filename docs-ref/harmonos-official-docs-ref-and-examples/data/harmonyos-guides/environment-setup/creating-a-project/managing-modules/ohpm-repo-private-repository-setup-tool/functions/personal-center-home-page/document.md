# Personal Center Home Page

The personal center home page is the core management page of ohpm-repo. The entire system is managed and operated in a centralized manner, as shown in the following figure.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/2kf64MKoQnSA-wVudj_pXQ/en-us_image_0000002501068684.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2DF1266A0FE6854C12461A1C358883C0281C9CCDE85D4C51528BF47F91DCF8A2 "Click to enlarge")

-   Area 1: personal information area, which displays the information about the login user. You can copy the publish ID and change the password.
    
    -   Copying the publish ID: Click **Copy** to copy the publish ID **publish\_id** of the user to the clipboard. The publish ID must be configured if the certificate authentication mode is used when you use the **ohpm** CLI tool to publish a package. For details about the publishing process, see [Publishing with the CLI Tool](../../getting-started/document.md#en-us_topic_0000001792256157_%E4%BD%BF%E7%94%A8%E5%91%BD%E4%BB%A4%E8%A1%8C%E5%B7%A5%E5%85%B7%E5%8F%91%E5%B8%83).
    -   Changing the password: Click this button to change the user password.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/CoAQK45LTvm_YKiDx4gQuw/caution_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=91CD48822890AF55F450FC980A00740F4A5799D881392C362ECBA87F2D77DEFA)
    
    For account security, do not use a simple or repeated password, and change the password periodically.
    
-   Area 2: background management area, which displays the operation panel of the corresponding menu in area 4.
-   Area 3: login and registration area. After login, hover the cursor over the user name in this area. A function menu is displayed. Click **Login out** and login in again using another account. Other functions are the same as those in area 4.
-   Area 4: function menu area, which displays **User manage**, **Repository manage**, **Package permissions**, **Security manage**, **Organize manage**, **Operation Log**, and **System setting** functions in the personal center. After you click a function, the operation panel is displayed in area 2. The administrator has all menu permissions, and common users have only the authentication management, package management, and organization management permissions.
