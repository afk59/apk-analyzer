# ohpm-repo restore

Uses the package generated using **ohpm-repo pack** to replace the corresponding file in the **<_deploy\_root_\>** directory and restarts the service.

#### Prerequisites

-   The [start](../ohpm-repo-start/document.md) or [restart](../ohpm-repo-restart/document.md) command has been successfully executed, and the ohpm-repo service has been successfully started.
-   The .zip file packed by running the [pack](../ohpm-repo-pack/document.md) command has been obtained.

#### Command Format

ohpm-repo restore <file\_path>

#### Description

Stops the current ohpm-repo service, replaces the corresponding file in the ohpm-repo deployment root directory with the package pointed by **<_file\_path_\>**, and restarts the ohpm-repo service. Before running this command, ensure that you have run the **ohpm-repo start** command to start the ohpm-repo instance.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/_Rje-1-sQXSs5Yjv6ER98Q/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D70A1281B406E38012F632C924959FC16D2540C09CF49F3B512FEA79E01E84AB)

-   **<_file\_path_\>**: path to the package generated by running the **ohpm-repo pack** command.

The value can be a relative path or an absolute path. When the value is set to a relative path, the current working path of the command line is used as the root directory.

-   **<_deploy\_root_\>**: root directory for ohpm-repo deployment. After the **install** command is executed, an environment variable named **OHPM\_REPO\_DEPLOY\_ROOT** is created to record the [ohpm-repo deployment directory](../../setting-the-configuration-file/document.md#en-us_topic_0000001745376470_%E5%85%B3%E4%BA%8E-deploy_root).

#### Parameters

## <file\_path>

-   Type: string
-   Mandatory parameter

Specifies the path of the package to be decompressed.

#### Example

Run the following command:

ohpm-repo restore "D:\\pack\_1702625827995.zip"
