# ohpm-repo help

Gets help information of ohpm-repo.

#### Command Format

ohpm-repo help \[command\]
ohpm-repo \[command\] --help
alias: -h

#### Parameters

**command** indicates the command name.

#### Description

-   If a command name is provided, its help information is displayed.
    
-   If the provided command name does not exist or no command name is provided, the brief information of all commands is displayed.
    

#### Example

Run the following command:

ohpm-repo -h
