# User Management

On the **User Manage** page, you can add, delete, and search for users, change user types, and reset user passwords. The following figure shows the page effect.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/FcQb4EEqTrmYNxJ0p7_XDg/en-us_image_0000002501068620.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=A6FFBCE5787528FD21386862FC5E7C2201C7E9C98445A02B5561843B1C2E5898 "Click to enlarge")

1.  Click **Add**. The **Add user** dialog box is displayed. Enter the user name and password of the new user. The new user will be forced to reset the password upon the first login. After entering the user information, click **Add** to add a user, as shown in the following figure.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/30/v3/mwmwHA_TRIKpdn7lJ7z_Fg/en-us_image_0000002500908788.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B76050D3829C99A46D360D1C54EAE5B3F502B7A39819BAE88F3A608C38C610C8 "Click to enlarge")
    
2.  Click **Edit Type**. The **Edit User Type** dialog box is displayed. You can change the user type to Administrator or User. Click **Confirm** to change the user type. The password text box is displayed. The administrator needs to enter the password of the current user account for authentication because changing the user type of other users is a sensitive operation. The following figure shows the page effect.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/W-OomaBzThKT0CEw-K4xEg/en-us_image_0000002500908784.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8810CB855B0E6924788D1AECBCF39CB0BE9487894BB24867F49C4DFE3A782F26 "Click to enlarge")
    
3.  Click **Reset**. The **Reset** dialog box is displayed. You can click **Generate new password** to generate a random new password for the user, and click the copy icon to copy the new password to the clipboard. (The password is reset only after you click **Confirm**.) Click **Confirm** to reset the password. The password text box is displayed. The administrator needs to enter the password of the current user account for authentication because resetting the password of other users is a sensitive operation. The following figure shows the page effect.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/cletU1m_RBqp0P-_T6Je2Q/en-us_image_0000002532748635.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=7072C480987C067FC23C11E9E961B969119240003CE164FCD89E9F6133C9E789 "Click to enlarge")
    
4.  Click **Delete**. A dialog box is displayed, asking you whether to delete the user. If you want to delete the user, click **Yes**. The password text box is displayed. The administrator needs to enter the password of the current user account for authentication because deleting a user is a sensitive operation. The following figure shows the page effect.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/sWBznqcJRweZVui1drvkSQ/en-us_image_0000002532748629.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=85ED034E2FB7914EC4C37555A7225066A47DF8666B58A07ECCE166742F61A616 "Click to enlarge")
    
    Deletion is prohibited if the user is the sole owner of any third-party package.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/38xaseNYS86giE1EWAqRYQ/en-us_image_0000002532748649.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F2D29849D99B720B693C0970F4B5B96D935B13E7F8F10D1ECA05246E20BCE757 "Click to enlarge")
    
    5\. Click the search box to search for users by specifying the user type (system administrator or common user) and performing a fuzzy search on the user name. The following figure shows the search page effect (using an example where the user type is system administrator and the user name is admin).
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/1W9etf_AQQCcojM6Qmu6iQ/en-us_image_0000002532748639.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062137Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=247E2209AFE0BBD819C5AF0F586894594A1339318E55E1EA37AA2A91AF4F1C50 "Click to enlarge")
