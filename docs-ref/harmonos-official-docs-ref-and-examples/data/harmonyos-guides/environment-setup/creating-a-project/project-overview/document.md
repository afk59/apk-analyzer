#### Basic Knowledge of an Application Bundle

Before developing an application, learn the basic knowledge about application bundles. For details, see [Application Package Overview](../../../getting-started/development-fundamentals/application-package-fundamentals/application-package-overview/document.md).

#### Switching Between Views

You can switch your project directory structure in DevEco Studio between **Project** and **Ohos** views. The **Project** view displays the actual file structure. The **Ohos** view hides rarely used files and reorganizes frequently used files in such a way that they are easier to locate and search.

By default, the **Project** view is used when you open or create a project. To switch to the **Ohos** view, choose **Project** > **Ohos** in the upper left corner.
