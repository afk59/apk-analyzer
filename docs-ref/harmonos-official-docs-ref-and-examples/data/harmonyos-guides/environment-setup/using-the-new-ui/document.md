# Using the New UI

Since version 6.0.0 Beta1, DevEco Studio is now based on the upgraded IntelliJ platform (2024.3.3). It features a completely new UI that simplifies the tool layout and optimizes icons, windows, and other visual elements. This update delivers a cleaner, more modern look and an enhanced development experience.

#### Enabling or Disabling the New UI

When you launch DevEco Studio, a dialog box is displayed, asking you whether to enable the new UI. Click **Enable and Restart**. DevEco Studio will restart and the new UI will be enabled.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/gbHBGmUCTLm24ZoWMbsCiA/en-us_image_0000002501070566.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F67FB3AFAAFAFDC20690DDF34F3E1A1C0C70CBDD07951CC108E93A732D852F83)

You can also enable the new UI by choosing **File** > **Settings...** (**DevEco Studio** > **Preferences/Settings...** on macOS) > **Appearance & Behavior** > **New UI** on the menu bar, checking **Enable new UI**, clicking **Apply**, and clicking **Restart** in the dialog box.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/JlvQgDtoT-WiLyW10SGlVA/en-us_image_0000002532750591.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=96D1749D9BF5AB38FA4A891A7F92A9B8C26EAC822CEB05F1DAE8CDA871F39F07)

To switch back to the original classic UI, click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/70N4ghqLTuOCETY_cEui4A/en-us_image_0000002501070570.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=CB251D9F6811EC5521960B6EF73EAE1D0D5A6EC5999F3EE5246473BC78F7D3DF "Click to enlarge") in the upper left corner of the page, choose **File** > **Settings...** (**DevEco Studio** > **Preferences/Settings...** on macOS) > **Appearance & Behavior** > **New UI**, deselect **Enable new UI**, click **Apply**, and click **Restart** in the displayed dialog box.

#### Changes in the Menu Bar

The menu bar that was originally fixed at the top of the page is now collapsed in the toolbar at the upper left corner of the page under **Main Menu** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/8zbeqykbReCCpzWevBMJDw/en-us_image_0000002500910724.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=99A7E34404428DEC9C4CDAF14DF04BCA3B002003A3B7EC96F19C67D5BDBF56F6 "Click to enlarge"). You can click the icon to expand the menu and select the required function or operation.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/724gjbu-TFqZ8C4jRURjfA/en-us_image_0000002500910728.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F7DE99F1C08037CFFF6A70AFB47445CE9E45C134B715A0A8AF158E6D8FE8014B)

To expand and fix the menu bar on the main page, go to **File** > **Settings...** > **Appearance & Behavior** > **Appearance** > **UI Options**, select **Show main menu in a separate toolbar**, and click **Apply**.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/6_d-SOJoTCaQv7dQhPfLrA/en-us_image_0000002532670637.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8F78703E23D463E18D50EE61F992D95FC36C2838E78AA6E159BCF590EAD85F89)

#### Tool Window Optimization

The tool windows on both sides of the main window provide more options. Compared with the classic UI, the icons of ArkUI Inspector, Services, Terminal, Problems, and Version Control are displayed in the tool window on the left. Click the Project ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/R86OebhZTrO5t44yHysV1g/en-us_image_0000002500910726.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062136Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=DEAB613F775402ECDD4C06ED170AC93A5F8611D08CD5A68D15032D4FC7A7651A "Click to enlarge") icon in the tool window to display the current project directory.
