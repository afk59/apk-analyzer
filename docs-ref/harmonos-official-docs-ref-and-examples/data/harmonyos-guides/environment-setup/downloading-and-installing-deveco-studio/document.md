# Downloading and Installing DevEco Studio

#### Downloading Software

Go to [Download Center](https://developer.huawei.com/consumer/en/download/deveco-studio), log in with your HUAWEI ID, download DevEco Studio, and verify the tool's integrity by following the instructions in **Tool Integrity**.

Follow the steps below to install DevEco Studio, depending on the operating system you are using.

#### Windows

## System Requirements

To prepare for installation, make sure your computer meets the following requirements:

-   Operating system: Windows 10 (64-bit) or Windows 11 (64-bit)
-   Memory: 16 GB or above
-   Hard disk: 100 GB or above
-   Resolution: 1280 x 800 pixels or higher

## Installation Procedure

1.  After you've downloaded the installation package, double-click **deveco-studio-xxxx.exe** in the package. In the dialog box shown below, choose a destination for the installation, either by keeping the default path (**C:\\Program Files**) or by clicking **Browse…** to select a different path. Then click **Next**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/WfXGgY1LTgOdDX6KxbsQzg/en-us_image_0000002532749911.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B9D5745795AB9CEA27F16268850DE0AB2E8C506AB62DF434AC52440FF2C53F85)
    
2.  Select **DevEco Studio** under **Create Desktop Shortcut** and click **Next** until the installation is complete.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/-zB7kb4oQXOYZLJPZ4CKlA/en-us_image_0000002500910036.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8A2FB0D96425787E60BC257D3281CC2943876F12EF9EDB25AE4B6D214BB7F846)
    
3.  When the installation is finished, click **Finish**. When the installation is finished, check and set up the development environment as instructed in [Setting Up the Proxy](../../coding-and-debugging/appendix/setting-up-the-proxy/document.md).

#### macOS

## System Requirements

To prepare for installation, make sure your computer meets the following requirements:

-   Operating system: macOS (x86) 11/12/13/14/15 or macOS (Arm) 12/13/14/15
-   Memory: 8 GB or above
-   Hard disk: 100 GB or above
-   Resolution: 1280 x 800 pixels or higher

#### Diagnosing the Development Environment

To get the most out of DevEco Studio, run a diagnostic test on your development environment and fix the failed items based on the provided suggestions. To initiate this process, simply click **Diagnose** on the welcome page, or choose **Help** > **Diagnostic Tools** > **Diagnose Development Environment** from the menu bar on the project page.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/oaimmIx1Qpyj4PVO-eTDWA/en-us_image_0000002501069884.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=BCBAA59AA4FEA8BB8957277C803B3493D59DD4763A3ED35D85C8BC9465468790)

The diagnosis items include the computer configuration, network connectivity, and installation of dependent tools. Fix the failed items, if any, based on the provided suggestions.

#### Enabling the Chinese Localization Plugin

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/krPhBp1fRDuvM6fovT7inQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=0AFA978C50071607D8792719B25C83F70D492D3CB419B188D65DEDA4778A9D6A)

Currently, this feature is available only in the Chinese mainland.

-   Since DevEco Studio 6.0.0 Beta1, the Chinese localization plugin is enabled by default. To switch the UI language to Chinese, go to **File** > **Settings...** (**DevEco Studio** > **Preferences**/**Settings** on macOS) > **Appearance & Behavior** > **System Settings** > **Language**, select **Chinese**, and click **Apply**. In the displayed dialog box, click **Restart** to complete the language switch. If the Chinese language option is not available during selection, enable the Chinese localization plugin by following the steps for [earlier versions](#li1956431816322), and then select it.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/GJgJm9wqS2OPvWBEL_fLcA/en-us_image_0000002545108523.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=237B653E933E3DF0065640ACCCB44A58B56E964035B737FC18F110A6019BD204)
    

-   For versions earlier than DevEco Studio 6.0.0 Beta1, go to **File** > **Settings** (**DevEco Studio** > **Preferences** on macOS) > **Plugins** via the menu bar, select the **Installed** tab, and enter **Chinese** in the search box. The result **Chinese(Simplified)** will appear. Click **Enable** on the right, then click **OK**. In the displayed dialog box, click **Restart**. The plugin will take effect after DevEco Studio restarts.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/JX8b-ZioQXyJQX0O1YVYEQ/en-us_image_0000002517865228.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062135Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D13C88C805AE219CF2377D352AB1545A29783D4ED19020007E1666FB86B8380D)
