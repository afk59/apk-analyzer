# Spatial Recon Kit Terms

#### Color Dithering

Color dithering simulates a wider color range by methodically blending the colors of adjacent pixels. By arranging and mixing pixels of different colors within a certain area, it creates a visual blending effect, allowing devices with a limited color depth to simulate more colors.

#### 3D Gaussian Splatting (3DGS)

3DGS, short for 3D Gaussian Splatting, represents a 3D scene using a certain number of 3D Gaussian spheres. Each Gaussian sphere has attributes such as position, size, color, and transparency. During rendering, these 3D Gaussian spheres are projected onto the 2D screen to form a complete image.

#### Kuwahara Filter

A filter that can smooth images while preserving edges.
