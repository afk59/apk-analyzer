# About This Kit

Spatial Recon Kit integrates rendering, computation, and other capabilities of the 3D Gaussian Splatting (3DGS) model, enabling users to perform customized operations on 3D models.

#### Features

Spatial Recon Kit provides capabilities related to spatial reconstruction, helping developers implement functions associated with 3D reconstruction (such as 3DGS), including:

-   3DGS model loading: loads 3D models in various formats, including MP4, PLY, and GLB.
-   Filters: allows stylized processing of rendered images.

#### Restrictions

## Supported Devices

This kit is applicable on phones, tablets, PCs/2-in-1 devices, and TVs.

## Supported Countries/Regions

This kit is available only in the Chinese mainland.

#### Relationship with ArkGraphics 3D Module

Spatial Recon Kit is an extension of the [ArkGraphics 3D](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkgraphics-3d-api) module and must be used together with it.
