# Getting Started

Install DevEco Studio. For details, please refer to [Downloading and Installing DevEco Studio](../../../environment-setup/downloading-and-installing-deveco-studio/document.md).

#### Software Requirements

-   Recommended OS for installing DevEco Studio: Ubuntu 16.04 or later, macOS 10.14 or later, or Windows 10 or later
-   DevEco Studio: DevEco Studio NEXT Developer Beta1 or later
-   HarmonyOS SDK: HarmonyOS NEXT Developer Beta1 SDK or later

#### Hardware Requirements

The following device types are supported: phone, tablet, PC/2-in-1 device, and TV.
