# What Can I Do If an Extension Instance Fails to Be Created?

1.  Call [HMS\_XEG\_GetString](https://developer.huawei.com/consumer/en/doc/harmonyos-references/xengine-kit-xengine#hms_xeg_getstring) or [HMS\_XEG\_EnumerateDeviceExtensionProperties](https://developer.huawei.com/consumer/en/doc/harmonyos-references/xengine-kit-xengine#hms_xeg_enumeratedeviceextensionproperties) to check whether the extension is supported by XEngine.
2.  If the extension is supported, click [here](https://developer.huawei.com/consumer/en/support/feedback/#/) to contact us.
