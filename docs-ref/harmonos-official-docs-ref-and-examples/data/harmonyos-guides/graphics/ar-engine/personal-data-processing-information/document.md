# Personal Data Processing Information

In personal data processing of AR Engine Kit, Huawei serves as the end user data processor, and you serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

-   List of personal data processed by Huawei
-   Guidance for you to help the end user control personal data

Sensor information (including information about the accelerometer, gyroscope sensor, magnetic field sensor, and gravity sensor)

 | 

AR Engine uses such information to calculate the image pose when a device moves.

 | 

Sensor information is processed only on the device side. After the processing is complete, the information is destroyed and will not be retained.

Images captured by the camera

 | 

AR Engine analyzes images captured by cameras to implement AR capabilities such as motion tracking, environment tracking, and hit testing.

Images are processed only on the device side. After the processing is complete, the images are destroyed and will not be retained.

#### Guidance for You to Help the End User Control Personal Data

AR Engine does not retain user data. The data controller needs to provide related data subject rights and explanation for end users.
