# Preparations

Make [necessary preparations](../../../../../getting-prepared/application-development-preparations/document.md) before you start app development.

#### Requesting the Open Capability of Second-Level Game Launch

For security purposes, the system has added permission protection to the second-level game launch capability. To use related APIs, you must submit a request for enabling second-level game launch. The capability will be available only after the request is approved.

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and click **Development and services**.
2.  Select your project from the project list. In the app list, select the app for which you want to request the second-level game launch capability.
3.  Go to **Project settings** > **Manage open capabilities**, and click **Request** next to **Second-Level Game Launch**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/8DH-Cbj4TqCcrY0z0Hj_gg/en-us_image_0000002486120152.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062052Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=143F1327E5AA4AEDE617814D7C681782F3E263720FC2DB64FB8BEAE3DC80EF1F)
    
4.  Provide required information, including the app introduction, usage scenario, and request purpose, based on the template in **Request reason**. Then, click **Submit**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/R_6zrgQlR8SluMH3B8w1-w/en-us_image_0000002518320143.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062052Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=976A273E24AB8DCFCD0B379A5FD6311A718B67DE8AEBFB5A625EE18261754CC7)
    
    Return to the **Manage open capabilities** page. The original **Request** button changes to **Requesting**. You will receive the request result in one to three working days. Please check the service enabling request information in the interaction center for updates.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/luH9-QspRkW7aYIm08iclQ/en-us_image_0000002541242837.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062052Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B2D8796E1D3CF3039D4C39F51BB31A4BE1342EF2DAFBAAACB291738CDB77338F)
    
    After the request is approved, the interaction center will send a notification to you, and **Requesting** will change to a dimmed **Request** button, indicating that the second-level game launch capability is successfully enabled for the app.
