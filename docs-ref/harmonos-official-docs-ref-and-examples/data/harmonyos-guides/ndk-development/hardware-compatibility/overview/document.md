# Overview

When you use C or C++ to develop HarmonyOS native libraries, hardware matters. HarmonyOS can run on devices of different architectures and from a variety of vendors. It is a great challenge to ensure the compatibility and consistent experience of applications that use HarmonyOS native libraries on different devices.

This section describes the HarmonyOS Application Binary Interfaces (ABIs). It defines the [ABI standards](../harmonyos-abis/document.md) supported by HarmonyOS. It also describes how to use the [CPU features](../cpu-features/document.md) in your applications without compromising compatibility. Finally, it provides an example to demonstrate how to better use [ARM Neon extensions](../using-neon-instructions/document.md).
