# Overview

DevEco Hvigor (Hvigor for short) is a TypeScript-based task orchestration tool, which mainly provides task management mechanisms, including key capabilities such as task registration and orchestration, project model management, and configuration management. It offers dedicated processes and configurable settings for building and testing apps.

DevEco Studio uses Hvigor to automatically execute and manage the build process, implementing the execution of app/atomic service build task flows and completing the construction and packaging of HAPs and App Packs.

Hvigor can run independently of DevEco Studio, which means you can build apps in DevEco Studio, [using the command line tools](../../command-line-tools/using-hvigorw/document.md), or on integrated servers. Regardless of whether you build your project from the command line tools or from DevEco Studio, the output of the build process is the same.
