# Build Products

#### HAP and HSP Build Products

HAP and HSP build products in release mode typically include the following files:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/4fNH5XLmQ9eyjVim8zx-Pw/en-us_image_0000002532749831.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=DF027B421A84918A4F55EA592DE92E9315AE56DC28DC79E873A7C429290B41B2)

-   **resources**: directory of resource files in the build product, such as images, media resources, and configuration files.
-   **modules.abc**: bytecode file compiled from the source code in the build product.
-   **module.json**: runtime configuration file generated by processing with **module.json5** in the **src** directory of the module in the build product. For details, see [module.json5 Configuration File](../../../getting-started/development-fundamentals/application-configuration-files-in-stage-model/module-json5-configuration-file/document.md).
-   **resources.index**: resource index file in the build product, including all resource IDs, names, types, and values in the module.
-   **pack.info**: package content description file in the build product, which provides related information during installation and upgrades.
-   **pkgContextInfo.json**: context information table file in the build product, which is used to search for dependency library information during runtime.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/k4CFjpQuQ8yUgOxQRRsSrg/caution_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3288415B725F3AB29CFA5CF47449004E204B6B3B17AED7C15348EAFB529F77B1)

-   The **resources.index** file contains plaintext information. To prevent information leakage, do not configure sensitive information in plaintext within resource files, such as **string.json**.
-   In the **src/main/ets** directory of a module, only .ets, .ts, and .js files are processed during compilation. Other files are packaged as resource files in the build product, without obfuscation or encryption. Do not store sensitive information in this directory.
-   In HAP or HSP files built with debug mode, the **ets** directory contains **sourceMaps.map** files with source code mapping information. For details about the format and parsing process of **sourceMaps.map**, see [ArkTS Stack Trace Analysis Principles](../../../coding-and-debugging/analyzing-logs-and-faults/fault-analysis/exception-stack-trace-analysis/document.md#section5924954297).
-   Lite wearable devices use standard JavaScript runtime. Therefore, the build product in release mode contains JavaScript source code; be mindful of code asset protection.

#### App Pack Build Products

The following figure shows an example of the App Pack build products. The package name depends on the module name in your project, which may be different from that shown below.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/erTyrLqISSWldO-dwRJ6rg/en-us_image_0000002501069808.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=5ACF70EB7FFF269DB71324F00D662E5E3C6D29AF860FB381D89C21CA046BAD8B)

-   **entry-default.hap**: an entry HAP containing bytecode, resources, third-party libraries, and configuration files. It is the basic unit for app installation and running. **application-default.hap** is a feature HAP.
-   **library-default.hsp**: an HSP containing bytecode, resources, third-party libraries, and configuration files, which allows for dynamic sharing of code and resources.
-   **pack.info**: a package description file that provides necessary information for releasing the app to AppGallery.
-   **pac.json**: a privacy manifest file in app build products, which is used to provide information required for releasing an app on AppGallery. For the configurable fields in this file, see [pac.json5 Privacy Manifest File](../../../coding-and-debugging/appendix/pac-json5-privacy-manifest-file/document.md).
