# ohpm help

Gets help information of ohpm.

#### Command Format

ohpm help \[command\]
ohpm \[command\] --help
alias: -h

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/iEHURhIAQCOXqYyToE6lpw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062159Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F3426FD414B10F64E18D5F7835288C7C1B19881C5756DEF773B94482F444D48C)

**command** indicates a command name.

#### Description

If a command name is provided, its help information is displayed.

If the provided command name does not exist or no command name is provided, the brief information of all commands is displayed.

#### Example

Run the following command:

ohpm -h
