# ohpm --version

Queries the version of the installed ohpm client.

#### Command Format

ohpm -v | --version

#### Description

-   This command is used to print the version number of the ohpm client.
-   You can verify the ohpm version after installation.

#### Example

Run the following command to query the ohpm CLI version:

ohpm -v
