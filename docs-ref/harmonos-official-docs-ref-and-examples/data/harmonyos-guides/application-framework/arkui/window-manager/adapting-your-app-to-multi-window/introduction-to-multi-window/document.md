# Introduction to Multi-Window

Multi-Window is a multitasking solution that allows multiple application windows to run simultaneously on the same screen in floating windows, split-screen views, or multitask views. With this feature, users can arrange the size and position of each window to fit their needs.

#### Floating Windows

A floating window is a non-full-screen application window that floats on the device screen. It is perfect for users to quickly switch to another task while they are in the middle of something else, like checking a message while browsing.

On smartphones, only one floating window can be displayed on a single screen. On foldable phones in the unfolded state and tablets, up to two floating windows can be displayed on a single screen. When the maximum number of floating windows has been reached, opening a new floating window will replace the oldest unused one.

## Triggering and Restoration of Floating Windows

Floating windows can be triggered in any of the following ways:

-   Triggered by a gesture: When an application is running in full-screen mode, users can swipe up from the bottom of the screen to the top-right hot zone to open a floating window.

-   Triggered by a notification: When a notification is received and displayed (not collapsed yet), users can pull down the notification to open a floating window.

-   Triggered from the side dock: Users can swipe from the edge of the screen to display the side dock, and then tap an application that supports floating windows on the dock to open a floating window.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/plLEZGStStSmaRgODmdWfQ/en-us_image_0000002529702141.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T061946Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=4EBC4A3DA8204EFB8B27B926C0765F986815348A9006E1B287195C4AD40B2BDA "Click to enlarge")

-   Restored from the recent task center: If a floating window has been enabled for an application, this application is displayed together with full-screen applications in the recent task center. Users can tap the widget of this application to restore its floating window.

Users can tap or long press the sidebar to expand the task selection screen and then tap the widget of this application to restore its floating window.

#### Split-Screen Views

Split-screen applies to scenarios where two applications are concurrently running on the screen for a long time. For example, users can watch shopping guides while browsing through commodities, watch videos while playing games, or take notes while watching videos.

## Triggering of Split-Screen Views

-   Triggered by a gesture: When an application is running in full-screen mode, users can swipe up from the bottom of the screen to the top-left hot-zone, and then tap another application icon or widget that supports split-screen mode on the home screen to enter the split-screen mode.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/rjQW84aoTX2UW68rPRqUXA/en-us_image_0000002498670826.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T061946Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=955343DF76AB141A318E6765B7FE276C23B00389985BE1587D6966DC121BC883 "Click to enlarge")
    

-   Application-initiated: Applications can proactively enable split-screen mode. For details, see [In-Application Split-Screen Mode](../adaptation-to-multi-window/declaring-the-support-for-multi-window/document.md#section152819561687).
-   Triggered from the side dock: Users can long press an application icon on the dock bar and drag it outward to activate the split-screen mode with the foreground application that supports split-screen views.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/246Y9IOiSY2MDQSqIZkS_w/en-us_image_0000002529702137.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T061946Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E56BDC77556D39CAC1DBE5213D03FF589BC9C2D42E7C22B59BA7AE0687567370 "Click to enlarge")
    

-   Switching from a floating window: Users can drag the top bar of the floating window to the hot zone to convert it into a split-screen view with the foreground full-screen application.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/UwcGBNeSQSS7ebruZ1BHLw/en-us_image_0000002497902168.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T061946Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=0652EE868D0936A15A087CCA5D4573B8BFD2BE6424F41EAF1BCAB426B5B67E78 "Click to enlarge")
    

#### Multitask Views

Starting from HarmonyOS 5.0.1, the multitask view is available on foldable devices and certain tablets.

The multitask view is designed to help users efficiently handle multiple tasks when the foldable device is in the unfolded state. With this feature, users can run multiple applications on the same screen simultaneously and quickly switch between them, breaking through the physical limitations of the screen.

The multitask view supports up to three windows on foldable devices (up to four windows on some tablets).

## Styles of Multitask Views

On dual-fold devices, the multitask view supports two window sizes: small and large. On triple-fold devices and tablets, the multitask view supports three window sizes: small, medium, and large. The size and position of the windows can be adjusted.

## Precautions

The sliding-side window in the multitask view is invisible. You can listen for [on('windowVisibilityChange')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-window-window#onwindowvisibilitychange11) to check whether the application is the sliding-side state.
