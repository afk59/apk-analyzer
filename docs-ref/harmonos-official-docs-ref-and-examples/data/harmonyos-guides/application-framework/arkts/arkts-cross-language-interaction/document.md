# ArkTS Cross-Language Interaction

In addition to using ArkTS for development, you can also use Node-API to implement cross-language interaction between ArkTS and C/C++ (native).

HarmonyOS Node-API is an extended version of Node API in the Node.js community but does not fully align with it.

In the [Node-API development process](../../../ndk-development/code-development/using-node-api/node-api-development-process/document.md), you can use the [data types supported by Node-API](../../../ndk-development/code-development/using-node-api/node-api-data-types-and-apis/document.md#data-types) and [available APIs](https://developer.huawei.com/consumer/en/doc/harmonyos-references/napi) to develop and encapsulate native capabilities. By importing the native module in ArkTS, cross-language interaction can be achieved.

[Node-API extension APIs](../../../ndk-development/code-development/using-node-api/node-api-guides/using-node-api-extension-apis/document.md) provide enhanced features for more flexible ArkTS interactions and custom object creation. You can also refer to [Node-API Development Specifications](../../../ndk-development/code-development/using-node-api/node-api-development-specifications/document.md) and [Node-API FAQs](../../../ndk-development/code-development/using-node-api/node-api-faqs/node-api-faqs/document.md) when developing cross-language features using extended Node-API capabilities.
