# Overview of the ArkTS Common Library

The ArkTS common library is a rich set of APIs designed to provide a series of essential and practical functional modules.

The ArkTS common library mainly provides [XML generation, parsing, and conversion](../xml-generation-parsing-and-conversion/xml-overview/document.md), [binary buffers](../buffer-and-fastbuffer/document.md), [multiple container libraries](../arkts-container-library/overview-of-the-arkts-container-library/document.md), and [URL string parsing](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-url), and [high-precision floating-point operating](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-arkts-decimal) to help you streamline your work and boost your efficiency.
