# About This Kit

UI Design Kit is a Huawei-provided UI development toolkit that adheres to the HarmonyOS Design System. It offers diverse extended components and lighting effects for you create premium and exquisite user interfaces (for details, see the [HarmonyOS design philosophy](https://developer.huawei.com/consumer/en/doc/design-guides/design-concepts-0000001795698445)). By utilizing this kit, you can ensure a consistent visual experience and premium design quality for your app across HarmonyOS all-scenario devices, in full compliance with [HarmonyOS design specifications](https://developer.huawei.com/consumer/en/doc/design-guides/general_overview-0000001929599380).

#### Restrictions

## Restrictions on Capabilities

-   **HdsNavigation/HdsNavDestination**: When the device is in landscape mode and the navigation mode is [Stack](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-navigation#navigationmode9), merging the toolbar into the menu bar is not supported, and the title bar defaults to a stacked layout (positioned above the content area).
-   **Icon batch processing API**: This API supports up to 10 concurrent requests, with a processing limit of 500 icons per batch.
-   **Symbol resource registration API**: Only one group of icon resources and animation parameter resources can be registered at a time. Each group supports a maximum of 10 custom symbol icons.
