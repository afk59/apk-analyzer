# Improving Accessibility Experience of Applications

Visually impaired users find it difficult to quickly locate UI objects on a page and understand their functions and operations. Therefore, gesture navigation in logical order and concise and clear voice feedback are designed to ensure that users can efficiently and intuitively obtain information and complete operations. In addition, through the developer self-testing process, we provide an accessible and easy-to-use experience for users to use applications independently and confidently.
