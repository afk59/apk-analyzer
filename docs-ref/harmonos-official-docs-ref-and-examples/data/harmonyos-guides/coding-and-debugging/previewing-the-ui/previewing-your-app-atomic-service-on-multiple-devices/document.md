# Previewing Your App/Atomic Service on Multiple Devices

If your app/atomic service is designed to run on multiple types of devices, you can see how it behaves on different devices while you are building it. This helps you make sure that your app/atomic service will run properly on devices with varying screen resolutions, shapes, and sizes.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/RqoIF39sTI2Fii_Msz_0ew/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C622E6ABF2290C6E3749A1064E0A2E020FA90612465879281D82DC7E90E673F0)

A maximum of four devices is allowed at a time for multi-device preview.

With the Previewer, you can put apps/atomic services written in ArkTS or JS side-by-side, and compare how they run on different devices. However, this multi-device preview feature does not work when the devices used support different programming languages.

Below, an app/atomic service written in ArkTS is used to show how the multi-device previewer works. The procedure is the same for apps/atomic services written in JS.

1.  In the project directory, open any .ets file (.hml/.css/.js file for apps/atomic services developed in JS).
2.  To open the Previewer, do either of the following:
    
    -   On the menu bar, choose **View** > **Tool Windows** > **Previewer**.
    -   On the toolbar in the upper right corner of the editing window, click **Previewer**.
    
3.  In the **Previewer** window, enable **Multi-profile preview** in **Profile Manager** and view how your app/atomic service runs on multiple devices.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/rpFtjbr0RRmnuZV5pNSpWQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=94CF178DFCCE5871FBED7B25FFC13A30C119BE0936A7944AE24DF5173CB297C2)
    
    Multi-profile preview does not support animations. To preview animations, disable this feature and view animations on a single device.
