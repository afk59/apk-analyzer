# Debugging Your App Using the Previewer

When your app/atomic service is debugged on a real device or the Emulator, the modified code can be updated to the debug environment after a long compile and installation process. Using the Previewer, you can run the app/service and view the UI display effect on DevEco Studio immediately after modifying the code.

You can use the Previewer to run and debug Ability lifecycle code and UI code. The Previewer provides basic debug features, including setting breakpoints, executing debugging, and viewing variables.

#### Constraints

-   Only one debugging task is allowed in a project.
-   The common preview mode and preview debugging mode are mutually exclusive. That is, you can use only one of them.
-   The Previewer does not support the following:
    -   Attach debugging
    -   Debugging across abilities
    -   Debugging of C++ code
    -   Hot reload
    -   Multi-process and worker/TaskPool debugging
