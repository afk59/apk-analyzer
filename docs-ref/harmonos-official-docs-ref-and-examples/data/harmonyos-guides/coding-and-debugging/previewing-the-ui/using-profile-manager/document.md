# Using Profile Manager

Different models of the same device type may come with different screen resolutions, and it is infeasible to debug apps/atomic services on all the real devices out there in the market. This is where Profile Manager comes into the picture. You can add a custom preview profile, which includes the resolution and language, to Profile Manager, and choose the profile in the Previewer to see how your app/atomic service looks on devices under the respective profile settings. Currently, you can customize the device resolution and system language.

You can add a custom preview profile and click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/M-wBQKaPQ8Knb7MqCJKASg/en-us_image_0000002501069726.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=CC9005EA0AE0E6642C967EDDE150F88FAF80B6C4A2A57EABAFFCA85DCBDFD9CC "Click to enlarge") in the upper right corner of the Previewer to switch to that profile, as shown below. You can then see how your app/atomic service looks on devices under the respective profile settings.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/SLJ8DejrQcecdJH_fNqq9g/en-us_image_0000002532749741.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D6E2788173FE103FF32CFA21C55C1654E035DF5A6562F882644BD01E074CFCD0 "Click to enlarge")

Profile Manager also supports multi-device previews. For details, see [Previewing Your App/Atomic Service on Multiple Devices](../previewing-your-app-atomic-service-on-multiple-devices/document.md).

In the following example, a preview profile is defined for a specific phone model.

1.  In the Previewer, open the **Profile Manager** dialog box.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/9a4MgeIOTDOXmantJOi55Q/en-us_image_0000002500909878.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9BF4C40DB0B39E7249DA4F987BE6B5812E2D49D52EAA0B137CD239ABA4B8F07A)
    
2.  Click the **\+ New Profile** button to add a profile.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/iyZvrxO4SsOL7VDli2rMaQ/en-us_image_0000002501069724.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=78D9E603FD7444D6E47E6E8DA2ECE8135905EED4F2AE34151F77434F2CDB960A)
    
3.  In the **Create Profile** dialog box, fill in the fields. Note that **Device type** must be set to a value of the **deviceType** field in the **module.json5** file.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/yYdDltZxRcCKzsmrkx1HXA/en-us_image_0000002532669785.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=58C27F099968CEE785C2BBC8642D37BCD8F44D928229BD5403EBFF52EE8C4ACD)
    
4.  When you are done, click **OK**.
