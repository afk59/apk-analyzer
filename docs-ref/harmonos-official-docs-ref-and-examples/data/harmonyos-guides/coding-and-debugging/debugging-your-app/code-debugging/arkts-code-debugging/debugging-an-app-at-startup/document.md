# Debugging an App at Startup

You can set an app to **Wait for Debugger**. This way, you can quickly start debugging by launching the app.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/4naChKDwSq6LzgTBSXk-6g/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=29FCB08EF028B486BCC281FE13ACD639BA9E499C09BE4166A00A421B191F3732)

-   Starting a regular debugging session will cancel the current wait-for-debugger mode.
-   Before setting the wait-for-debugger mode, you need to install the target app on a device.

#### Procedure

1.  Select the device to be debugged and choose **Run** > **Attach to Process by Name**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/OjYrEbT_R66wTcBDgzBXRw/en-us_image_0000002500910540.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=AC1F6814D9013D1D2229A947AF1F5EAC6329886B454288A6378881C3F5EE7420)
    
2.  Select the target app (the current project is selected by default), and select a debug type. Click **Attach** to set the app to the wait for the debugger.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/6bXmlYoVQIKBJ5IK3m66IA/en-us_image_0000002501070388.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=FF43F7CBE55CAB11DD813C7761D170DCD779297E426815CFE906ADEF9F79573D)
    
    A waiting progress bar is displayed at the bottom, and it will remain in a waiting state until the app is launched. You can cancel it by clicking the Cancel button on the right side of the progress bar.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/sl3tcXE_Qv6LakTIPTeAdw/en-us_image_0000002532750407.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=ADC587FE35E14A740FD50A3814C2D6099556CDEFC4A3A9DE97173C43CAD5300C)
    
3.  Start the app on the device to start debugging.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/iWgkjEzCTYGjKqCQNYE6xg/en-us_image_0000002501070386.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=A8DE245B3046CA5F0F43DF04E0C3CCF14CDE8664C62D640988CC70B85E415FF3)
