# Starting and Debugging an App/Atomic Service

To start your app in debug mode right from the beginning, do as follows:

1.  Set breakpoints. To set a breakpoint, locate the code line and click its left sideline, or move the cursor to the code line and press **Ctrl**+**F8** (**Command**+**F8** for macOS). If a breakpoint cannot be added, see [What should I do if breakpoints cannot be added during debugging?](https://developer.huawei.com/consumer/en/doc/harmonyos-faqs/faqs-app-debugging-1) for troubleshooting.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/waANvLpzRjGCZu8rFE_bkQ/en-us_image_0000002501069838.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=7352FA35931EF082E36DE719546C662B1857DCC4DB738FFE4FEFE2D9561E32B5)
    
    After a breakpoint is set, the execution of your code will pause at the specified line of code, and the line will be highlighted with a red dot.
    
2.  Select the device to be debugged.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/bPqDSYLZR8SKQ5c-L10bvw/en-us_image_0000002532749861.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D914BE4A5539638909CB307967B4D8E59A4A1DA4956A819F50FD099F94344D67)
    
3.  Select the configuration for debugging, and then select the module to be debugged. You can also [set debugging parameters](../../../running-debugging-configuration/document.md) in **Edit Configurations**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/gjMBNggkQ4yba8Co-YFKDQ/en-us_image_0000002500909986.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9C0455598CDD13F9CE657F5821F1DC65A411672FF382A7DC225F6331C10C99D6)
    
4.  On the toolbar, click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/uaiEiVS1RuiNIbS7oUMODQ/en-us_image_0000002532749853.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=223770663D954E9D0DF561CCFC2777D1FCF11A64C3EC6340DFF8416AA43292F6 "Click to enlarge") **Debug**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/VANyGGjtRyCFkPERu8u_6Q/en-us_image_0000002501069836.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C97CDAE55F770B3377E3022330178701682A71CBECC9927A86C59F134677EE4C)
    
    Alternatively, choose **Run** > **Debug**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/YHcWuLkITGOr14EHQM7y6g/en-us_image_0000002532669917.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9B77E61B295074526E6D103339476799A3DF969A71A7FF99EA688AC68984C299)
    
5.  Debug code with the [debugger](../../debug-tool-window/document.md).
    
    The breakpoint is highlighted, and its **Frames** and **Variables** are displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/tNRdn25yQpuzbzEXk06QPA/en-us_image_0000002532669909.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=AC0D33AC56F0CFE6F0772BB6E7FB66119A8C735ED3190556BF1473D1F193FBA2)
