# Checking Variables

When a breakpoint is hit, you can view the variables in the **Debugger** window. After selecting a frame in the **Frames** pane, you can check or calculate the variables in the **Variables** pane.

To add a variable or an expression to the **Watches** list, enter the variable or expression in the **Watches** window and click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/SnHBzpBfQnaP7k9Fzh_2iA/en-us_image_0000002501069894.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E209BADF79C7DC251B27D2FAED1B5E1FD472F7B34A8BF91EC9A7CBDAF4B0699C) **Add to Watches**.

To remove an entry from the **Watches** list, right-click the entry and choose **Remove Watches** from the shortcut menu.
