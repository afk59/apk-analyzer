# Printing Expressions

With the Evaluate and log feature, you can print specified expressions when the code execution reaches a breakpoint.

1.  Set a breakpoint where you need to print the result of an expression.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/po609xCuRqG8JW-PQ1Zh_Q/en-us_image_0000002532750051.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=EDF5B2F051195CAE715315EAF1495A1AF3CFA6F5A30009228A556D55D50F711C)
    
2.  Right-click the breakpoint and choose **More** from the shortcut menu.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/qiyDqBcMRtesx8Lqu0VBow/en-us_image_0000002532750053.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2628B871D8B96ED7638965D214C1E94024E8679232C18817D0064B335F2A18E0)
    
3.  Select **Evaluate and log** and enter the expression to be printed in the text box below.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/kdYSyLe1Tp2fAHMn1iMr7Q/en-us_image_0000002532670097.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=41E38EC1F08E936846062AECB0E31E91E2E6F33E37E5C42BBD31927EC280E300)
    
4.  Start debugging to hit the breakpoint. Switch to the Console window in the debug mode, where the printing result of the expression will be displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/UIy5LSwXQWeXINsWplw1eg/en-us_image_0000002501070022.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=20F90EDF911D6E59D25E6E04E2937E7DB4EA42B43473F98787A66B7291E954CE)
