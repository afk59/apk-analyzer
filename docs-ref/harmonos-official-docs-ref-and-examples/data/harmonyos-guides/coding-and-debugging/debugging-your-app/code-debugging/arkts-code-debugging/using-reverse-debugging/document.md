# Using Reverse Debugging

In ArkTS code development scenarios, DevEco Studio provides reverse debugging capabilities in addition to basic debugging capabilities, allowing you to roll back the call stack.

When the program is interrupted, right-click in the call stack window and choose **Restart Frame** from the shortcut menu to go back to the previous call stack.
