# Viewing Stack Information

In the native code debugging window, click **Layout Settings** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/gsEYTeY7QQ-KL5k47qtV4w/en-us_image_0000002532670075.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=76B88AF0767122DDA43152114D30C8BD169A6E958B901AE3BF3D97BC3A2A9144) and select **Parallel Stacks** to open the **Parallel Stack** pane.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/C4Lq_PfgSPmf7TdztHQ6lg/en-us_image_0000002500910152.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C46EB4483351CB30E97B122AD220622C64160FC1BE5243179622CCCA7613AA5E)

When an app is paused, the **Parallel Stack** pane can display the call stack information of multiple threads and combine duplicate call stacks, which helps you better understand the concurrent execution of the app and locate potential multi-thread problems.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/EFhYQVc-RvSMjNufawOI1A/en-us_image_0000002532750023.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C4FC69D3E83A1AEBCF50511EE957E49D361FFB95F2315B5847D762407C63BB0F)

#### Switching Call Stacks

You can double-click a call stack in **Parallel Stack** to go to the stack, and view the stack information such as variables.

#### Viewing Thread Information

You can move the cursor to the position where multiple threads are combined to view the detailed information about these threads.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/bzAymlKzTUa2eFCy98AoPQ/en-us_image_0000002532750025.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=5A5A90AC9E001955CE3FB4FFEBCC673698EC4C74D69C27791F788ACCF9C5A03C)
