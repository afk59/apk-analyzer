# Viewing Memory Information

To open the **Memory View** pane, click **Layout Settings** and select **Memory View** in the native code debugging window.

#### Viewing Address Memory

To view the memory of an address, enter the address in the text box after **Go to** in **Memory View**, and click **View**.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/gWpRKd5RSu2i_3Bg6cauUw/en-us_image_0000002532670571.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=98EC01D7E6AD12456C93421B08F13874E9AE9BFA4455ED4F34EB2E5251E1D1CB)

You can click **Settings** to set the byte format, offset, and memory size.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/XtuJY0zlQySLcnhFSltp1w/en-us_image_0000002532750533.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3AA4A426A37B24262EE86E8993367BF4A84CB5F3502FF75A5EA782AA73EAF2AB)

#### Converting Memory

To convert the value of a memory cell, click the memory cell. The value will be automatically converted into different types of values on the right. You can also press and drag to select multiple memory cells to display the ASCII code conversion result of the selected memory cells.

#### Viewing Variable Memory

In the **Variables** pane, right-click a variable and choose **Inspect Memory** from the shortcut menu. The **Memory View** is displayed, showing the memory information about the variable address.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/drXA38CbT8--Nc96VKRPmQ/en-us_image_0000002501070500.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=5105815AFB118B83CD5DB2C647C7F13EF5851EDD87A82FC4FF544B5B039737AF)

#### Modifying Memory Size

To modify memory size, double-click the memory cell and enter the new memory value. You can also modify the value in the data conversion result box on the right to achieve the same purpose.
