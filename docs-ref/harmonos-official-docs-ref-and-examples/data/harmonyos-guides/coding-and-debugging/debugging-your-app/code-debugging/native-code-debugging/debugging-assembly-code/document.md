# Debugging Assembly Code

You can view disassembly information and debug assembly code in DevEco Studio. In addition, when the program pauses at a position without source code (for example, stepping into a function without debugging information), DevEco Studio will open the disassembly view, allowing you to check the address where the program is currently stopped and the corresponding assembly code.

#### Disassembly View

To view the assembly code corresponding to a stack frame, right-click the stack and choose **Disassemble Frame** from the shortcut menu.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/0yhbRu-OQn2lUJR4Z7DHYg/en-us_image_0000002532750387.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9E7FC4064521D068B6D07BF8F64E377BEAC073379D25E38D967F4B3F1E5FC4A0)

On the **Disassembly** page, you can view the source code, function names, and switch to the corresponding source code.

#### Setting Breakpoints in Assembly Code

On the **Disassembly** page, you can set breakpoints for debugging. Then, the app/atomic service will pause at the specified address.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/4ee2QaBmRHSOluzrFf3B4A/en-us_image_0000002501070370.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=364DD595E505BFDFC485BAC4AEE69349162F8D084B4F67D4B0481F335F1FF2AC)

On the **Disassembly** page, you can click the following buttons to perform single stepping of assembly instructions.
