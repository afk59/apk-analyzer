# Using Smart Step Into

During C++ debugging, if there are multiple function calls on the current line of code, you can use the ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/8iWIa9pwS6C8K5q3pk3sVw/en-us_image_0000002532749805.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=4151D3B700B478583C091DA480972B534052BF58E0991FD61CB3C0D5CD5B5B41) **Smart Step Into** feature to directly step into the implementation of a specific function.

#### Procedure

In the **Debugger** pane under the **entry-Native** debugger in the debug window, click the ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/pcI5MYpsRA-qBF1HU_RNyA/en-us_image_0000002501069780.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=399909B2E04DF7DA64EC7638770798FEF0D3A2011C62FD9A0572C00CBA2DFD3E) button (or press **Shift+F7**) to initiate **Smart Step Into**. DevEco Studio will highlight the functions in the current code that are available for stepping into.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/eZN3x2JwScK_-iTfc2ll5Q/en-us_image_0000002532669853.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6A0795C062A313ED43060987C2A50DD2CB2E67BD0458947C02D9800C2024A0B4 "Click to enlarge")

Click the function you want to step into, and the program will execute inside the implementation of the target function.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/NKxWH69ISHiPSFRF-hp4FQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062151Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=DE55A6D16D8CBB11933494FA49D43E1A3AF16773E758339B1F2A55A970C90A78)

Functions that have already been executed are not highlighted.
