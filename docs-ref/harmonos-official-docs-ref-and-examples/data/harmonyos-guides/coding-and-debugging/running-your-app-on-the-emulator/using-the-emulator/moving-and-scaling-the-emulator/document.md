# Moving and Scaling the Emulator

-   Moving the emulator
    
    You can use the mouse to drag the emulator to a specified position on the screen. Place the cursor on the edge of the screen. When the cursor changes to ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/C-jPQT5rQQyXABg-TUhNdA/en-us_image_0000002532668811.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F42D2B2C07008BB72EF4803E04A2A971811A928B2EEC3C93B8257495361E266A), hold down the left mouse button and move it to drag the emulator. After the emulator is dragged to the target position, release the left mouse button.
    
-   Scaling the emulator
    
    To resize the emulator, move the cursor to any corner of the screen. When the cursor changes to ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/UwzMyhpyQkmNXQ4BXkZBGw/en-us_image_0000002532748775.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=40158E4A43582A82565682CF0590045C3691668DA13B528FDF127542573D5B5F), hold down the left mouse button and move it to scale the emulator. After the emulator is scaled to the target size, release the left mouse button.
