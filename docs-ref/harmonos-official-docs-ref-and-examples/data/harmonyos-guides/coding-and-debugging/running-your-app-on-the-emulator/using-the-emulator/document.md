# Using the Emulator

The Emulator UI consists of two parts: device screen and toolbar. The device screen emulates a real-device display, allowing you to debug and test apps in an emulated environment. The Emulator enables app development without physical devices, cutting costs on devices and resources. The toolbar provides various debugging tools and control options to help you emulate different scenarios and operations, improving debugging efficiency.
