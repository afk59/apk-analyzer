# Controlling the Screen

When an emulator is running, you can use the mouse to emulate fingers interacting with the device screen. Together with the keyboard, you can perform advanced screen operations. The corresponding relationships are as follows.

| 
Operation

 | 

How to Emulate

 |
| :-- | :-- |
| 

Swipe

 | 

Place the cursor on the screen, hold down the left mouse button, move the mouse, and then release the button.

 |
| 

Drag and drop

 | 

Place the cursor over an item on the screen, hold down the left mouse button, drag the item, and then release the button.

 |
| 

Tap

 | 

Place the cursor on the screen, hold down the left mouse button, and then release the button.

 |
| 

Double-tap

 | 

Place the cursor on the screen, double-click the left mouse button, and then release the button.

 |
| 

Long press

 | 

Hover the cursor over an item on the screen, press and hold the left mouse button for a while, and then release the button.

 |
| 

Input

 | 

Click the input field and enter text using the physical keyboard or the soft keyboard popped up on the screen.

 |
| 

Pinch-to-zoom

 | 

Press the **Control** key on Windows (or the **Command** key on macOS) to bring up a multi-touch UI for emulating pinch gestures. Clicking the left mouse button emulates pressing both fingers, and releasing it emulates lifting both fingers. The mouse acts as the first finger, with the anchor point serving as the second finger. Drag the cursor to move the first point.

 |
| 

Scroll

 | 

Open a vertical menu on the screen and scroll the menu items using the mouse wheel. Click a menu item to select it.

 |
| 

Copy and paste

 | 

Copy a section of text on the computer and paste it into the text box on the emulator screen. The maximum length of text supported for pasting into the emulator is 30,000 English characters. Any text exceeding this threshold will be truncated.

Since DevEco Studio 6.0.1 Beta1, text can be copied and pasted between a computer and the emulator.

 |
