# Working Environment

The Emulator runs entirely on the local computer, conducive to a smooth and reliable experience. As such, it imposes the following requirements on the local computer:

Requirements for Windows

|

 |

 |

Operating system

 | 

Windows 10 Enterprise/Pro/Education (build version: 10.0.18363 or later)

 | 

Latest 64-bit Windows

 |
| 

CPU

 | 

-   64-bit processor with second level address translation (SLAT)
-   Support for the AES instruction set
-   Support for VM monitor mode extension (VT-c of Intel CPUs)
-   Running the Emulator in a virtual machine system: not supported
-   Windows ARM-based CPUs: not supported
-   Supported CPU models: models released after 2017

 | 

-   Latest Intel Core i5, i7, and i9 series CPUs
-   Latest AMD Ryzen 5, 6, 7, and 9 series CPUs
-   Laptops with CPUs featuring suffixes H/HK/HX, or desktops with CPU suffixes S/F/K

Intel® Core™ N-series and U-series processors: not recommended due to their insufficient performance
