# Overview

DevEco Studio provides the Emulator for you to run and debug HarmonyOS apps/atomic services. The Emulator mimics the basic functions of real devices, such as screen rotation, volume adjustment, hardware sensor functionality, and location positioning. This allows you to test apps seamlessly across multiple virtual environments, eliminating the need for physical devices. In some cases, the Emulator even provides a faster and more efficient testing experience than physical devices. For example, the Emulator provides the Shake emulation that allows you to easily trigger the Shake functionality. With the Emulator, you can develop and debug apps more flexibly and efficiently.
