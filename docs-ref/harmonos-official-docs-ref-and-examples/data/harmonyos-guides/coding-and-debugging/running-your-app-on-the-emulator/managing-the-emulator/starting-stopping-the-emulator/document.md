# Starting/Stopping the Emulator

On the **Device Manager** page, click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/n4_uko9uR1CCQncEkkRb7w/en-us_image_0000002500908792.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=54ED55989830A52BBF623235B16DB9F824219C40B1CC837A73251F713E243964) to start the emulator. When the emulator is started, it carries the user data from the last run by default, including the files uploaded by the user and the installed apps. A freshly created emulator contains no user data. If you want to wipe the user data generated during the last run, choose **Actions** > ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/1IcaQB_bSIyYfyv1kho6-w/en-us_image_0000002500908786.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=49A8577C6E17F6D8DB103FCC6903A4446B4453EDB68D0BC47E41106E6FAE7F39) > **Wipe User Data**.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/o8hRL3URQAelV5zvDyUN4Q/en-us_image_0000002501068650.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B9628106CDD46CE87814B588B19EC239841CAE210C09E9E8A92EE3CA461CB743 "Click to enlarge")

At emulator runtime, you can choose **Actions** > ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/mmuA7GtdTrW_DQ6sgcLRYQ/en-us_image_0000002500908782.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=86F14239E8E1B002A304A99F686DADC523D0B69FF640498810E7BC9ED3A73771) > **Show on Disk** to display the user data generated locally by the emulator. Choose **Actions** > ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/WHW2nSUFToCBBPQEwFLR4w/en-us_image_0000002500908778.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=08EA04BCB0F1CD89F03A5F9A0BE68F4103BA2D86FC1B0A2EDA15A2D582F9124E) > **Generate logs** to generate all log information from the emulator's startup to the current moment. To stop the emulator, click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/CCd9hSAuTyyVthUXh-I5jQ/en-us_image_0000002532668661.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3AF615A5A65762D94B8CCE560E1BFAA28E00F61C12ACDA02605F5F92339667B7) on the **Device Manager** page or click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/dEtMjx9dQka1OMVQj5AEmw/en-us_image_0000002500908798.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=ACCA51D420A52BAAD33892C14A139D978358AA1E316D23ADBB30B8A47EF51241) on the emulator toolbar.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/thqRF7JLSESiqBDJnN8tbw/en-us_image_0000002532748623.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3EF80A316223F0F7E9D4ABAF45E386394E4842D83B3D20173C6B70E41A56ADD5 "Click to enlarge")

After the emulator stops, you can choose **Actions** > ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/bY4oVzgpRMuS7JCKzF3fhw/en-us_image_0000002500908796.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062150Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=7BB295A9A53F2DEE45E6A5EE71A91358DB5D6A92C7C586A9A7F995819CBE1B58) > **Delete** to delete the emulator and clear the user data and configuration of the emulator.
