# @todo

Records the tasks to be completed. You can use the **@todo** tag multiple times in an ArkTSDoc comment.

#### Syntax

@todo text describing thing to do.

#### Example

The following is an example of using the **@todo** tag.

/\*\*
 \* @todo Write the documentation.
 \* @todo Implement this function.
 \*/
export function foo() {
  // write me
}
