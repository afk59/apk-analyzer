# Quickly Inserting Scenario-based Code Snippets

In DevEco Studio, you can use Kit Assistant to quickly insert pre-built, scenario-based components or code snippets into your ArkTS project by dragging and dropping them, saving time on coding frequent scenarios.

1.  Choose **View** > **Tool Windows** > **Kit Assistant** on the menu bar or press **Alt+K** (**Option+K** on macOS) to access the **Kit Assistant** page.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/5aw660w2SwiifKIx8wIs5w/en-us_image_0000002532670127.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=1083B5A484D003350082DCB81B8D1DABB39681322BC7E3292BB8C7DBD95E90F5)
    
2.  On the **Kit Assistant** page, browse the directory on the left to find and view scenario-based components and code snippets provided by different kits. The pane on the right displays detailed information of the selected item, including the usage constraints and applicable scenario.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/8r0tNN32QyKHf50_wCjiHg/en-us_image_0000002501070052.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9FD46AFF517CBBB7742F03930E08EDECC6D60731ED1A8F470AF9DE11C7F58413)
    
3.  Drag the required component or functional code from the directory to the desired location within your .ets file.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/GGhOKGnYS_W2RGIXAsrg5w/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062149Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D3D4A876991CE5B4C4A7A01DEE24E0934EB32E57970C323B78B1EB636DE2E49F)
    
    Kit Assistant may disable features or components that are not compatible with your current module or project settings, such as unsupported devices, API versions, or project models, or if they are not applicable to atomic services.
