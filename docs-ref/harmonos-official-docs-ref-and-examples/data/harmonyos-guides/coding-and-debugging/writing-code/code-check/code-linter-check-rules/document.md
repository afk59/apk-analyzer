# Code Linter Check Rules

Code Linter check rules are described in terms of their purpose, configuration options, and positive/negative code examples.

These examples are intended to help you quickly understand what the rule checks for and how to address the detected defects. Be aware that they are snippets and may not run as-is due to differences in runtime environments. To execute them, you need to modify and build them into complete, runnable code.
