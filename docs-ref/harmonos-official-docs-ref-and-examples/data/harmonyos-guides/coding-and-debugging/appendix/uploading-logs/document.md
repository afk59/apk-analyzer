# Uploading Logs

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/02ZrT_lqQrSnq1pZbnC3MQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E862BCB54F04CA6CA620DA354434C5903CF179CCCC2B45A7512E59D735469EE4)

Currently, this feature is available only in the Chinese mainland.

If you encounter issues such as DevEco Studio lag, freezing, or other failures during development, click **Send Report** in the **IDE Error** popup, then confirm by clicking **OK** to submit the log information to DevEco Studio.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/pmkYWqAISgWymKbyKHKDrQ/en-us_image_0000002500910700.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=73C80F40FFA2D4AFB4979250B10999BAF80883214709499C3F06FCF9B8F7665B "Click to enlarge")

Alternatively, click **Help** > **Collect Logs and Diagnostic Data** via the menu bar to select and upload related logs. This helps improve the stability of DevEco Studio.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/tdG5fdoBQIOkVym9BjCQzg/en-us_image_0000002532670611.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=AA9D4AFF75E126B731C870EFE6A3FB41AB8ECA739BE2EE6BAC9CC84D43337665 "Click to enlarge")

To disable data collecting, choose **File** > **Settings** (**DevEco Studio** > **Preferences**/**Settings** on macOS) > **Appearance & Behavior** > **System Settings** > **Data Sharing**, and deselect **Send usage statistics**.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/NsYg0mX_QIKm981oT9cXyg/en-us_image_0000002532750565.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062154Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=53C13C03DF829A6ED79350177ADCCBE0AC8C485255E6574AE586F67F5660A286)
