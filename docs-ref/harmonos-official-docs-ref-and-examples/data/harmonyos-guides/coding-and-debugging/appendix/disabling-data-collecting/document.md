# Disabling Data Collecting

When DevEco Studio is started for the first time, a dialog box is displayed, asking you to enable the data collecting function. This function helps DevEco Studio improve user experience. The collected data will be processed according to the [Statement About HUAWEI DevEco Studio Platform and Privacy](https://legal.cloud.huawei.com/terms/scope/huawei/deveco-studio-hmos/privacy-statement.htm?code=CN&amp;branchid=0&amp;language=en-us).

To disable data collecting, choose **File** > **Settings** (**DevEco Studio** > **Preferences**/**Settings** on macOS) > **Appearance & Behavior** > **System Settings** > **Data Sharing**, and deselect **Send usage statistics**.
