# DevEco Studio Parameters

DevEco Studio is developed based on the IntelliJ platform. In addition to IntelliJ parameters, the following parameters are added for DevEco Studio. You can set these parameters in **idea.properties**.

| 
Parameter

 | 

Parameter Description

 |
| :-- | :-- |
| 

grs\_url

 | 

Sets the cloud environment connected to DevEco Studio.

 |
| 

npm\_config\_strict\_ssl

 | 

Specifies whether to enable HTTPS certificate verification for npm. The default value is **true**, which means HTTPS certificate verification is enabled.

 |
| 

ohpm\_config\_strict\_ssl

 | 

Specifies whether to enable HTTPS certificate verification for ohpm. The default value is **true**, which means HTTPS certificate verification is enabled.

 |
