# Error 1001502014 is reported during authorization

Make sure that you have applied for the scope on the **Health Service Kit** card for the data types specified in the authorization request. For details about how to apply for the scopes, please refer to [Applying for Health Service Kit](../../development/getting-started/applying-for-health-service-kit/document.md). For details about the scopes matching each data type, please refer to [Scope Description](../../development/data-types/scope-description/document.md).

For more information about error codes, please refer to [ArkTS API Error Codes](https://developer.huawei.com/consumer/en/doc/harmonyos-references/errorcode-healthservice).
