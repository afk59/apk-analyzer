# No scope for a data type after obtaining the authorization

Your app scopes for authentication are the intersection of the scopes you have applied for and those granted by users. Make sure that:

1.  You have applied for the scopes for the required data types by referring to [Applying for Health Service Kit](../../development/getting-started/applying-for-health-service-kit/document.md). For details about the scope matching each data type, please refer to [Scope Description](../../development/data-types/scope-description/document.md).
2.  Users have selected the required scopes during the authorization.
