# Managing Data Sources

#### Scenario

The data source provides app or device information. Each piece of health and fitness data must be associated with a data source via a **DataSourceId**.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/WvCP1OY0Rzi_Ks4B7l2flQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062106Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F684ABFE49C6A5C6140577462658DD9FB245854E01BE467463296273DFB09BA3)

The value of **DataSourceId** is generated by the platform when the data source information is inserted, and cannot be changed.

#### Before Getting Started

-   Complete [Applying for Health Service Kit](../../getting-started/applying-for-health-service-kit/document.md) and [Configuring the Client ID](../../getting-started/configuring-the-client-id/document.md).
-   Before calling an API for the first time, call the [init](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#section1571935817328) method to perform initialization.
-   Make sure that you have obtained users' authorization for your app to access specific data types by calling [User Authorization](../managing-user-authorization/document.md#section0247115178), before calling the relevant APIs to access those data types.
-   For details about error codes, refer to [ArkTS API Error Codes](https://developer.huawei.com/consumer/en/doc/harmonyos-references/errorcode-healthservice). For FAQs, click [FAQs About Health Service Kit](../../../faqs-about-health-service-kit/document.md).

#### Development Procedure

## Inserting a Data Source

1.  Import the Health Service Kit functional module and related public modules.
    
    import { healthStore } from '@kit.HealthServiceKit';
    import { hilog } from '@kit.PerformanceAnalysisKit';
    
2.  Create a data source.
    
    let dataSource: healthStore.DataSourceBase = {
      deviceInfo: {
        uniqueId: 'test',
        name: 'test', // This field is mandatory when a data source is inserted.
        category: healthStore.DeviceCategory.WEARABLE\_BAND, // This field is mandatory when a data source is inserted.
        productId: '0554', // This field is mandatory when a data source is inserted.
        model: 'lotana',
        manufacturer: 'HUAWEI',
        mac: 'testDeviceMac',
        sn: 'testDeviceSn',
        hardwareVersion: '1',
        softwareVersion: '2',
        firmwareVersion: '3',
        udid: ''
      }
    }
    
3.  Call [insertDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#en-us_topic_0000001768344397_section127081351115614) to insert a data source and process the returned result.
    
    try {
      const dataSourceId = await healthStore.insertDataSource(dataSource);
      hilog.info(0x0000, 'testTag', \`Succeeded in inserting dataSource, the dataSourceId is ${dataSourceId}.\`);
    } catch (err) {
      hilog.error(0x0000, 'testTag', \`Failed to insert dataSource. Code: ${err.code}, message: ${err.message}\`);
    }
    

## Reading Data Sources

1.  Import the Health Service Kit functional module and related public modules.
    
    import { healthStore } from '@kit.HealthServiceKit';
    import { hilog } from '@kit.PerformanceAnalysisKit';
    
2.  Create a data source read request.
    
    let readSourceRequest: healthStore.DataSourceReadRequest = {
      deviceUniqueId: 'testudidupdate'
    }
    
3.  Call [readDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#en-us_topic_0000001768344397_section1275644314589) to query the data and process the returned result.
    
    try {
      let dataSources = await healthStore.readDataSource(readSourceRequest);
      dataSources.forEach((dataSource) => {
        hilog.info(0x0000, 'testTag', \`Succeeded in reading dataSource, the dataSourceId is ${dataSource.dataSourceId}.\`);
      });
    } catch (err) {
      hilog.error(0x0000, 'testTag', \`Failed to read dataSource. Code: ${err.code}, message: ${err.message}\`);
    }
    

## Updating a Data Source

1.  Import the Health Service Kit functional module and related public modules.
    
    import { healthStore } from '@kit.HealthServiceKit';
    import { hilog } from '@kit.PerformanceAnalysisKit';
    
2.  Create a data source.
    
    let newDataSource: healthStore.DataSource = {
      deviceInfo: {
        uniqueId: 'test',
        name: 'test',
        category: healthStore.DeviceCategory.WEARABLE\_BAND,
        productId: '0554',
        model: 'lotana',
        manufacturer: 'HUAWEI',
        mac: 'testDeviceMac',
        sn: 'testDeviceSn',
        hardwareVersion: '1',
        softwareVersion: '2',
        firmwareVersion: '3',
        // Update the UDID.
        udid: 'updateudid'
      },
      // Pass the value of **dataSourceId** returned when you insert the data source during the development.
      dataSourceId: 'xxx'
    }
    
3.  Call [updateDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#en-us_topic_0000001768344397_section7156914939) to update the data source and process the returned result.
    
    try {
      await healthStore.updateDataSource(newDataSource);
      hilog.info(0x0000, 'testTag', 'Succeeded in updating dataSource.');
    } catch (err) {
      hilog.error(0x0000, 'testTag', \`Failed to update dataSource. Code: ${err.code}, message: ${err.message}\`);
    }
