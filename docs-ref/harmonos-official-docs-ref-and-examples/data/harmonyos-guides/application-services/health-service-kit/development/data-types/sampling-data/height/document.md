# Height

Height data of a user at a certain time point.

Constant in the HarmonyOS SDK: [samplePointHelper.height.DATA\_TYPE](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-samplepointhelper#section691019541405)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/7ei1VF2YREOdeO2V5wR3JA/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062107Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=617ABCFE2C57ADC45AB3C2EA72E349ACD40CDE6DC9C676813CA0CF97D9976028)

This data type is not supported on wearables.

#### OAuth Scope

To apply for the required scopes, go to **Health data** > **Body fat** on the Console of HUAWEI Developers.
