# Overview

Data of workout records that last for a period of time, such as running and rope jumping records, comprises the workout type, app information, time range, associated detailed data, and associated statistics.

You can call [healthStore.readData](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#en-us_topic_0000001768344397_section410015582312) to obtain workout record data from the Huawei Health app.

For details about the workout record data model, please refer to [ExerciseSequence](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#section17704373316).

Workout type constant: [exerciseSequenceHelper.DATA\_TYPE](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-exercisedequencehelper#section171402050378)

#### OAuth Scope

To apply for the required scopes, go to **Activity data** > **Daily activity summary** on the Console of HUAWEI Developers.
