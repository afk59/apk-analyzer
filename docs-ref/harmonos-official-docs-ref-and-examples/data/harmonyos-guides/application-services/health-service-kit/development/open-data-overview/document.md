# Open Data Overview

This section lists the data provided by Health Service Kit. You can apply for the data scopes required for your app. In the Openness Level column, ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/OdoOOe50Sh6UmtasnYio6Q/en-us_image_0000002477254506.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=59B32E3C131C0A0053A5C63C6315CBCCE4EBEC5E2B68B44E89664A32A3FF5119) indicates advanced data that is not open to individual developers. You can access these data by registering as an enterprise developer and applying for the relevant scopes. ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/LeR45qb5ROura4HKqkLbqg/en-us_image_0000002477414494.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8095C0CBC376446ADCB5328198BF5EA147CEDDA7659CE4F8F356F0E97B817D8E) indicates basic data that is open both to individual and enterprise developers.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/gzQT7IsmT6qp9WL3ZWXdjg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=5E5F0220EFDA892482DC053ABE0E56D57BA81EF229BCF179EDAFF1D8152A9B4B)

-   Data timeliness is subject to actual usage, and cannot be ensured if the wearable device is not connected to the phone's Bluetooth, or the Huawei Health app is not kept alive in the background. During the development, you need to take extreme situations that may affect data timeliness into consideration, and determine the appropriate data usage scenarios, to ensure the stability of your product/service.
-   For details about the scopes corresponding to each data type, please refer to [Scope Description](../data-types/scope-description/document.md).
