# Applying for Health Service Kit

Before applying for Health Service Kit, set up the development environment, and complete basic preparations such as [creating a project](https://developer.huawei.com/consumer/en/doc/app/agc-help-create-project-0000002242804048), [creating a HarmonyOS app](https://developer.huawei.com/consumer/en/doc/app/agc-help-create-app-0000002247955506), and [adding a public key fingerprint](../../../../../getting-prepared/application-development-preparations/document.md#section1726913517284), by referring to [Application Development Preparations](../../../../../getting-prepared/application-development-preparations/document.md). Then proceed with the following development steps.

1.  Sign in to [HUAWEI Developers](https://developer.huawei.com/consumer/en) and click **Console**.

    If you have not registered a HUAWEI ID, register one and complete identity verification by referring to [HUAWEI ID Registration](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148) and [Identity Verification](https://developer.huawei.com/consumer/en/doc/start/atpopb-0000001062836624). You can register either as an individual developer or an enterprise developer.
    
2.  From the **App services** tab, click **Health Service Kit**. If the **Health Service Kit** card cannot be found, click **Customize console** in the upper right corner to add it.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/g6ptSeBmSFGyIpNr0t4VHQ/en-us_image_0000002509334443.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=181BB23C9041D023EE757472794555D5A7B2A2526EC4432E54D1AA0B0B69C1D3 "Click to enlarge")
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/V95zVHLpRS6vM6GAjJCamw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9DFABB3E73EF81A39AB24828662AD2BB255F53589A813F9F82D7134AB0788541)
    
    -   Currently, member accounts under a team account cannot independently use Health Service Kit. For details, please refer to [Team Account](https://developer.huawei.com/consumer/en/doc/start/team-account-guides-0000001053785552).
    

3.  Click **Apply for Health Service Kit**, agree to the agreement, and the screen for data scope application will be displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/CzoMnYkBRPOz9K2tgRFbYQ/en-us_image_0000002477254486.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2B6F364E6324700CA6E89CACA88F4FE7BDEF7B1E5A601788758DFFB8DB965530 "Click to enlarge")
    
4.  Set **Product Type** to **HarmonyOS App**, fill in the application information, and select the scopes required for your app.

    -   After the related app or service is released, Huawei will conduct random checks on the use of scopes. The checks include but are not limited to spot checks on released apps, monitoring of API calling, and inspection by assigned specialists. You can learn about the check criteria and how the check results are handled by referring to the agreement you have signed before applying for Health Service Kit.
    -   For details about the OAuth scopes corresponding to data types, please refer to [Scope Description](../../data-types/scope-description/document.md).

#### FAQs About Applications Being Rejected

The following lists typical FAQs about applications being rejected. Please read the following content before submitting your application. If you have submitted an application and the application is rejected, modify the application materials by referring to the following solutions and submit them again.

## Lack of Scopes

Requirement: Each read/write scope you apply for must be specified in the application materials.

Solution: Ensure that each of the scope you apply for is specified in Sheet 1 and Sheet 2.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/BxkiHk6UQCGEg-SYP-C_nw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062105Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3B4748927A7C70800EFB5FD35EDBFA2059768D91E8E419A341BAA4E5203FDFE8)

For any changes in the usage scenarios of the data read/write scopes you have applied for, update the application material before applying for verification.

## Incorrect Icon Usage

Requirement: The usage of icons must comply with [Specifications for Using Logos](../../../appendixes/specifications-for-using-logos/document.md).

Solution: Ensure that you present the Huawei Health logo in scenarios described in the application materials you have submitted in compliance with [Specifications for Using Logos](../../../appendixes/specifications-for-using-logos/document.md).

## Mandatory Content Missing

Requirement: Complete all of the sheets in the application material.

Solution: Complete the sheets left empty in the application material. Particularly, the Enterprise Introduction sheet is mandatory for enterprise developers. If you are an individual developer, complete the Developer Info sheet and specify your institute or university in the sheet.

#### Enterprise Qualification Not Meeting the Requirements

If you have any questions about the qualification requirements, [submit a ticket](https://developer.huawei.com/consumer/en/support/feedback/#/) or send an email to [hihealth@huawei.com](mailto:hihealth@huawei.com).

Specify the following in your email or ticket: developer site, country/region where users reside, introduction to the enterprise and project scenarios, and contact information of the project owner.

## Individual Qualification Not Meeting the Requirements

Requirements: For individual developers, if your app has not been released on AppGallery, or the app is not a mobile app, Health Service Kit data will not be open to your app. You can apply for accessing user data with the basic openness level, if you do not have any adverse credit records. User data with the advanced openness level is currently not open to individual developers. For details about the data openness levels, please refer to [Open Data Overview](../../open-data-overview/document.md).

Solution: Release your mobile app on AppGallery, or re-register as an enterprise developer to apply for Health Service Kit. When applying for Health Service Kit, select only the user data with the basic openness level.

If the issue persists, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/) for assistance.

1.  Sign in to the [Submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/) page and select **HMS Core**.
2.  Select **Health Service Kit**.
3.  Describe the question and click **Submit**.

After you submit a question, we will get back to you within one to two workdays. We may need you to get the questions further clarified, so please pay attention to the progress and reply in a timely manner.
