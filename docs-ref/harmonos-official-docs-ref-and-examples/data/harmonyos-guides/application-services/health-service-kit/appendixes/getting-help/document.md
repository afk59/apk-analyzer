# Getting Help

When you encounter a problem, read the official documentation first to quickly get what you want. If you still cannot find the answer, contact us in any of the following ways:

-   [Submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/). We will get back to you within one to two workdays. We may need you to get the questions further clarified, so please pay attention to the progress and reply in a timely manner.

-   Provide feedback on the official website.
    1.  If you have any questions about content on the official website, select the related text, and click **Send feedback**.
    2.  Select a problem category, describe the problem, and click **Send**.
