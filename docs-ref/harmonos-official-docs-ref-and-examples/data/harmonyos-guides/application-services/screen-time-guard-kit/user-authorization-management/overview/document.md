# Overview

Screen Time Guard Kit can be used for time management and app restriction on user devices only after being authorized by users. It provides APIs for your app to request and revoke user authorization. Users can also proactively toggle on or off the user authorization switch on the authorization list page of Digital Balance. You can implement the callbacks of a specific ExtensionAbility to detect users' behavior of toggling on or off the user authorization switch on the authorization list page of Digital Balance.
