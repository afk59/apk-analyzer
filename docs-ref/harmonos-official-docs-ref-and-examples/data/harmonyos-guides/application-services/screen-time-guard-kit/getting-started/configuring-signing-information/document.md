# Configuring Signing Information

-   In the debugging phase, [request a debug certificate](https://developer.huawei.com/consumer/en/doc/app/agc-help-debug-cert-0000002283256797), [register a debug device](https://developer.huawei.com/consumer/en/doc/app/agc-help-add-device-0000002283189937), and [request a debug profile](https://developer.huawei.com/consumer/en/doc/app/agc-help-debug-profile-0000002248181278) in AppGallery Connect. Then, [manually configure signing information](../../../../coding-and-debugging/configuring-a-debug-signature/document.md#section297715173233).
-   In the release phase, [request a release certificate](https://developer.huawei.com/consumer/en/doc/app/agc-help-release-cert-0000002283336729) and [a release profile](https://developer.huawei.com/consumer/en/doc/app/agc-help-release-profile-0000002248341090) in **AppGallery Connect**. Then, [manually configure signing information](../../../../app-release/release/document.md#section280162182818).
