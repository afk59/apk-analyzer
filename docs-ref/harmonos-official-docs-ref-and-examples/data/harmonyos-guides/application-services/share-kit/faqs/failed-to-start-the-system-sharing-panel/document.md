# Failed to Start the System Sharing Panel

**Symptom:**

The system sharing panel cannot be started.

**Possible causes:**

1.  The API is incorrectly used. As a result, the API throws an exception.
2.  A certain other module is faulty.

**Procedure:**

1.  Check whether the exception is caused by improper use of the Share Kit API. For details, please refer to [Share Kit APIs](https://developer.huawei.com/consumer/en/doc/harmonyos-references/share-system-share) and [Error Codes](https://developer.huawei.com/consumer/en/doc/harmonyos-references/share-error-code). After locating the fault, modify the code.
2.  If a certain other module is faulty, check whether a fault log exists. If so, locate the fault based on the module in the fault log. If not, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/) for assistance.
3.  If the fault cannot be located, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/). Huawei will get back to you as soon as possible.
