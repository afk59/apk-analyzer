# Transfer Between Trusted Devices

-   If two devices are signed in to the same HUAWEI ID, the devices are trusted by default and data can be transferred without confirmation.
-   If two devices are signed in to different HUAWEI IDs, the users will be asked whether to trust the peer device. After the two devices trust each other, data can be transferred without confirmation within 1 hour.
