# Enabling Grab & Drop on a Device

To use the Grab & drop feature, enable it first.

Enabling path: **Settings** > **System** > **Shortcuts & gestures** > **Grab & drop**.

#### Association Between "Grab & Drop" and Grabshot

When the Grab & drop feature is enabled, grabshot is also enabled. Users can manually enable or disable grabshot as needed.

| 
Grab & Drop Enabled

 | 

Grab & Drop Disabled

 |
| :-- | :-- |
| 

-   Grabshot enabled: Original images are transferred in gallery scenarios. Screenshots are transferred in other scenarios.
-   Grabshot disabled: Original images are transferred in gallery scenarios. No screenshot is captured or transferred in other scenarios.

 | 

-   Grabshot enabled: Screenshots are only captured, but not transferred.
-   Grabshot disabled: No screenshot is captured or transferred.

 |

"Grab & drop" and grabshot are triggered by the same gesture. When both features are enabled and the current app has registered the Grab & drop event, clenching the fist will trigger both features. Under the image transferred using Grab & drop, there is the **Save screenshot to this device** option (deselected initially by default). The user can select the option to save the screenshot locally, and the system will record the choice as the default setting for the next operation. If the user chooses to save the screenshot, the screenshot will be saved to the gallery while sending data.
