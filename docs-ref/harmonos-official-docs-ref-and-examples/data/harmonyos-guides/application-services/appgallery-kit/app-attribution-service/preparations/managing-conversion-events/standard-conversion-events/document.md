# Standard Conversion Events

Make sure that you have set conversion events before accessing the app attribution service. The app attribution service supports standard and custom conversion events. You are advised to use standard conversion events for registration and reporting. If standard conversion events fail to meet your business needs, create [custom conversion events](../custom-conversion-events/document.md) for subsequent attribution activities.

**The developer role in effective state can view standard conversion events and custom conversion events on the conversion event management page.**

Choose **Conversion Event Management** on the left and click **Custom Conversion Events**.
