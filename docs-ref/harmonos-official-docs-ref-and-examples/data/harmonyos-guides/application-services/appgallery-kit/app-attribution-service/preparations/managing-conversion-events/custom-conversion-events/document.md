# Custom Conversion Events

**If selecting the developer role, you can perform the following operation on the conversion event management page:**

Add, modify, delete, and view custom conversion events.

When you add, modify, or delete custom conversion events, such operations will be reviewed by the operations team. Only an approved operation can take effect.

#### Adding a Custom Conversion Event

1.  Choose **Conversion Event Management** on the left. The **Custom Conversion Events** tab page is displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/lUCGVu3sRm2dQctLawUQtA/en-us_image_0000002337734772.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=0D30EF4DBD5FC8A61720B0897CB57E8BB87D9F772C0CD786695010037231CAC2 "Click to enlarge")
    
2.  Click **New** in the upper right corner to enter the **New Custom Conversion Event** page.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/e77zhKlvQUGzGNZwvz8QPQ/en-us_image_0000002337894504.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=079D81BA367533106EE89CA9B0C5E6C35B13AE516AA24FE7A6A246F0FF3E37E9 "Click to enlarge")
    
3.  Enter an event name, event ID, and description, and click **OK**. A custom conversion event with the status of **Reviewing (new)** is generated.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/Kvny6SLYQQeZMp_1EBiSOA/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C19D10E0DA1994E876F168B4E2852531371B2C5F4B4DEABC15A3AB5C38840E86)

-   Enter an event ID that ranges from 501 to 600.
-   Both the event name and ID should be unique.

#### Modifying a Custom Conversion Event

1.  Click **Edit** on the right of a custom conversion event in effective or rejected state.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/TvPmMIobSg2yqvnWCyTyTw/en-us_image_0000002371652877.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8198C991D21EDE8072DFF956FA0E92AD1E8A4CDBD192464016443899F9125743 "Click to enlarge")
    
2.  On the displayed editing page, modify the event name, event ID, and description, and then click **OK**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/F2dP9KHqTqe6ecfkiUt_OQ/en-us_image_0000002371652849.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=10D482AA472CE5FBC226EBD6D38DBD87729BBA33B28ED758835541E2FD124A0C "Click to enlarge")
    
3.  View the modified data, which is in **Reviewing (new)** or **Reviewing (updated)** state.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/qTOyeLbFTBqzeyy77irwnw/en-us_image_0000002337894528.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=14CD0CE5EC31E60AF9EC758C2A3172548B1D918F93BB387C39A748E1A66722B0 "Click to enlarge")
    

The modified record can take effect only after being approved. If it is rejected, the original event name and ID still apply.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/NNvziHcXSHKOjf0fwLXCGw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062058Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8B71A2AF9D84A690FA3BCE2149E32DEC5A1BD5D879BF9798AE343DD1166BE3B4)

-   The new event name and ID should not be the same as those of any effective event or any event under review.
-   After you modify a rejected event, its status will be displayed as **Reviewing (new)**.

#### Deleting a Custom Conversion Event

Click **Delete** on the **Registration** page. Then click **OK** in the pop-up.

That way you can delete the rejected record.

If you are deleting an effective event, click **OK**. The status of the record changes from **Effective** to **Reviewing (deleted)**.

An effective record can only be deleted after being approved by the review team.
