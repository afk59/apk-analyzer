# Registering an Enterprise Account

Before registering an attribution role, you need to register as a developer on [HUAWEI Developers](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148) and complete [identity verification as an enterprise developer](https://developer.huawei.com/consumer/en/doc/start/edrna-0000001062678489).
