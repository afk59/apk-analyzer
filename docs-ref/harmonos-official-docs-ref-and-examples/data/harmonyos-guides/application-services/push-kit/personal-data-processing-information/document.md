# Personal Data Processing Information

In personal data processing of Push Kit, Huawei serves as the end user data processor, and you serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

-   List of personal data processed by Huawei
-   Guidance for you to help the end user control personal data

The above stored personal data will be uploaded through a secure channel to the Huawei server for processing. Before calling a Push Kit API, ensure that the user agrees to the privacy statement of your app.

#### Guidance for You to Help the End User Control Personal Data

-   How to clear the end user's personal data?
    
    Push tokens can be stored for a maximum of 15 days, and basic app information can be stored for a maximum of six months. When the storage period expires, data will be automatically deleted from the server.
