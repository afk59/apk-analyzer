# About This Kit

File Manager Service Kit provides the file management capability for you to implement functions such as moving files to the recycle bin and obtaining file icons, meeting users' diverse requirements for file management.

#### Use Cases

File Manager Service Kit provides the following functions:

-   Move a file in the public directory to the recycle bin.
-   Obtain a file icon based on the file type.

#### Restrictions

## Supported Countries and Regions

Currently, this kit is available only in the Chinese mainland.

## Supported Devices

This kit is only applicable to mobile phones, tablets, and PCs/2-in-1 devices. Running or debugging the kit via the Emulator is not supported.
