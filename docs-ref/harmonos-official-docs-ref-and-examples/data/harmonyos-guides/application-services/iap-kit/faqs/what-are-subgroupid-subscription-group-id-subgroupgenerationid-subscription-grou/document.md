# What Are subGroupId (Subscription Group ID), subGroupGenerationId (Subscription Group Generation ID), and subscriptionId (Subscription ID)?

-   **subGroupId** identifies a subscription group, which contains multiple auto-renewable subscriptions.
-   **subGroupGenerationId** is a unique ID that identifies a user's consecutive subscriptions within the same subscription group. This ID is generated when a user subscribes to a product for the first time. The ID remains unchanged when the user subscribes to other products in the same subscription group. The ID changes when the user subscribes to a product again after the subscription expires and the [account hold period](../../product-purchase/auto-renewable-subscription-purchase/understanding-auto-renewable-subscriptions/document.md#section1656191811315) ends.
-   **subscriptionId** identifies the subscription relationship between a user and a product in a subscription group.
