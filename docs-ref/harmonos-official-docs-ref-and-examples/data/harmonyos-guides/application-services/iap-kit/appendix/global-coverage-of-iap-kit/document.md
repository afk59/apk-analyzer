# Global Coverage of IAP Kit

IAP Kit is now available in numerous countries and regions around the world, providing secure, convenient, and efficient payment services for consumers and merchants.

Currently, bank card payment is already supported in **183** countries and regions.

Due to limitations with certain currencies on the payment platform, decimal values are not supported. You must set the **amount** field in the order parameters to an integer value such as **5.00**, rather than a non-integer value such as **5.02**.

Currencies involved:

BEF, XOF, XAF, XPF, KMF, GRD, GNF, HUF, IDR, JPY, LUF, MGA, MGF, PYG, PTE, RWF, KRW, ESP, TRL, VND, IQD, COP, CLP, ISK, and KES (M-Pesa does not support decimals, while bank cards, HUAWEI Points, and coupons support decimals. It is recommended to prioritize setting the amount to an integer).
