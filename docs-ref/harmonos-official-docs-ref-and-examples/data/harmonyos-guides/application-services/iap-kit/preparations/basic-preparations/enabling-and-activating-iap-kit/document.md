# Enabling and Activating IAP Kit

1.  To use IAP Kit, first turn on the **In-App Purchases (HarmonyOS NEXT)** switch. This operation is required for each app that needs to use this kit. For details, please refer to [Enabling the In-App Purchases (HarmonyOS NEXT) API](https://developer.huawei.com/consumer/en/doc/app/switch-0000001958955097).
2.  After turning on the switch, it is necessary to activate **In-App Purchases (HarmonyOS NEXT)**. For details, please refer to [Activating the In-App Purchases Service and Configuring Event Notifications](https://developer.huawei.com/consumer/en/doc/app/parameters-0000001931995692).

-   During the release phase, you **must** [apply for a release certificate](https://developer.huawei.com/consumer/en/doc/app/agc-help-add-releasecert-0000001946273961) and **re-apply for** [a release profile](https://developer.huawei.com/consumer/en/doc/app/agc-help-add-releaseprofile-0000001914714796) after enabling and activating IAP Kit. Then, you need to [manually sign](../../../../../app-release/release/document.md#section280162182818) your app.
