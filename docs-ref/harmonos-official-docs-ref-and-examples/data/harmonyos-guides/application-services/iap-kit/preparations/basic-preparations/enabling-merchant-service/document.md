# Enabling Merchant Service

Enabling Merchant Service is a prerequisite for you to distribute paid content (such as paid apps/themes, in-app content, and ads). Within Merchant Service, you must configure bank account details, currency settings, and other information to receive revenue shares from Huawei For more details and instructions, please refer to [Merchant Service](https://developer.huawei.com/consumer/en/doc/start/merchant-service-0000001053025967).
