# Configuring Signing Information

In DevEco Studio, [create a project](../../../../environment-setup/creating-a-project/creating-a-project/document.md) and [configure a debug signature (automatic signing)](../../../../coding-and-debugging/configuring-a-debug-signature/document.md#section18815157237) to guarantee successful project compilation and development.

If your DevEco Studio version is earlier than 6.0.0.848, [manually sign](../../../../coding-and-debugging/configuring-a-debug-signature/document.md#section297715173233) your app.
