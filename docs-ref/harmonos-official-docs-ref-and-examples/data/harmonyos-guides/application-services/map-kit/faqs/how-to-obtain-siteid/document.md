# How to Obtain siteId?

**siteId** can be obtained in multiple ways. The following provides three methods for reference:

1\. Use the [on('poiClick')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/map-map#section0279247143911) method to obtain the value.

2\. Obtain the value from the result returned by [place search](../../place-search/document.md) APIs (APIs of keyword search, nearby place search, place details search, autocomplete, and forward geocoding).

3\. Obtain the value from the result returned by the [chooseLocation](https://developer.huawei.com/consumer/en/doc/harmonyos-references/map-scenemap#section927375116348) API.
