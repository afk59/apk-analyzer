# Personal Data Processing Information

In personal data processing of Map Kit, Huawei serves as the end user data processor, and you serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

-   List of personal data processed by Huawei Map Kit
-   Guidance for you to help the end user control personal data
