# Overview

#### Function Overview

The Nearby Transfer capability is added since version 5.1.0 (18).

The capability enables game data exchange when devices are close to each other.

#### Use Case

This service allows players to transfer resource packages to each other face to face. Players who have updated to the latest game version can share resource packages on their devices with players who haven't updated yet. This helps those players complete the update more quickly, saving their mobile data and time. Additionally, this helps mitigate the negative impact of frequent game updates, which may cause user churn.
