# Overview

#### Function Overview

The game scene perception module provides APIs to help you quickly enable interaction between the game and the system. Through game scene perception, your game can send game data to the system and obtain device status information from the system.

#### Use Case

The game scene perception module mainly optimizes game scenes. It applies different resource allocation strategies based on the game scene and system running status.
