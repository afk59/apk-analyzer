# Overview

The basic game service can rapidly build cost-effective basic functions for games, such as multi-provider sign-in, HUAWEI ID identity verification, and anti-addiction for minors, allowing developers to focus on core capabilities of their games, thereby accelerating game promotion and facilitating in-depth game operations based on user and content localization.

#### Constraints

The basic game service supports phones, tablets, and PCs/2-in-1 devices. Starting from version 5.1.1(19), TVs are also supported.

#### Use Case

## Online Game Sign-in

An online game is a game that requires Internet connection.

After integrating with the basic game service, an online game allows users to sign in with a HUAWEI ID or official game account on the multi-provider sign-in panel.

## Standalone Game Sign-in

A standalone game is a game in which data is stored locally and no server connection is required.

After integrating the basic game service, a standalone game allows users to quickly sign in with a HUAWEI ID. The basic game service also provides HUAWEI ID identity verification and anti-addiction for minors for standalone games.
