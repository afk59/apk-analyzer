# Overview

Starting from 6.0.1(21), mini game capabilities are supported.

Developed based on industry standards, mini games are installation-free apps that offer an instant, tap-to-play experience and can be added to the phone home screen as needed. Crucially, a single development effort enables developers to distribute their mini games to all compatible devices.

#### Constraints

Mini game capabilities are supported on phones, tablets, PCs/2-in-1 devices, and TVs.

#### Use Case

Inter-app shared libraries are provided during mini game runtime to implement the sign-in and payment functions.
