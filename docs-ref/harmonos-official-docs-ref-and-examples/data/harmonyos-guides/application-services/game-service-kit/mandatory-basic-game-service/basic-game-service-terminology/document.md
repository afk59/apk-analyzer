# Basic Game Service Terminology

#### H

## HarmonyOS 4 and earlier

Legacy systems including HarmonyOS 3.1/4.0 and earlier as well as EMUI.

## HarmonyOS 5.0 and later

New commercial versions including HarmonyOS 5.0 and later.

#### I

## Interoperability

Interoperability refers to the unification of player IDs across HarmonyOS 4-and-earlier version and HarmonyOS 5.0-and-later version of your game, allowing players to sign in to different versions of your game using their HUAWEI IDs, and enabling account asset synchronization across these systems.

#### S

## Standalone Game

A game in which data is stored locally and no server connection is required.

#### U

## User ID

Player ID in HarmonyOS 4-and-earlier version or HarmonyOS 5.0-and-later version of a game. The parameter names used in different systems to represent the ID are as follows.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/ZJifCMCxRmWAlEyB0g1maw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062104Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=84F513A341E64A7211A6E7102FDD365679D193D428A0FBB3197F2DD4973408C9)

Player IDs are case sensitive. For example, "gamePlayerId=xxx" and "gamePlayerId=XXX" indicate two different players.

**openId** or **playerId** selected during [app ID mapping configuration](../game-sign-in/online-game-sign-in/mandatory-sign-in-with-a-huawei-id/document.md#en-us_topic_0000002385861065_section3907114313255).

teamPlayerId

 | 

**teamPlayerId** ≈ **uid** + **developerid**

 | 

If a player uses the same HUAWEI ID to sign in to different games under the same **developerid**, the player will obtain the same **teamPlayerId**.

For games that are newly integrated with the basic game service, you do not need to pay attention to this ID.

 |
| 

HarmonyOS 4 and earlier

 | 

openId

 | 

User ID generated by encrypting the combination of a HUAWEI ID (user account) and the unique app ID.

A simple way to understand it is: **openId** ≈ **uid** + **clientid**.

 | 

**openId** is the unique ID that identifies an account in an app. **openId** does not change even if the app entity changes.

If a user uses the same HUAWEI ID to sign in to different games (whether from the same developer or multiple developers), the user obtains a unique **openId** for each game.

 |
| 

playerId

 | 

Game player ID provided by Game Service Kit by encapsulating the HUAWEI ID (user account).

A simple way to understand it is: **playerId** ≈ **uid**.

 | 

**playerId** is associated only with the HUAWEI ID (user account) and does not change even if app or developer account information changes. It is used for game apps only.

 |
| 

unionId

 | 

User ID generated by encrypting the combination of a HUAWEI ID (user account) and the developer ID.

A simple way to understand it is: **unionId** ≈ **uid** + **developerid**.

 | 

**unionId** is unique under a developer entity. It changes if the app entity changes.

If a player uses the same HUAWEI ID to sign in to different games under the same develop entity, the player will obtain the same **unionId**.

 |
