# Obtaining the Game Key

Obtain the game private key or public key in AppGallery Connect for signing or signature verification on your server.

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html), choose **Development and services**, and select your project and game.
2.  Choose **Build** > **Games Service** and record the game key information. If you need to update the key, contact Huawei technical support by [submitting a ticket online](<https://developer.huawei.com/consumer/en/support/feedback/#/add/101704353566310877?level2=101704353626565886&amp;level3=101704354579010004&amp;keyWord=Game Service Kit>).
