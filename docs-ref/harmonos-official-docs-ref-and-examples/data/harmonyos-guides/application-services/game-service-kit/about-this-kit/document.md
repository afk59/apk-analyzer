# About This Kit

#### Overview

Game Service Kit helps you build basic game capabilities quickly at a low cost and provides you game scene optimization services, effectively improving game development efficiency and supporting game operations.

| 
**Function**

 | 

**Description**

 |
| :-- | :-- |
| 

(Mandatory) [Basic game service](../mandatory-basic-game-service/document.md)

 | 

Rapidly builds cost-effective basic functions for games, such as multi-provider sign-in, HUAWEI ID identity verification, and anti-addiction for minors, allowing developers to focus on core capabilities of their games, thereby accelerating game promotion and facilitating in-depth game operations based on user and content localization.

 |
| 

(Optional) [Game scene perception](../optional-game-scene-perception/document.md)

 | 

Allows a game to closely collaborate with the operating system for improved gameplay experience with restricted system resources. Specifically, the game provides elaborative game scene, configuration, and network information for the system, and the system provides its status information for the game.

 |
| 

(Optional) [Nearby transfer](../optional-nearby-transfer/document.md)

 | 

Allows devices to exchange game data when they are close to each other.

 |

#### Constraints

## Supported Countries/Regions

Currently, this kit is available only to HUAWEI IDs with both the service area and registration location within the Chinese mainland.
