#### Guidance for You to Help the End User Control Personal Data

**How to Clear the End User's Personal Data**

Game Service Kit will delete any data that can identify the end user from their sign-in records after they successfully delete their HUAWEI ID.

Game Service Kit stores sign-in records of the latest five years (determined by local laws and regulations) at most. Expired sign-in records will be automatically deleted.
