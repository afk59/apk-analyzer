# Third-Party Development Framework Access

Live View Kit supports third-party platforms as HarmonyOS does. HarmonyOS provides access guides for common third-party development frameworks:

-   [React Native](https://gitee.com/react-native-oh-library/usage-docs)
-   [Flutter](https://gitcode.com/openharmony-tpc/flutter_samples/tree/br_3.7.12-ohos-1.1.0/ohos/docs)
-   [Uni-app](https://en.uniapp.dcloud.io/tutorial/harmony/intro.html)
