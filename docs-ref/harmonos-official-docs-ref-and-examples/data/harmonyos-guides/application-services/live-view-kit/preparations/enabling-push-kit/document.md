# Enabling Push Kit

If you need to create, update, and end live views through the Push Kit server, [enable Push Kit](../../../push-kit/preparations/enabling-push-kit/document.md) for your project before enabling Live View Kit.

-   After enabling Push Kit, you can [update live views through Push Kit](../../app-development/updating-a-live-view-through-push-kit/document.md) or use a push token to add a debugging device for live view debugging.
