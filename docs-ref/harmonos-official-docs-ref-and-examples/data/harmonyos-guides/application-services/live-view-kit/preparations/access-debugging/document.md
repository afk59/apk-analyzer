# Access Debugging

If you need to debug and verify Live View Kit on devices, you can click **Manage debugging device** to add devices for debugging. The debugging devices will bypass the verification on the local live view creation permission.

The debugging device management function can also be used to let users experience the live view function before the official rollout by adding their devices as debugging devices.

**After the live view function is fully tested on the debugging devices, you can apply for the formal permission on Live View Kit.** (Be sure to attach the screenshots of the access debugging results on the debugging devices when you apply for the formal permission.)

#### Restrictions

-   The added debugging devices will be processed and take effect within 24 hours. The debugging permission validity period is the same as the push token validity period.
-   Debugging devices must be added based on push tokens. You can add up to 100 debugging devices for each app.

#### Adding Debugging Devices

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html), click **Development and services**, and find your project in the project list. Then, go to **Grow** > **Push Kit** > **Settings**. The **Settings** page is displayed.
2.  Select your app, click **Manage debugging device** next to **Live view**, and add debugging devices based on [push tokens](../../../push-kit/preparations/obtaining-a-push-token/document.md). Then you will be able to perform access debugging on these devices.
