# Creating a Local Live View

#### Introduction

You can use the [liveViewManager](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager) module to create a local live view and implement its entire lifecycle (including creation, update, and ending). Note that you can create a live view only when your app is running in the foreground and a user actually uses your app service. In addition, updating or ending a live view locally requires that your app process is running. Therefore, you are advised to use Push Kit to update or end a locally created live view.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/26oFdkQxRFGVqI3gkD83lQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062111Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=455C85BCDD913FF2594E792C23356C212083EDD89C577589C63D218F7CAB96C3)

Live View Kit provides sample code for the entire live view lifecycle in 11 scenarios, including ride hailing, instant delivery, air travel, rail travel, queuing, meal pickup, live score, shared leasing, timing, workout, and navigation. If you want to experience the effect before integrating Live View Kit, please refer to [Live View Kit Sample Code](https://gitcode.com/HarmonyOS_Samples/live-view-kit_-sample-code_-clientdemo_-arkts).

#### Importing liveViewManager

Import [liveViewManager](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager) to your project, create a live view control class (for example, **LiveViewController**), and construct the **isLiveViewEnabled()** method to check whether the live view function (**Settings** > **Apps & services** > **APP** > **Live view**) is enabled. You must enable the live view function before creating a live view. The sample code is as follows:

import { liveViewManager } from '@kit.LiveViewKit';

export class LiveViewController {
  private static async isLiveViewEnabled(): Promise<boolean> {
    return await liveViewManager.isLiveViewEnabled();
  }
}

#### Creating a Live View

There are five live view templates based on the extension area: progress visualization template, emphasized text template, left-right text template, live scores template, and navigation template.

Call the [liveViewManager.startLiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section195321751104612) API to create a live view. The input parameter of this API is a live view instance (liveViewManager.[LiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section411410371767)).

The progress visualization template is applicable to scenarios such as ride hailing and food delivery.

After building a **LiveViewController** class, initialize it in the code and call the **LiveViewController.startLiveView()** method.

import { liveViewManager } from '@kit.LiveViewKit';
import { Want, wantAgent } from '@kit.AbilityKit';

export class LiveViewController {
  public async startLiveView(): Promise<liveViewManager.LiveViewResult> {
    // Check whether the live view function is enabled.
    if (!await LiveViewController.isLiveViewEnabled()) {
      throw new Error("Live view is disabled.");
    }
    // Create a live view.
    const defaultView = await LiveViewController.buildDefaultView();
    return await liveViewManager.startLiveView(defaultView);
  }

  private static async buildDefaultView(): Promise<liveViewManager.LiveView> {
    return {
      // Construct a live view request body.
      id: 0, // Live view ID, which is generated by you.
      event: "DELIVERY", // Application scenario of the live view. The value **DELIVERY** indicates instant delivery (takeout and fresh food).
      liveViewData: {
        primary: {
          title: "Rider picked up order",
          content: \[
            { text: "Distance from store:" },
            { text: "300 ", textColor: "#FF0A59F7" },
            { text: "m | " },
            { text: "3 ", textColor: "#FF0A59F7" },
            { text: "minutes left" }
          \], // If **textColor** is set for some objects in the array, its values for all these objects must be the same. If **textColor** is not set for an object in the array, the default text color **#FF000000** will be used.
          keepTime: 15,
          clickAction: await LiveViewController.buildWantAgent(),
          layoutData: {
            layoutType: liveViewManager.LayoutType.LAYOUT\_TYPE\_PROGRESS,
            progress: 40,
            color: "#FF317AF7",
            backgroundColor: "#f7819ae0",
            indicatorType: liveViewManager.IndicatorType.INDICATOR\_TYPE\_UP,
            indicatorIcon: "indicator.png", // Progress indicator icon. The value is a file name in **/resources/rawfile** or an image.[PixelMap](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-image-pixelmap) object.
            lineType: liveViewManager.LineType.LINE\_TYPE\_DOTTED\_LINE,
            nodeIcons: \["icon\_1.png", "icon\_2.png", "icon\_3.png"\] // Icon of each node in the progress bar. The value of each element is a file name in **/resources/rawfile** or an image.[PixelMap](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-image-pixelmap) object.
          }
        }
      }
    };
  }

  private static async isLiveViewEnabled(): Promise<boolean> {
    return await liveViewManager.isLiveViewEnabled();
  }

  private static async buildWantAgent(): Promise<Want> {
    const wantAgentInfo: wantAgent.WantAgentInfo = {
      wants: \[
        {
          bundleName: 'xxx.xxx.xxx', // Actual package name of the app.
          abilityName: 'EntryAbility'
        } as Want
      \],
      actionType: wantAgent.OperationType.START\_ABILITIES,
      requestCode: 0,
      actionFlags: \[wantAgent.WantAgentFlags.UPDATE\_PRESENT\_FLAG\]
    };
    const agent = await wantAgent.getWantAgent(wantAgentInfo);
    return agent;
  }
}

## Action to Be Triggered upon Live View Tapping

Call wantAgent.[getWantAgent](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-app-ability-wantagent#wantagentgetwantagent-1)() to construct the parameter values for the action to be triggered upon live view tapping. Currently, the live view supports the following actions:

-   Default action when a user taps a live view: Carry the liveViewData.primary.[clickAction](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section452772611408) parameter required by the capsule in the liveViewManager.[LiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section411410371767) struct.
-   Redirection action when a user taps an auxiliary area: Carry the liveViewData.primary.extensionData.[clickAction](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section14934174734616) parameter required by the capsule in the liveViewManager.[LiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section411410371767) struct.

#### Updating and Ending a Live View Locally

After calling [liveViewManager.isLiveViewEnabled](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section19741144281410)() to verify that the live view function is enabled, you can call [updateLiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section1310319579406) of the liveViewManager to update the live view and call [stopLiveView](https://developer.huawei.com/consumer/en/doc/harmonyos-references/liveview-liveviewmanager#section929145112243) to end the live view. You need to modify the corresponding parameters in the request body when updating the live view. The sample code is as follows:

import { liveViewManager } from '@kit.LiveViewKit';

  }
