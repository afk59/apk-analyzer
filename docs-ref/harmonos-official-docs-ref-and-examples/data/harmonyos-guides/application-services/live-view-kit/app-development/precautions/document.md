# Precautions

The currently supported live view scenarios are listed in [Applicable Scenarios](../../about-this-kit/document.md#section4266105713209). We also provide [Node Design References for Different Application Scenarios](../../live-view-design-specifications/document.md#section596543013594) for your reference.

Live view messages sent by your app must comply with the [Live View Design Specifications](../../live-view-design-specifications/document.md). Solutions that do not comply with the design specifications will not be granted formal permission on Live View Kit. After the live view function goes live in your app, any action that violates the specifications will be regarded as a [violation](../../about-this-kit/document.md#section61131311488).
