# Why Is the Profile Picture Not Displayed in the Notification Banner?

**Problem**

The notification banner is launched when an incoming call is received, but the profile picture cannot be displayed properly.

**Solution**

1.  Check whether the size of the profile picture is within 196,608 KB.
2.  The uploaded image cannot exceed 221 x 221 pixels, and 112 x 112 pixels is recommended.
3.  If the fault persists, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/). Huawei technical support will get back to you as soon as possible.
