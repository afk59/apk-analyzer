#### API Description

APIs used for incoming calls are provided by [voipCall](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall). For details, please refer to the [API Reference](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall).

| 
API

 | 

Description

 |
| :-- | :-- |
| 

on(type: 'voipCallUiEvent', callback: Callback<VoipCallUiEventInfo>): void

 | 

Subscribes to **voipCallUiEvent**.

 |
| 

off(type: 'voipCallUiEvent', callback?: Callback<VoipCallUiEventInfo>): void

 | 

Unsubscribes from **voipCallUiEvent**.

 |
| 

reportIncomingCall(voipCallAttribute: VoipCallAttribute): Promise<ErrorReason>

 | 

Reports the incoming call.

 |
| 

reportCallAudioEventChange(callId: string, callAudioEvent: CallAudioEvent): Promise<void>

 | 

Reports the audio event.

 |
| 

reportCallStateChange(callId: string, callState: VoipCallState): Promise<void>

 | 

Reports the call status change.

 |
| 

reportCallStateChange(callId: string, callState: VoipCallState, callType: VoipCallType): Promise<void>

 | 

Reports the call status change and specifies the call type.

#### Development Procedure

1.  Import dependencies.
    
    import { voipCall } from '@kit.CallServiceKit';
    import { image } from '@kit.ImageKit';
    import { hilog } from '@kit.PerformanceAnalysisKit';
    
2.  Subscribe to **voipCallUiEvent** to detect the user's answering, hanging up, muting, and unmuting operations on the banner. It is recommended to complete the step before reporting the incoming call.
    
    Sample code:
    
    // Subscribe to **voipCallUiEvent**.
    voipCall.on('voipCallUiEvent', callback => {
      hilog.info(0x0000, 'CallDemo', 'Succeeded in registering voipCallUiEvent');
    });
    
3.  After a call connection is established within the app, the incoming call must be reported to Call Service Kit along with call details. For more information, please refer to  [VoipCallAttribute](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section4221135015444).
    
    If the app is running in the background, the system will display a banner for the incoming call.
    
    Sample code:
    
    // Construct parameters for reporting the incoming call.
    let voipCallAttribute: voipCall.VoipCallAttribute = {
      callId: '1234567890',
      voipCallType: voipCall.VoipCallType.VOIP\_CALL\_VOICE,
      userName: 'Callman',
      userProfile: image.createPixelMapSync(new ArrayBuffer(100), { size: { width: 90, height: 90 } }),
      abilityName: 'VoipCallAbility',
      voipCallState: voipCall.VoipCallState.VOIP\_CALL\_STATE\_RINGING,
      showBannerForIncomingCall: true
    };
    
    // Report the incoming call.
    voipCall.reportIncomingCall(voipCallAttribute).then(errorReason => {
      if (errorReason == voipCall.ErrorReason.ERROR\_NONE) {
        hilog.info(0x0000, 'CallDemo', 'Succeeded in reporting the incoming call');
      } else {
        hilog.error(0x0000, 'CallDemo', 'Failed to report the incoming call: %{public}d', errorReason);
      }
    });
    
    For a video call, the  [isVoiceAnswerSupported](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section4221135015444)  parameter can be used to specify whether voice-only answering is allowed. Sample code is as follows:
    
    // Construct parameters for reporting the incoming call.
    let voipCallAttribute: voipCall.VoipCallAttribute = {
      callId: '1234567890',
      voipCallType: voipCall.VoipCallType.VOIP\_CALL\_VIDEO,
      userName: 'Jack',
      userProfile: image.createPixelMapSync(new ArrayBuffer(100), { size: { width: 90, height: 90 } }),
      abilityName: 'VoipCallAbility',
      voipCallState: voipCall.VoipCallState.VOIP\_CALL\_STATE\_RINGING,
      showBannerForIncomingCall: true,
      isVoiceAnswerSupported: false  // Voice mode is not supported for the video call.
    };
    
4.  The user can choose to answer or reject the call.
    
    Answering methods: reporting the status twice and reporting the status once
    
    -   (Recommended) Reporting the status twice
        
        For example, for a voice call, once receiving the [VOIP\_CALL\_EVENT\_VOICE\_ANSWER](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section26961727970) callback, the app immediately reports the [VOIP\_CALL\_STATE\_ANSWERED](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section24523814719) state to Call Service Kit and implements call answering simultaneously.
        
        After call answering is completed, the app reports the [VOIP\_CALL\_STATE\_ACTIVE](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section24523814719) state to Call Service Kit. The system will then update the notification banner.
        
        Sample code:
        
        voipCall.on('voipCallUiEvent', callback => {
          if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_VOICE\_ANSWER) {
            // Immediately report the answered state to Call Service Kit.
            voipCall.reportCallStateChange(callback.callId, voipCall.VoipCallState.VOIP\_CALL\_STATE\_ANSWERED);
        
            // Implement call answering in the app.
        
            // After implementing call answering in the app, report the active state to Call Service Kit.
            voipCall.reportCallStateChange(callback.callId, voipCall.VoipCallState.VOIP\_CALL\_STATE\_ACTIVE);
          }
        });

        Benefits of reporting the status twice:
        
        Due to network issues, a noticeable delay (example: around 1 second) may occur between the user's tap on the answer button and the call being answered. User experience may be compromised if the banner continues to notify of the ringing state during the delay.
        
        Reporting the status twice updates the screen for the user when the call is answered.
        
    -   Reporting the status once
    
    For example, for a voice call, once receiving the [VOIP\_CALL\_EVENT\_VOICE\_ANSWER](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section26961727970) event callback, the app implements call answering.
    
    After call answering is completed, the app reports the [VOIP\_CALL\_STATE\_ACTIVE](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section24523814719) state to Call Service Kit.
    
    Sample code:
    
    voipCall.on('voipCallUiEvent', callback => {
      if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_VOICE\_ANSWER) {
        // Implement call answering in the app.
    
        // After completing call answering in the app, report the call status to Call Service Kit.
        voipCall.reportCallStateChange(callback.callId, voipCall.VoipCallState.VOIP\_CALL\_STATE\_ACTIVE);
      }
    });
    
    If the user taps the button for rejecting the call on the notification banner, the app will complete the rejection upon receiving the  [VOIP\_CALL\_EVENT\_REJECT](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section26961727970)  callback, then report the  [VOIP\_CALL\_STATE\_DISCONNECTED](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section24523814719)  state to Call Service Kit. The system will dismiss the notification banner accordingly.
    
    After the call is rejected, skip steps 5 and 6 and go directly to step 7.
    
    Sample code:
    
    voipCall.on('voipCallUiEvent', callback => {
      if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_REJECT) {
        // Implement call rejection in the app.
    
        // Report the call status to Call Service Kit.
        voipCall.reportCallStateChange(callback.callId, voipCall.VoipCallState.VOIP\_CALL\_STATE\_DISCONNECTED);
      }
    });
    
5.  During the call, the user can mute or unmute the call as needed.
    
    For example, when the user taps the mute button on the notification banner, Call Service Kit will trigger the [VOIP\_CALL\_EVENT\_MUTED](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section26961727970) callback and report the event to the app.
    
    After the app completes the mute operation, it will then report the [AUDIO\_EVENT\_MUTED](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section312217120409) state to Call Service Kit.
    
    Sample code:
    
    voipCall.on('voipCallUiEvent', callback => {
      if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_MUTED) {
        // Report the mute to Call Service Kit.
        voipCall.reportCallAudioEventChange(callback.callId, voipCall.CallAudioEvent.AUDIO\_EVENT\_MUTED);
      } else if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_UNMUTED) {
        // Report the unmute to Call Service Kit.
        voipCall.reportCallAudioEventChange(callback.callId, voipCall.CallAudioEvent.AUDIO\_EVENT\_UNMUTED);
      }
    });

6.  When the user taps the button for hanging up, Call Service Kit will trigger the [VOIP\_CALL\_EVENT\_HANGUP](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section26961727970) callback and report the event to the app.
    
    The app then ends the call after receiving the event and reports the [VOIP\_CALL\_STATE\_DISCONNECTED](https://developer.huawei.com/consumer/en/doc/harmonyos-references/call-voipcall#section24523814719) state to Call Service Kit. The system will then cancel the banner notification.
    
    Sample code:
    
    voipCall.on('voipCallUiEvent', callback => {
      if (callback?.voipCallUiEvent == voipCall.VoipCallUiEvent.VOIP\_CALL\_EVENT\_HANGUP) {
        // Implement call hang-up in the app.
    
        // Report the call status to Call Service Kit.
        voipCall.reportCallStateChange(callback.callId, voipCall.VoipCallState.VOIP\_CALL\_STATE\_DISCONNECTED);
      }
    });
    
7.  Unsubscribe from **voipCallUiEvent** if necessary, as the app no longer needs to detect the user's operations on the banner after the call ends.
    
    Sample code:
    
    // Unsubscribe from **voipCallUiEvent**.
    voipCall.off('voipCallUiEvent', callback => {
      hilog.info(0x0000, 'CallDemo', \`Succeeded in unRegistering voipCallUiEvent, callId: ${callback.callId}\`);
    });
