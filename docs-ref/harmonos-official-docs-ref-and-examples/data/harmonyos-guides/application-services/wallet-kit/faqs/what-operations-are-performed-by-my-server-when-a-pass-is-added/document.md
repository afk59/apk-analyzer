# What operations are performed by my server when a pass is added?

1.  Push the pass template to the Huawei server by referring to [Enabling a Car Key](../../digital-car-key/enabling-a-car-key/document.md#section5585115171117).
2.  When a user taps a button or link for adding a pass, your server encrypts the user instance as JWE data and sends the data to the Huawei server.
