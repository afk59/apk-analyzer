# Can I remove the header, footer, watermark, and background from a specific page using PDF Kit?

You cannot remove the header, footer, watermark, and background from a specific page using PDF Kit. For details, please refer to [Headers and Footers](../../pdfservice-capabilities/adding-and-deleting-headers-and-footers/document.md), [Watermarks](../../pdfservice-capabilities/adding-and-deleting-watermarks/document.md), and [Backgrounds](../../pdfservice-capabilities/adding-and-deleting-backgrounds/document.md).
