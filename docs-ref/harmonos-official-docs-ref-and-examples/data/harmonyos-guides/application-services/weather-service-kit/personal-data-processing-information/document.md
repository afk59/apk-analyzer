# Personal Data Processing Information

Weather Service Kit queries the weather forecast data of the corresponding location based on the rough location information (accurate to two decimal places) provided by the caller. Weather Service Kit never proactively collects the location information of users.

#### Guidance for You to Help the End User Control Personal Data

-   How to clear the end user's personal data
    
    The latitude and longitude data is pseudonymized and not associated with information that can be used to identify users, such as user IDs and device IDs. The cloud server does not store the data.
