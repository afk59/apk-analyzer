# Setting Quick Entry for Enabling Application Notifications

#### When to Use

The in-application notification settings page is often hidden deep within the application, making it difficult for users to locate. This has resulted in a higher rate of users disabling application notifications.

To address this issue, we have added a quick entry to the in-application notification settings page—both in the left-swipe menu of notification messages and on the system's application notification settings page. This entry directly redirects users to the in-application notification category management page, enhancing user experience for notification management and reducing likelihood of users turning off application notifications.
