# What Should I Do If Compilation Fails?

**Symptom**

The "install failed due to grant request permissions failed" message is displayed, indicating that compilation fails as the signing certificate does not have the required permissions.

**Solution**

1.  Ensure that the permissions are correctly configured in your app signature by referring to the [overview of access control](../../../../system/security/application-access-control/access-control-overview/document.md).
2.  If the fault persists, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/). Huawei will get back to you as soon as possible.
