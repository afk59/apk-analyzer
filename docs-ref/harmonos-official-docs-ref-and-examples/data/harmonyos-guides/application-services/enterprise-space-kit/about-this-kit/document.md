# About This Kit

Enterprise Space Kit offers APIs for workspace management and inter-workspace data transfer management to enterprise [MDM](../../../system/basic-functions/mdm-kit/document.md) apps, enabling enterprises to flexibly configure and manage their workspaces as well as inter-workspace data transfer policies. By leveraging centralized management and remote configuration of this kit, MDM apps can ensure that workspaces satisfy enterprise service needs while also meeting data transmission security requirements. Enterprise Space Kit is widely adopted in government agencies, large technology enterprises, central state-owned enterprises, and commercial banks for "dual-purpose device" and "multi-network enterprise" scenarios. This ensures simple and user-friendly operations for enterprise employees, simplified administration of enterprises, and secure isolation of enterprise data.

#### Use Cases

-   For [MDM](../../../system/basic-functions/mdm-kit/document.md) apps that focus on enterprise security control, Enterprise Space Kit provides the capabilities of making review settings for outgoing data transfer and obtaining review information. In this way, enterprises can then review their outbound file transfer events based on their specific security management requirements. Review information can contain file information, file status, file sending destination, and file sending time.
-   Enterprise Space Kit offers unified workspace management and the capability to deliver workspace management policies. The policies include creating a personal workspace, removing a workspace, and subscribing to workspace events. Enterprises can configure and manage their workspace management policies based on their specific service needs.

#### Emulator Support

Running or debugging using the Emulator is not supported.

## Access Restriction

After Enterprise Space Kit is enabled, data in [public directories](../../../coding-and-debugging/debugging-your-app/device-file-access/document.md#section975311314172) of background workspaces may become inaccessible after workspace switches.
