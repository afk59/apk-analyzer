# Enabling Cloud Functions

You need to enable Cloud Functions before using it. If you have enabled it, skip this step.

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and click **Development and services**.
2.  Click the project for which you need to enable Cloud Functions.
    
3.  Go to **Serverless** > **Cloud Functions**. On the **Cloud Functions** page that is displayed, click **Enable Now**.

    If you have not set a data processing location, a dialog box will be displayed to guide you through the setting. Currently, you can [enable multiple data processing locations](https://developer.huawei.com/consumer/en/doc/app/agc-help-data-location-0000002277923065#section154810363471) for Cloud Functions.
    
4.  If you have enabled multiple data processing locations, you can switch among these locations to facilitate management.
