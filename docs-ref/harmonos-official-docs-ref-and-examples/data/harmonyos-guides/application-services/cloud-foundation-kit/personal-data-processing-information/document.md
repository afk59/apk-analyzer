#### Guidance for You to Help the End User Control Personal Data

-   How to Clear the End User's Personal Data
    -   The end users or you proactively delete the data.
        -   To delete user data from Cloud Storage, call [StorageBucket.deleteFile](https://developer.huawei.com/consumer/en/doc/harmonyos-references/cloudfoundation-cloudstorage#section1290422653419).
        -   To delete user data from Cloud DB, call [DatabaseZone.delete](https://developer.huawei.com/consumer/en/doc/harmonyos-references/cloudfoundation-clouddatabase#section1630522892714).
    -   You proactively delete the entire project.
