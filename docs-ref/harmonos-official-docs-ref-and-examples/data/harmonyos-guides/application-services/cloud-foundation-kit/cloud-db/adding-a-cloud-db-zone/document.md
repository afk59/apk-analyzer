# Adding a Cloud DB Zone

This section describes how to create a Cloud DB zone named **QuickStartDemo**.

#### Prerequisites

You have [enabled Cloud DB](../../getting-started/enabling-cloud-db/document.md).

#### Procedure

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and click **Development and services**.
2.  Click the project for which you want to create a Cloud DB zone.
3.  Go to **Serverless** > **Cloud DB**.
4.  Click the **Cloud DB Zones** tab and click **Add**.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/kqGlFjZQS--zxjh2nKLUNQ/en-us_image_0000002440774608.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062102Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=694BEC82C5F70C4966EA2960260F5AC3F3CFDA5EEF4D24BA8835F2A64A0C7F46)
    
5.  In the **Add Cloud DB Zone** dialog box, set **Cloud DB zone** to **QuickStartDemo** and click **OK**.
