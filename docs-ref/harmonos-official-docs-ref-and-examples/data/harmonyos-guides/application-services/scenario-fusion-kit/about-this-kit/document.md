# About This Kit

Scenario Fusion Kit leverages components of the ArkUI framework, offering scenario-specific components that seamlessly integrate across subsystems. This streamlines developer adoption and fosters a unified user experience within the HarmonyOS ecosystem. ArkUI empowers your app with smart input suggestions and one-tap complex form filling, all with just a single line of core code. Scenario Fusion Kit helps you with system development for your app or atomic service to further enrich the HarmonyOS ecosystem and actually implement services.

#### Business Value

-   Higher development efficiency
    
    Using the service, you can build scenario-specific components across multiple subsystems, which you only need to import once. This unlocks efficient, easier development of frequently used scenarios for your app or atomic service.
    
-   User experience streamlined based on standard component tap behavior
    
    Button components provided by the kit can collaborate with other services such as Account Kit and system settings to provide unified user experience upon component taps.
    
-   Scenario-specific input suggestions for realizing one-tap filling of complex forms
    
    SmartFill helps users easily fill out forms. This function can be launched using just a single line of code after you integrate ArkUI input components.
