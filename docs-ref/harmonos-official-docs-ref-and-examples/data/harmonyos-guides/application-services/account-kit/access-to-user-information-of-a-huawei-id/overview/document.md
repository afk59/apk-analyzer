# Overview

When your app needs to obtain user identifiers or complete user profiles (avatar, nickname, shipping address, and invoice title), or needs to obtain the risk level of the user, use the capabilities provided by Account Kit to guide the user to fill in and manage relevant data, and to complete authorization. To implement the functions of obtaining a user's avatar and nickname, shipping address, and invoice title, please refer to the [sample code](https://gitcode.com/HarmonyOS_Samples/accountkit-samplecode-clientdemo-arkts) provided by Account Kit.

**Typical use cases:**

1.  [Obtaining the Avatar and Nickname](../obtaining-the-avatar-and-nickname/document.md): The user's avatar and nickname information is required to complete relevant profile information.
2.  [Obtaining the Shipping Address](../obtaining-the-shipping-address/document.md): The user's shipping address is required for some services.
3.  [Obtaining the Invoice Title](../obtaining-the-invoice-title/document.md): The user's invoice title is required for some services.
4.  [Obtaining the Risk Level](../obtaining-the-risk-level/document.md): The user's risk level is required for some services.
5.  [Obtaining the Mobile Number](../obtaining-the-mobile-number/document.md): The user's mobile number is required for some services.
