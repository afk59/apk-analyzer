# Management Rules for Using the Sign-in Capability of Account Kit

To safeguard user privacy and ensure a seamless sign-in experience, Huawei has formulated the management rules for using the sign-in capability of Account Kit in accordance with the [HUAWEI Developers Service Agreement](https://developer.huawei.com/consumer/en/doc/start/agreement-0000001052728169), [Agreement on Use of Huawei APIs](https://developer.huawei.com/consumer/en/doc/app/10129), [AppGallery Review Guidelines](https://developer.huawei.com/consumer/en/doc/app/50104), [Atomic Service Review Guidelines](https://developer.huawei.com/consumer/en/doc/app/50129), and other relevant agreements and applicable laws and regulations. These guidelines are applicable to all apps that use HUAWEI ID sign-in. Below are the requirements that should be adhered to.

#### Review Requirements for App Release

To eliminate the hassle of repeated sign-ins across different apps, we empower HarmonyOS apps and atomic services with seamless HUAWEI ID sign-in. HarmonyOS apps and atomic services to be released to HUAWEI AppGallery must comply with the following requirements:

(1) If your app allows users to sign in using a third-party account, it must also provide the HUAWEI ID sign-in option. Users can easily sign in to your app with HUAWEI IDs and are entitled to relevant ID security configurations.

(2) If you need to build an account system for your atomic service, it is a must to use the HUAWEI ID sign-in capability.

#### Sign-in UI Design Specifications

HUAWEI ID provides comprehensive sign-in design guidelines to ensure HarmonyOS apps offer a simple, efficient, consistent, and secure sign-in experience. For details about the design guidelines, please refer to [the rules specified here](https://developer.huawei.com/consumer/en/doc/design-guides/id-0000001880001344).
