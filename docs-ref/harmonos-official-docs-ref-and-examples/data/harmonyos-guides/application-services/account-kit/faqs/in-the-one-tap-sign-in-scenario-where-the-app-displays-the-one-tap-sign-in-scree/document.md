# In the One-Tap Sign-In Scenario Where the App Displays the One-Tap Sign-In Screen, What Should the App Proceed If the User Signs Out of the HUAWEI ID or Switches to Another HUAWEI ID on the Device?

The app monitors the sign-in status of the HUAWEI ID on the current device by [subscribing to the HUAWEI ID sign-in status event](../../sign-in/subscribing-to-huawei-id-sign-in-sign-out-events/document.md). If a HUAWEI ID sign-out event is detected, the app must redirect to a sign-in screen that offers other sign-in options. If a new–HUAWEI ID sign-in is detected, it is necessary to re-obtain the anonymous mobile number and refresh the one-tap sign-in screen. For details, please refer to the [sample code for one-tap HUAWEI ID sign-in](https://gitcode.com/HarmonyOS_Samples/accountkit-samplecode-clientdemo-arkts).
