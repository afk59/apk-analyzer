# Is the UnionID/OpenID of a HUAWEI ID user or the mobile number used as their unique identifier during one-tap sign-in with HUAWEI ID?

It is recommended that the UnionID or OpenID of a HUAWEI ID user be used as their unique identifier, and the user's account in the app be associated with the mobile number bound to the HUAWEI ID. The UnionID and OpenID do not change. Even if the mobile number bound to a HUAWEI ID is changed, the user can still use the HUAWEI ID to sign in to the original bound account within the app. This approach ensures seamless connectivity of user accounts across diverse devices, scenarios, and services (such as apps and atomic services), thereby guaranteeing a consistent user experience. If the mobile number of a HUAWEI ID is used as the unique identifier of a user, once a new mobile number is bound to the HUAWEI ID, subsequent sign-ins will use the account linked to the new mobile number. Check [Scenario Design](../../sign-in/signing-in-with-huawei-id-through-just-one-tap-obtaining-the-mobile-number-union/document.md#section4654113502814) for the detailed process of one-tap sign-in with HUAWEI ID.
