# Enabling App Linking

You need to enable App Linking before using it. If you have enabled it, skip this section.

1.  Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and click **Development and services**.
2.  Click the project to which your HarmonyOS app belongs.
3.  In the navigation tree on the left, choose **Grow** > **App Linking**, and click **Enable Now** on the **App Linking** page displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/jyfOOeq1SP2vCLwdzjpxhA/en-us_image_0000002505890542.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062100Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=D11B5E083D46D577FC2F154A59A49D2E7DB164799854C7314CDDE3E0E287BE4A)
    
4.  If no data processing location has been set for the project, select desired data processing locations and set the default one in the dialog box that is displayed, and click **OK**.
