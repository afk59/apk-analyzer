# Making Preparations

Before starting app development, you need to make the following preparations:

1.  Register as a developer.
    
    [Register as a developer](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148) on HUAWEI Developers and complete [identity verification](https://developer.huawei.com/consumer/en/doc/start/rna-0000001062530373) to enjoy the open capabilities and services provided by HUAWEI Developers.
    
2.  Create an app.
    
    Create a HarmonyOS app in [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html). For details, please refer to [Creating a Project](https://developer.huawei.com/consumer/en/doc/app/agc-help-create-project-0000002242804048) and [Creating a HarmonyOS App](https://developer.huawei.com/consumer/en/doc/app/agc-help-create-app-0000002247955506).
