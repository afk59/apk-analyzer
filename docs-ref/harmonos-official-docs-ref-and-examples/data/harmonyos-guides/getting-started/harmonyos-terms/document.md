# HarmonyOS Terms

#### A

## **ABC file**

A file containing the source code written in ArkCompiler Bytecode (ABC) format. It is generated by the ArkCompiler toolchain, with a file name extension of .abc. For an application in release mode, the ABC file is packed into an HAP.

## **ANS**

Advanced Notification Service, a system service in HarmonyOS to handle notification-related operations, including subscription, publishing, and updating.

## **Atomic service**

A lightweight, installation-free service that provides specific functionalities directly to users. These services can be started through independent entries such as service widgets, and automatically loaded by the application framework from the background.

## **ArkUI**

ArkUI is a UI framework used to develop cross-device applications that run on HarmonyOS. It provides streamlined UI development and helps developers efficiently build UIs with high performance for cross-device applications.

## **ArkCompiler**

A unified programming platform developed by Huawei. It consists of a compiler, a toolchain, and runtime components, supporting compilation and running of high-level languages on different chip platforms. ArkCompiler supports traditional applications and atomic services running on a wide range of devices, such as smartphones, PCs, tablets, TVs, cars, and wearables.

#### D

## **DFX**

Design for X (also called Design for eXcellence), a design approach targeted at each stage of the product lifecycle. The "X" represents a stage or feature of the product lifecycle. For example, DFR stands for design for reliability, and DFT stands for design for testability. DFX covers all non-functional design of a product, including R&D, manufacturing, O&M, and service. It aims to improve the overall product quality, performance, and user experience at reasonably low cost.

## **DV**

Device Virtualization, which employs the virtualization technology to integrate capabilities and resources of different devices.

#### E

## **ExtensionAbility**

A component that provides extension capabilities for specific scenarios (such as service widgets and input methods) in the stage model.

#### F

## **FA**

Feature Ability, an ability with a UI in the FA model to interact with users.

## **FA model**

Application development model used in earlier HarmonyOS versions. Now, the [stage model](#section149771135182013) is recommended for application development.

#### H

## **HAP**

Harmony Ability Package, released with the file name extension .hap. A HAP provides all content of an application, including code, resources, third-party libraries, and an application configuration file.

## **HarmonyOS**

HarmonyOS is a next-generation operating system for smart devices, providing a unified language for enabling intelligence, interconnection, and collaboration across different devices. It gives a neat, smooth, seamless, secure, and reliable interaction experience in all scenarios.

In 2024, HarmonyOS was released with a brand-new architecture, named HarmonyOS NEXT. The first Developer Beta version of HarmonyOS NEXT was publicly released on June 21, 2024, and the first official Release version (version number 5.0.0) was launched on October 22, 2024. HarmonyOS NEXT uses [OpenHarmony](#section15569823194110) as its underlying operating system and has passed the OpenHarmony compatibility certification. It optimizes the underlying layer for an all-scenario experience and provides a smoother system and enhanced privacy protection capabilities, bringing consumers a more efficient, convenient, and secure intelligent operation experience.

## **HDF**

Hardware Driver Foundation that allows unified access from peripheral devices and provides foundation for driver development and management.

## **HML**

HarmonyOS Markup Language, a markup language similar to HTML, used for creating pages using components and events and provides advanced capabilities such as data binding, event binding, list rendering, and conditional rendering.

## **Hop**

A hop refers to a distributed operation involving multiple devices running HarmonyOS. The hop capability breaks boundaries of devices and enables multi-device collaboration, achieving precise control, universal coordination, and seamless hops of user applications. For example, a user can edit the same email, do a crossfit exercise, or play a game across devices.

The hop capability provides you with broad application scenarios, innovative product perspectives, enhanced product advantages, and superior experience.

#### I

## **IDN**

Intelligent Distributed Networking, a distributed networking capability unit specific to HarmonyOS. You can use IDN to obtain the device list and device states and subscribe to the connection state changes of devices on the distributed network.

#### K

## **Kit**

A set of open capabilities that developers use to implement functionalities in specific scenarios.

#### M

## **Manual hop**

A manual hop refers to the hop operation manually triggered by the user simply by tapping the standard hop icon embedded in a user application and selecting a desired device. After the user taps the icon, the hop panel provided by the system is invoked. The panel displays information about the user application to be hopped and the target devices that can be hopped to. It also provides guidance for the user to perform subsequent hop operations.

## **MSDP**

Mobile Sensing Development Platform, a framework that provides convergence sensing across devices. Backed by the distributed capabilities of HarmonyOS, the MSDP collects and processes data from various sensors integrated into devices to accurately sense users' states, such as the space status, motion status, gestures, and health status. It thereby builds ubiquitous basic sensing capabilities, bringing smart life experience to users.

## **Multi-device collaboration**

Multi-device collaboration is one of the technologies for implementing hops of user applications across devices. This technology enables different FAs or PAs on multiple devices to run concurrently or successively, or same FAs or PAs on multiple devices to run concurrently to implement complete business functionalities.

#### O

## **OpenHarmony**

In 2020, Huawei donated the foundational capabilities of HarmonyOS to the OpenAtom Foundation to initiate the OpenHarmony open source project. OpenHarmony provides underlying OS capabilities, including the application and UI frameworks, basic services (such as distributed management, data, and file services), and basic applications (such as the home screen, Settings, Calendar, and Contacts).

#### P

## **PA**

Particle Ability, an ability without a UI in the FA model. PAs are invoked to implement FA functionalities. For example, a PA runs in the background to provide the computing capability or acts as a data warehouse to provide the data access capability.

## **PC/2in1**

PCs/2-in-1 devices, mainly used for multi-window and multi-task interactions, and keyboard and mouse operations. It fully showcases the device productivity. In HarmonyOS documentation, "2-in-1" refers to "PC/2-in-1 device".

#### S

## **SDK**

Software Development Kit (SDK), a collection of development tools and open capabilities used to build applications.

## **Service widget**

Service widgets are used to present important information about user applications, allowing users to access desired services instantly via shortcut gestures.

## **Stage model**

An application development model introduced from HarmonyOS 3.1 Developer Preview onwards. It provides two types of components: UIAbility and ExtensionAbility. The model name comes from the unique classes provided by this development model, such as **AbilityStage** and **WindowStage**.

## **Super Virtual Device**

Also called Super Device. It integrates the capabilities of multiple devices through the distributed technology into a virtual hardware resource pool and then centrally manages and schedules these capabilities based on application requirements.

## **System suggested hop**

A system suggested hop refers to the hop operation triggered through a system suggestion. When another device is available on the same network to provide better experience for the user of the application, the system automatically recommends this device for the user. The user can determine whether to start the hop.

#### U

## **UIAbility**

A component in the stage model used to provide UI capabilities to interact with users.

## **UX**

User experience (UX), the complete experience a user has before, during, and after using a product or system.
