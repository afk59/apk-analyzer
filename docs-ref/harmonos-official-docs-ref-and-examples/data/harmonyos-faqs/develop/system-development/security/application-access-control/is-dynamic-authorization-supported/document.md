# Is dynamic authorization supported?

Permissions can be classified into system\_grant permissions and user\_grant permissions.

-   During application installation, the system automatically grants permissions based on the application declaration. In this case, it does not involve dynamic authorization.
-   When an app is running, a pop-up window is sent to the user for dynamic authorization.

For more information, see [Authorization Mode](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/app-permission-mgmt-overview#authorization-mode).
