# How do I store important data such as private keys?

You can use APIs to import the private key to HUKS for management. The imported key can be used only in a secure environment (such as TEE), which improves security. You can also use the asset store service to protect important data. For details, see [Asset Store Kit](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/asset-store-kit).
