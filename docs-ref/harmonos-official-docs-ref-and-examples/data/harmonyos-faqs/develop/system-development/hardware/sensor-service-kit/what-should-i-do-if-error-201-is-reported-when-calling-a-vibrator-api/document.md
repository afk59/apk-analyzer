# What should I do if error 201 is reported when calling a vibrator API?

**Symptom**

Error 201 is reported if an error occurs when calling an API of the vibrator module. The error message is as follows:

"vibrate fail, error.code: 201 error.message: NaN"

**Solution**

Permission verification failed. You must apply for the **ohos.permission.VIBRATE** permission.

**Reference**

[Application Permission Management Overview](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/app-permission-mgmt-overview)
