# How do I obtain the API version numbers supported by a device?

You can query the version number through the deviceInfo module. The following methods can be used to obtain the version number:

-   **deviceInfo.sdkApiVersion**: SDK API version
-   **deviceInfo.firstApiVersion**: first API version
-   **deviceInfo.distributionOSApiVersion**: API version of the distribution OS
