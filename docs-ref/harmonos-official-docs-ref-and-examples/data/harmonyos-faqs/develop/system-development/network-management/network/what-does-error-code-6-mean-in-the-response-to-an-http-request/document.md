# What does error code 6 mean in the response to an HTTP request?

Error code 6 indicates that the host name cannot be resolved. Ping the URL in the request, and check whether the ping is successful.

The HTTP error code mapping is in the format of 2300000 + Curl error code. For more common error codes, see [libcurl Error Codes](https://curl.se/libcurl/c/libcurl-errors.html).
