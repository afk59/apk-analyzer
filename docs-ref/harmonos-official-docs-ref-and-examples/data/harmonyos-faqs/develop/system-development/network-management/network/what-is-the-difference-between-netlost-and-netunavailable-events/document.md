# What is the difference between netLost and netUnavailable events?

The [on('netLost')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-net-connection#onnetlost) event indicates a network loss, for example, Wi-Fi or mobile network disconnected.

The [on('netUnavailable')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-net-connection#onnetunavailable) event indicates that the network is not accessible after a network connection is successfully established. For example, an exclamation mark (!) on the Wi-Fi icon indicates that the Wi-Fi network is not accessible.
