# How do I send SMS messages?

You can use the SMS service to implement SMS sending functions for your application. When sending an SMS message, the application sends a request to the server, and the server calls [sms.sendShortMessage](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-sms#smssendshortmessage10) to send the SMS message.

**Reference**

[@ohos.telephony.sms (SMS)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-sms)
