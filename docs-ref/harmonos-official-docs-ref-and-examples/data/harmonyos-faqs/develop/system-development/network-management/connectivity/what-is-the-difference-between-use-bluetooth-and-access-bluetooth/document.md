# What is the difference between USE\_BLUETOOTH and ACCESS\_BLUETOOTH?

-   **USE\_BLUETOOTH**: This permission is used by deprecated APIs in API versions 7 to 9. It allows an application to view the Bluetooth configuration, such as the Bluetooth name, Bluetooth device type, and whether Bluetooth is enabled.
-   **ACCESS\_BLUETOOTH**: This permission is used by APIs in API version 10 or later. It allows an application to access Bluetooth functionalities, such as device pairing and connection as well as Bluetooth Low Energy (BLE) advertising and scanning.
