# How do I apply a blur effect to a component?

You can apply a blur effect to a component by setting the component's **backdropBlur**, **blur**, **backgroundBlurStyle**, and **foregroundBlurStyle** attributes.

**Reference**

[Image Effects](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-image-effect), [Foreground Blur](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-foreground-blur-style)
