# How do I disable the split-screen mode?

During development, you can set the **fullscreen** field in the **supportWindowMode** attribute of the [abilities](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/module-configuration-file#abilities) tag in the **module.json5** file. After setting, the application forcibly runs in full screen mode and cannot enter the split-screen mode.
