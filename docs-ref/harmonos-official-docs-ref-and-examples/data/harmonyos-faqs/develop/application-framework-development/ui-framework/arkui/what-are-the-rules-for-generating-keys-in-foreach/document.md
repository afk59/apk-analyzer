# What are the rules for generating keys in ForEach?

The generation rules for keys in **ForEach** are related to **itemGenerator** and **keyGenerator**:

-   If the **keyGenerator** function is not specified, the framework will automatically generate the key. The default rule combines the item and index as a string, using the following formula: (item: any, index: number)=>{ return index +'\_'+ JSON.stringify(item); }
-   If a custom **keyGenerator** is provided but does not include **index**, and if the **itemGenerator** includes **index**, the key will be generated by concatenating the custom value with the index. For example, the key created for **(item) => item + 2** is **index+'\_'+(item+2)**. If the **itemGenerator** does not includes **index**, the key will be generated according to the custom rule.
-   If a custom **keyGenerator** is provided and includes **index**, regardless of whether the **itemGenerator** includes **index**, the key will be generated according to the custom rule.
