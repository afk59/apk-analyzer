# How do I set the background color for the XComponent component?

When the **XComponentType** of the **XComponent** component is **TEXTURE**, you can use the universal attributes for setting the background color. When the **XComponentType** is **SURFACE**, you need to use the APIs provided by EGL/OpenGL ES or child components for styling.
