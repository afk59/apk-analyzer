# What is the difference between struct and class?

In the ArkUI framework, **struct** is only used within custom components. The custom component instance formed by **struct** decorated by @Component has different type features from the instance generated by class. To pass components as parameters between other components, use [custom placeholder nodes](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-user-defined-place-holder).
