# How do I obtain the attribute information of a component?

You can obtain all attribute information of a component with the specified ID through [getInspectorByKey](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-component-id#getinspectorbykey9).

**Reference**

[Component ID](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-component-id)
