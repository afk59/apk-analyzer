# How do I implement a mixed text and image layout?

1.  Lightweight mixed text and image layout: Nest [Span](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-span) and [ImageSpan](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-imagespan) child components in the [Text](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-text) component. For details, see [Example 1: Setting the Alignment Mode](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-imagespan#example-1-setting-the-alignment-mode) in **ImageSpan**.
2.  Rich mixed text and image layout with interactive text editing: Use the [RichEditor](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-richeditor) component, add text content through [addTextSpan()](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-richeditor#addtextspan), and add image content through [addImageSpan()](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-richeditor#addimagespan). For details, see [Example 1: Updating the Text Style](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-richeditor#example-1-updating-the-text-style) in **RichEditor**.
