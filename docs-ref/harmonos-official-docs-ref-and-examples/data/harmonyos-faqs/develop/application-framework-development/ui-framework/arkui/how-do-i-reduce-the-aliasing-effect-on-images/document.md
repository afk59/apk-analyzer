# How do I reduce the aliasing effect on images?

**Solution**

Aliasing may occur when **ImageInterpolation.None** is set for the **Image** component. Therefore, you can set **interpolation** to **High**, **Medium**, or **Low** to reduce aliasing.

[ImageInterpolation](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image#imageinterpolation)
