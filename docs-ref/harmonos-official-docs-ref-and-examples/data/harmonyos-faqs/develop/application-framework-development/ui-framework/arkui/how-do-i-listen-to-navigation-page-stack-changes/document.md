# How do I listen to Navigation page stack changes?

You can call the [uiObserver.on('navDestinationSwitch')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-arkui-observer#uiobserveronnavdestinationswitch12-1) method to listen to Navigation page switch events, including typical scenarios such as page access statistics and page lifecycle management.
