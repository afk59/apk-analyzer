# What are the differences between the Flex component and W3C's flexbox?

In the W3C standard, the default size of a **Flex** component on the main axis is determined by the child components. However, the default value of **align-items** in the **Flex** is **stretch**, which means that child **Flex** items fill the main axis of the parent **Flex** container when the parent does not have **align-items** set. When **align-items** of the parent container is set to values other than **stretch**, the size of the child **Flex** items on the main axis is determined by their own child components.

Unlike the W3C standard, in ArkTS, the default size of the **Flex** component on the main axis is determined by the parent component, meaning that it fills the parent component in the main axis direction by default. Therefore, the **alignItems** attribute does not affect the main axis size of the **Flex** component unless the main axis size is explicitly set. Moreover, the default value of the **alignItems** attribute of the **Flex** component is **ItemAlign.Start**, so after setting **ItemAlign.Start**, the **Flex** component will still fill the parent component on the main axis.
