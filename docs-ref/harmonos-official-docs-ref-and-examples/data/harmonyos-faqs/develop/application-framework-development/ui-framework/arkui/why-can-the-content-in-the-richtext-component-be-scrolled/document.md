# Why can the content in the RichText component be scrolled?

The **RichText** component is implemented using **WebView** at its core. Therefore, it follows the same behavior principles as a browser. If the content inside the **RichText** component exceeds the visible area, it will trigger scrolling behavior, just as it would in a browser.
