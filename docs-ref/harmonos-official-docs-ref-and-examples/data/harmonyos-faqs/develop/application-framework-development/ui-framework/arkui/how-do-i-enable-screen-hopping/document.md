# How do I enable Screen Hopping?

On PCs/2-in-1 devices running HarmonyOS 4.0 Canary2, the AssociateAssistant application is provided by default for testing the Screen Hopping feature. You can use this application to use Screen Hopping by following the following steps:

1.  Log in to the same HUAWEI ID on the two devices.
2.  Enable WLAN and Bluetooth.
3.  In the application list, enable AssociateAssistant Ensure that Screen Hopping is enabled on both devices.
4.  After it is enabled, the device search status page will be displayed on the application screen.
5.  If the icons of both devices are displayed on the AssociateAssistant application page, the networking is successful and the devices go online properly. If the networking fails, restart WLAN or Bluetooth on the devices and try again.
6.  After the networking is successful, move the cursor to the screen edge of one device to initiate a link establishment request. An animation is displayed for the first link establishment request. If you see the cursor on the target device, Screen Hopping is working correctly.
