# How do I take a screenshot and obtain the screenshot content?

There are two screenshot modes: UI component screenshot and window screenshot.

For details about the UI component snapshot, see [@ohos.arkui.componentSnapshot (Component Snapshot)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-arkui-componentsnapshot).

For details about the window screenshot, see [snapshot](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-window-window#snapshot9).
