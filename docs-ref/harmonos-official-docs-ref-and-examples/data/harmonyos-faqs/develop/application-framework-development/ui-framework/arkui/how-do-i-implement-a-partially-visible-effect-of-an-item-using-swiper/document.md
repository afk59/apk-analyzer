# How do I implement a partially visible effect of an item using Swiper?

You can use the [nextMargin](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-container-swiper#nextmargin10) parameter to control the visible area of adjacent items. For details, see [Setting the Navigation Indicator Interaction and Page Turning Effect](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-container-swiper#example-1-setting-the-navigation-indicator-interaction-and-page-turning-effect).
