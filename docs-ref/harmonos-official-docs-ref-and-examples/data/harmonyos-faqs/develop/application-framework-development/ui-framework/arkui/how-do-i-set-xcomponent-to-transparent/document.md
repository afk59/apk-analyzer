# How do I set XComponent to transparent?

Set the related universal attributes for the **XComponent** to achieve the purpose. Note that the background, opacity, and image effect attributes are partially supported depending on the type. When the type is **TEXTURE**, the background color, opacity, and shadow (of image effects) attributes are supported. For configuration of other attributes, you are advised to use the APIs provided by EGL/OpenGL ES instead.
