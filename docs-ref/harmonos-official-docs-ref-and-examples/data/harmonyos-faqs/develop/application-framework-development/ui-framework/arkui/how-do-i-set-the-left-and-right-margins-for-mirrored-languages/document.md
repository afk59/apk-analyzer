# How do I set the left and right margins for mirrored languages?

[LocalizedMargin](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-types#localizedmargin12) and [LocalizedPadding](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-types#localizedpadding12) provide the mirrored language spacing types, which are used to set the outer margin and inner margin in different directions. In the RTL (from right to left) language environment, start/end is automatically mapped to right/left.
