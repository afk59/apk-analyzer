# How do I use the navPathStack parameter of Navigation?

After obtaining the NavDestination collection through **navPathStack**, you can use the following method to query parameters:

-   Call [getParamByIndex](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-navigation#getparambyindex10) to obtain the parameter information of the **NavDestination** page specified by **index**.
-   Call [getParamByName](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-navigation#getparambyname10) to obtain the parameter information of all **NavDestination** pages with the specified name.

**Reference**

[NavPathStack](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-navigation#navpathstack10)
