# How do I use the onSubmit event of the TextInput component?

The [onSubmit](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-textinput#onsubmit) event is triggered when a user presses **Enter** on the (physical or soft) keyboard. The callback parameter in the event is the current Enter key type. The Enter key type can be set through the [enterKeyType](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-basic-components-textinput#enterkeytype) attribute of the **TextInput** component. Setting the key style of the soft keyboard requires support by the input method.
