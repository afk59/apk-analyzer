# How do I open a half-screen display through routing?

Use the **Navigation** component for all operations. For details, refer to the **NavDestinationMode.DIALOG** display mode. Dialog mode, where the navigation destination is transparent by default, and adding or removing the navigation destination from the routing stack does not affect the lifecycle of the lower-layer navigation destinations.

**Reference**

[Page Display Mode](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-navigation-navigation#page-display-mode)
