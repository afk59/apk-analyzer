# How do I upload a HAR under multiple accounts?

It is recommended that a HAR be uploaded by its original author. If you want to allow multiple accounts to upload a newly created package, configure the **name** field in the module-level **oh-package.json5** file with a value of the <@group>/<package> type, such as **"@hw-one/hhshs"**. Then, create an organization in the repository and add users to that organization for upload access.
