# How do I resolve dependency version conflicts?

If a dependency version conflict occurs, you can configure the [override](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-oh-package-json5#en-us_topic_0000001792256137_overrides) field in the project-level [oh-package.json5](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-oh-package-json5) file to unify the versions.
