# How do I access files in the rawfile Directory across HSPs?

**Solution**

To share resources between HSPs, you are advised to export the resources from the source HSP and import them into the target HSP.

**Reference**

[Exporting Resources from HSP](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/in-app-hsp#exporting-resources-from-hsp)
