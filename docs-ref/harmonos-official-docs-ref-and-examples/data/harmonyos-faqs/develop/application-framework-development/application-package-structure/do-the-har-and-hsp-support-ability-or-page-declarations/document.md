# Do the HAR and HSP support ability or page declarations?

Page support: Both the HAR and HSP support page declarations. However, pages in the HAR must be accessed using named routes. For details, see **Reference**. Ability support: The HAR and HSP do not support ability declarations. You are advised to configure abilities in HAPs.

**Reference**

[Named Route](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-routing#named-route)
