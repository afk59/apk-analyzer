# How do I save pixels as an image file?

**Question**

How do I save pixels as an image file?

**Answer**

1.  Use **packToData** to convert the image source into a JPEG file.
2.  Use the APIs provided by @ohos.file.fs to save the file to the sandbox directory.

**Reference**

[@ohos.multimedia.image (Image Processing)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-image), [@ohos.file.fs (File Management)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-file-fs)
