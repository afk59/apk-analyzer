# How do I store PixelMap data to a database?

Convert the PixelMap data into an **ArrayBuffer** and save it to the database by using the **readPixelsToBuffer()** method.

**Reference**

[readPixelsToBuffer](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-image-pixelmap#readpixelstobuffer7)
