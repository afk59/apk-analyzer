# Where is the database file stored?

**Question**

-   Where is data stored for the database created using ArkTS, that is, where is the **database.db** file?
-   What is the difference between an RDB store and lightweight data storage?

**Answer**

-   Store data in the database directory in the application sandbox.
-   For details about the difference between an RDB store and lightweight data storage, see the following reference.

**Reference**

[Application file directory and application file path](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/app-sandbox-directory#application-file-directory-and-application-file-path)

[Application Data Persistence Overview](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/app-data-persistence-overview)
