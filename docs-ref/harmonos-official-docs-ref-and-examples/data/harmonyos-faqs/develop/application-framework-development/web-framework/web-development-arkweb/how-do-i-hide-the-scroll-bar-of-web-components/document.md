# How do I hide the scroll bar of Web components?

Set the values of [horizontalScrollBarAccess](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-basic-components-web-attributes#horizontalscrollbaraccess9) and [verticalScrollBarAccess](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-basic-components-web-attributes#verticalscrollbaraccess9) to **false** to set the visibility of the horizontal and vertical scroll bars respectively.
