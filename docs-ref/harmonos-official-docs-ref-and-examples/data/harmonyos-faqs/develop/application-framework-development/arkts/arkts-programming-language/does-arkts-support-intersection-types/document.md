# Does ArkTS support intersection types?

Intersection types may cause performance degradation, making type inference complex and uncertain.

As such, ArkTS does not support intersection types. Inheritance can be used as an alternative.

[Recipe: Use Inheritance Instead of Intersection Types](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/typescript-to-arkts-migration-guide#section-types)
