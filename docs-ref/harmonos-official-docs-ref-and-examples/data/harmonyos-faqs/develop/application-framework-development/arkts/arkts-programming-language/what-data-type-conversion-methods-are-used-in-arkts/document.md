# What data type conversion methods are used in ArkTS?

ArkTS also supports built-in type conversion methods of JavaScript or TypeScript, such as **Number()**, **String()**, and **Boolean()**.

ArkTS supports the **as** type conversion of TS, but not type conversion using the **<>** operator. Currently, the **as** type conversion can be used during build, but not at runtime.
