# How do I convert the sendable type to JSON data?

You can use [ArkTSUtils.ASON](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-arkts-utils-ason) of ArkTS, which is supported since API version 12.

ASON allows you to parse JSON strings and generate data that can be passed across concurrency domains. It also supports conversion from sendable data into JSON strings.
