# What are the differences between ArkTS and TS files?

ArkTS is developed based on the TS syntax and is compatible with most TS features. ArkTS adds declarative UI capabilities, which allows you to develop high-performance applications in a more natural and intuitive manner. You are advised to use ArkTS to develop UIs and TS to develop service logic.
