# How do I use closures in ArkTS?

**Question**

Does ArkTS support closures in TypeScript?

**Answer**

ArkTS does not allow function declarations nested within other functions. Use the **lambda** function instead.

[Recipe: Nested Functions Are Not Supported](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/typescript-to-arkts-migration-guide#recipe-nested-functions-are-not-supported)
