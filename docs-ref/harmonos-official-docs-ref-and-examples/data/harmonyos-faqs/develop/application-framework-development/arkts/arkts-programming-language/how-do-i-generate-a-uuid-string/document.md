# How do I generate a UUID string?

You can use **generateRandomUUID** in the **util** class to generate a UUID of the string type.

let uuid = util.generateRandomUUID(true);
console.info("RFC 4122 Version 4 UUID:" + uuid); // Output randomly generated UUID
