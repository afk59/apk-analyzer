# How do I apply for multiple continuous tasks?

**Question**

If multiple tasks are running in the background, you need to request the same number of continuous tasks.

**Answer**

At a time, a UIAbility can request only one continuous task. To request continuous tasks of different types, you must create multiple UIAbility instances. At different time, a UIAbility can request different types of continuous tasks.
