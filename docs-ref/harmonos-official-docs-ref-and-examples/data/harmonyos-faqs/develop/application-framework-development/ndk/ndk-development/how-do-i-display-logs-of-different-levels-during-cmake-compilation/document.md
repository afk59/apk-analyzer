# How do I display logs of different levels during CMake compilation?

In the **hvigor/hvigor-config.json5** file, set the value of **level** in the **logging** field. The level can be **debug**, **info**, **warn**, or **error**. Then, in the **run** window, you can view the log information printed by the **message** method in the **CMakeLists.txt** file.
