# How do I listen for recordings?

Audio-related listening of the system is implemented in **AudioStreamManager**. You can call **on(type: 'audioCapturerChange', callback: Callback<AudioCapturerChangeInfoArray>): void** to listen for audio capturer changes. For details, see [on('audioCapturerChange')](https://developer.huawei.com/consumer/en/doc/harmonyos-references/arkts-apis-audio-audiostreammanager#onaudiocapturerchange9).
