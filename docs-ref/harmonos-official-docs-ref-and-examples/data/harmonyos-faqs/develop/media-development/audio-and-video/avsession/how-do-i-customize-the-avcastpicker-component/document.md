# How do I customize the AVCastPicker component?

The **AVCastPicker** component supports the following customization capabilities:

Default colors for icons, color changes upon selection, adaptation with light and dark mode, and customization of internal component elements

For details, see [Implementing a Custom Style](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-switch-call-devices#implementing-a-custom-style).
