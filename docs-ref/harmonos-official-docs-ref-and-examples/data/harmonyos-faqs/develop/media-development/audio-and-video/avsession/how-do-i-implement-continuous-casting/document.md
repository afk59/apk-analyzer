# How do I implement continuous casting?

When transitioning between different episodes of a TV series, including trailers and bonus content, an application should ensure a seamless experience by obtaining the playback URL for the next episode to continue casting without interruption. The application must prepare for the next episode in advance, either when it receives a callback indicating the end of the current content or detects that the playback progress is 5 seconds from the end, to maintain continuous casting.
