# Why are some buttons in the media controller grayed out and unclickable?

The media controller displays controllable elements on the UI based on the application's registration of specific control commands. Applications should register the commands they support to ensure that the UI elements are interactive. It is recommended that elements in the media controller be used for better experience.

[Registering Control Commands](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/avsession-access-scene#registering-control-commands)
