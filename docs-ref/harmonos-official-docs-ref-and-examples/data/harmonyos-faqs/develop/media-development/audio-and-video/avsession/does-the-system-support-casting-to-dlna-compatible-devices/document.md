# Does the system support casting to DLNA-compatible devices?

The system supports resource casting using the Cast+ and DLNA protocols. When creating an AVSession, the application can pass the protocol type to match the expected target device. For details, see step 2 "Set media resource information" in "How to Develop" in the reference document provided below.

**Reference**

[AVCastPicker Development](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/distributed-playback-guide)
