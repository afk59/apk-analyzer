# What should I do if the browser window cannot be displayed during DevEco Studio login authorization?

**Symptom**

When you log in to DevEco Studio or open the help document, the browser window is not displayed.

**Solution**

Perform the following operations to use another browser:

1.  Choose **Settings** > **Tools** > **Web Browsers and Preview** in the browser.
2.  As shown in the following figure, click the button in the red box to place Edge on the top. That is, set the default browser to an existing browser on the computer, such as Edge.
