# Can the same set of signing files be used by multiple people for debugging on different devices?

Yes. During the [manual signing](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-signing#section297715173233) process, add multiple devices when applying for a debug certificate and [requesting a debug profile](https://developer.huawei.com/consumer/en/doc/app/agc-help-add-debugprofile-0000001914423102). In this way, the same set of signing files can be used by multiple people for debugging on multiple devices.
