# What should I do if the Allow button is not displayed and browser does not redirect after entering a HUAWEI ID?

**Symptom**

After you enter an authenticated HUAWEI ID on the browser, the **Allow** button is not displayed and the browser does not redirect.

**Solution**

This issue is caused by a compatibility problem with the browser. It is recommended that you use the Chrome, Internet Explorer 11, or Safari browser which has been proofed to be compatible. You can set the default browser to one of them.

1.  Set or change the default browser.
    
    -   **Windows**: Take Windows 10 as an example. Choose **Control Panel** > **Programs** > **Default Programs** > **Set your default programs** to change or set the default browser.
    -   **macOS**: Take macOS 10.15 as an example. Choose **System Preferences** > **General** > **Default web browser** to change or set the default browser.
