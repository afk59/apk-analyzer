# What should I do if "FileTransfer Failed: \[Fail\]Transfer Stop at:XXX, Reason: no space left on device" is displayed during HAP installation on DevEco Studio?

**Symptom**

The error message "FileTransfer Failed: \[Fail\]Transfer Stop at:XXX, Reason: no space left on device" is displayed during HAP installation on DevEco Studio.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/EVHRkpLBReKcP_vIWw4ZBw/en-us_image_0000002356614812.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062624Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8A5B4D3FF27FC445831AAFF3F8B55967F5A57B8BFDF666242D60EE5D858B5965)

**Solution**

The device has insufficient disk space so that data cannot be written. Check the device disk space. If the Emulator is used, click **Wipe User Data** to clear the data, and then restart the Emulator.
