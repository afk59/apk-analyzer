# How do I use DevEco Studio to debug C/C++ code breakpoints?

**Symptom**

After a breakpoint is added to the C/C++ code in DevEco Studio, it does not work during debugging.

**Possible Causes**

The debug type is not set to **Dual (ArkTS/JS + Native)**.

**Solution**

Choose **Run/Debug Configurations** > **Debugger**, and set **Debug type** to **Dual (ArkTS/JS + Native)**.
