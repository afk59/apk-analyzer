# What should I do if the error message "hap path error" is displayed during application running?

**Symptom**

When an application is run or debugged, it crashes and the error message "errorMsg:hap path error" is displayed.

**Solution**

The dependency package may not be installed. Choose **Run/Debug Configurations** > **Deploy Multi Hap****/Hsp**, select **Deploy Multi Hap/Hsp Packages**, select the dependency package, and run the application again.
