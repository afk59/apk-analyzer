**Solution**

The cause of the crash in the network unit test case is **container\_overflow**. This check item has a high number of false positives, and it is currently disabled through an environment variable. The test case did not set the corresponding ASan environment variable, which triggered this check and led to a false positive. To solve this issue, set the ASan environment variable when running the test case. Add the following two commands to the Linux script being executed:

sh
export ASAN\_OPTIONS=detect\_container\_overflows=0
