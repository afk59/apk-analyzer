# How do I automatically format modified code when committing in DevEco Studio?

In the project directory, right-click the file or folder you want to commit and choose **Git** > **Commit File** from the shortcut menu. In the displayed **Commit Changes** window, select **Reformat code** to automatically format the code you are committing.
