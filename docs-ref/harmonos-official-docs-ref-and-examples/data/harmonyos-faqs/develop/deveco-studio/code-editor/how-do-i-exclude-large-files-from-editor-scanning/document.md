# How do I exclude large files from editor scanning?

**Question**

When a project contains large source files, such as files with over 100,000 lines of code generated by tools like protobuf, the editor consumes significant system memory when scanning these files. How can the editor be configured to ignore files above a certain size, for which code editing features are not needed?

**Answer**

To exclude files larger than 10 MB (as an example), choose **Help** > **Edit Custom Properties** in DevEco Studio to open the **idea.properties** file, add **arkts.server.max.intellisense.filesize=10240** to the file, and restart DevEco Studio. The editor will now filter out files larger than 10 MB. The value of **arkts.server.max.intellisense.filesize** must be an integer greater than 0.
