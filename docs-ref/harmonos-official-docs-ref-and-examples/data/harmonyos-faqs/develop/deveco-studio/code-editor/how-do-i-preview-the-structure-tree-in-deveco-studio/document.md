# How do I preview the structure tree in DevEco Studio?

DevEco Studio provides a [code structure tree](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-editer-overview#section388152319329). You can press **Alt+7** or **Ctrl+F12** (**Command+7** on macOS) to open the code structure tree, or choose **View** > **Tool Windows** > **Structure** to quickly view the structure tree of file code, including global variables, functions, class member variables, and methods, and navigate to the corresponding code line.
