# Does DevEco Studio provide a feature to check for unreferenced resources in one click?

Yes. Choose **Code** > **Analyze Code** > **Run Inspection by Name** or press **Ctrl+Alt+Shift+I** and enter **Unused resources** to check for unreferenced resources.
