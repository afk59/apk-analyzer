# How do I set up DevEco Studio to automatically add header comments and copyright notices when creating new .ets files?

Perform the following steps:

1\. Choose **File** > **Settings** > **Editor** > **File and Code Templates**.

2\. On the **Files** tab in the right pane, select **ArkTS File**.

3\. Add header comments and copyright notices.
