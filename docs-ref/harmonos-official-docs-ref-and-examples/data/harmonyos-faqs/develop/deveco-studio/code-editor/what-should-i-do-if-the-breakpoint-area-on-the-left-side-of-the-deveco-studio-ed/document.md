# What should I do if the breakpoint area on the left side of the DevEco Studio editor disappears?

Choose **Main Menu** > **File** > **Settings** > **Editor** > **General** > **Gutter Icons** and select **Show gutter icons** to solve this problem. The following figure shows the details.
