# What should I do if the server fails to be started and the process exits unexpectedly?

**Symptom**

During the server startup, the server exits unexpectedly, and the following dialog box is displayed:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/ZHINs935S_Cr3bYQL_qJ0w/en-us_image_0000002446289578.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062616Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F8AE854E52F5FC6018CE17FD5B034D51D35E16BC9FC016D2034DF18FB55430E2)

**Solution**

1\. Clear the cache and restart DevEco Studio.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/PKg1XdALQimdPjtixw7XDA/en-us_image_0000002446449442.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062616Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=480F7745D65CB813D18B7C699DE46B2E72CE488D297D2F6E1F2E910279773552)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/XyLc6FlqQm-3XWWBooZkGA/en-us_image_0000002479769241.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062616Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=824B0CF59564E1591F6F04C9C82E93339106D3F858C32F5B8FC8C525DF6EBB8C)

2\. Collect logs and [Submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/7?level2=101747979797569375) on HUAWEI Developers.
