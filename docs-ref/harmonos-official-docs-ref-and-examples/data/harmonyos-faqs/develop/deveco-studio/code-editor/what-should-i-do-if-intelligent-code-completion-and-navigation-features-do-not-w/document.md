# What should I do if intelligent code completion and navigation features do not work?

**Symptom**

The intelligent code completion and navigation features do not work in DevEco Studio.

**Solution**

-   Scenario 1: The directory where the project file is located contains Chinese characters. Move the project file to a directory that contains only English letters, and then open the project again.
-   Scenario 2: The power saving mode is enabled. You need to disable it. You can uncheck **File** > **Power Save Mode** above DevEco to disable the power saving mode. After unchecking the option, as shown in the figure below, it indicates that power saving mode is disabled.
