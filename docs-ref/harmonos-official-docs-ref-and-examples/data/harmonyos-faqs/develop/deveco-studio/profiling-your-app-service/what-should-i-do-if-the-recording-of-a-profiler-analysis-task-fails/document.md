# What should I do if the recording of a Profiler analysis task fails?

**Symptom**

After the start recording button in the Profiler is clicked for an insight analysis task, the recording fails.

-   DevEco Studio displays an error message to indicate that the task startup or recording failed.

-   An exception icon is displayed for the corresponding task in the session list.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/Jh8ACyG7TJ27rCuEWc2N4w/en-us_image_0000002194318540.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062624Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=CCD30F598A69C2BC81CCB135F72871894AEADAF341201D7C0011EAFE4E4F8801)
    

**Solution**

An insight analysis task goes through three phases: initializing, recording, and data analyzing. The issue may arise during any of these stages, including connection termination, plugin errors, and abnormal device status.

To solve this issue, perform the following steps:

1.  Ensure that the device screen is always on.

2.  Push the package to the device again or restart the application or service.
3.  Restart the device.
4.  Restart DevEco Studio.
