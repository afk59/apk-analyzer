# What should I do if an exception occurs when I enable lane recording for a wearable device using DevEco Profiler?

**Symptom**

When DevEco Profiler is used to analyze the performance of an application on a wearable device, the application may be closed unexpectedly and recording may be abnormal if multiple lanes are recorded at the same time when the memory of the wearable device is small.

**Solution**

It is recommended that you keep the screen on and record a single lane of the application on your wearable device.
