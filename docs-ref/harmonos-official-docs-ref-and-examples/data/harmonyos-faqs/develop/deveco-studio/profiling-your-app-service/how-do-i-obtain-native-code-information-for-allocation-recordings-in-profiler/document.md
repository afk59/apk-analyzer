# How do I obtain native code information for Allocation recordings in Profiler?

**Solution**

Choose **Run** > **Edit Configurations** > **Diagnostics**, disable **Address Sanitizer**, **Thread Sanitizer**, and **Hardware-Assisted Address Sanitizer**, and start a new recording.
