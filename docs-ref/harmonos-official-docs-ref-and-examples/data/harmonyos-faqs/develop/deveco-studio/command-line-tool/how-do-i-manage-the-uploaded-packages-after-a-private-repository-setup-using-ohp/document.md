# How do I manage the uploaded packages after a private repository setup using ohpm-repo?

1.  Choose **HomePage** > **PersonalCenter** > **Repository manage** to edit the repository.
2.  Manage the uplink and its proxy configurations, upload third-party packages, and view the list of third-party packages in the private repository.
