# How do I check for the HAR version conflicts in a project?

Run the **ohpm install --all** command to view the reserved information.

You can view the installed third-party libraries using [ohpm list](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-ohpm-list). To resolve dependency version conflicts, you can use the **overrides** field to manage the version or refer to [Dependency Version Conflicts of a Module](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-ohpmrc#section1623415477574).
