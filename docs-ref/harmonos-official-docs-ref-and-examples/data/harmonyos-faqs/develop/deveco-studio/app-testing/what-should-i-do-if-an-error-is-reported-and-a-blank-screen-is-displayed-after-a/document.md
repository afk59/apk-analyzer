# What should I do if an error is reported and a blank screen is displayed after a UI test case times out?

**Symptom**

When a UI test case times out, a blank screen appears, and the error message "Tests failed" is displayed.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/N2IflZVSQI-AkHnQ1kRMHQ/en-us_image_0000002229758661.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062624Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F4A3F698AD1EF6ECBBE5C7A67D2FD4D8DAD88D8612F6A0A409AF515B89DECFF8)

**Solution**

When running a UI test case, keep the device always on.
