# What should I do if "The system-image file is missing." is reported when the Emulator is started?

**Symptom**

The Emulator fails to be started, and the message "The system-image file is missing." is displayed.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/tNb_Zr7xQEG1NF8SeOHGaw/en-us_image_0000002229758805.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B2C630E3C81660A0AE8B2F4199FAC849874892E1119D83D87963E2002842C0CC "Click to enlarge")

**Solution**

Use either of the following methods to solve the problem:

-   Choose **Tools** > **Device Manager** on the menu bar. On the **Local Emulator** tab page, click **New Emulator** in the lower-right corner. On the virtual device configuration page, update the Emulator image files.
-   Delete the created Emulator and create a new one.
