# How do I increase the Emulator RAM?

**Symptom**

The default RAM of the Emulator is 4 GB. When the emulator RAM is insufficient, the emulator may freeze or crash.

**Solution**

You are advised to increase the RAM size when creating an emulator. For details, see [Creating an Emulator](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-emulator-create).
