# What should I do if the divider is not clear or displayed in the Settings of the Emulator or the List component?

**Symptom**

When **strokeWidth** of the divider of the **List** component is set to **0.25 vp** or not an integral multiple, the resolution of the Emulator cannot display the divider with a fine line width.

**Solution**

Use a real device to display the divider or increase the value of **strokeWidth**.
