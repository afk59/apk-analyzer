# What should I do if the real-name authentication is required after login?

**Symptom**

To use the local Emulator, you need to sign in with a developer account that has completed real-name authentication. If the account has not been authenticated, the local Emulator will remind you to complete real-name authentication.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/zeLcQhJSS0u-tSdyUSfH-w/en-us_image_0000002194158868.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C801C76442785A2026CE574DD590297AE4CC893E54D5D6CBD367D1F859863BD8 "Click to enlarge")

**Solution**

The possible causes are as follows:

-   If you haven't performed real-name authentication, perform the following steps.
-   If your real-name authentication result has not taken effect yet, perform step 4 to clear the browser cookies and try again.

1.  Click **Verify Identity** to go to HUAWEI Developers for real-name authentication.
2.  Perform real-name authentication as prompted. For details, see [Identity Verification](https://developer.huawei.com/consumer/en/doc/start/ibca-0000001062388135). Individual developers can perform authentication using their bank card or ID card.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/Unn8zF0WQsigCM6ls4tnJg/en-us_image_0000002194318476.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6B2CFE13CE82D0FC56681BE2D643F9DC3FB2A10FD165787000E0777E96FE36AD "Click to enlarge")
    
3.  After the authentication is complete, click the profile picture in the upper-right corner of the DevEco Studio UI, click **Sign out**, and log in to DevEco Studio again.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/Cb0MttPHS0CBFDfaBSMXqA/en-us_image_0000002194318480.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2871275F806E6A6C863781ADFC7DE62003B58E420353D35E40ABC776B49A2FAE)
    
4.  (Optional) If the system still prompts you to perform real-name authentication after you have done it, clear the browser **Cookie** (by pressing **Ctrl+Shift+Del**) and try again.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/ERY5kUYnTf2y1GCGNqYuKg/en-us_image_0000002229604249.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9656079BE04809CA62027CD62C900E8ABE395E34AC3D9139945613D2C5333148 "Click to enlarge")
