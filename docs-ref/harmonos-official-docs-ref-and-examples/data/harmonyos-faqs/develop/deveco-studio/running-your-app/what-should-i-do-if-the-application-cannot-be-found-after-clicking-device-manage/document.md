# What should I do if the application cannot be found after clicking Device Manager?

**Symptom**

When you click **Device Manager** to perform login authorization, a message is displayed, indicating that the program cannot be found. As a result, you cannot open the browser to log in.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/Pu9xw3DcSPmFYydRsfJLZg/en-us_image_0000002229604305.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062622Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=52D80435C930DC63BFDF9862E595FF30E97130CA058761A6EA0ABE821967214D)

**Solution**

The default browser is damaged or uninstalled, and therefore cannot be opened.

You can reset the default browser and log in again. For details, see [What should I do if the allow button is not displayed and browser does not redirect after entering a HUAWEI ID?](../../signing-service/what-should-i-do-if-the-allow-button-is-not-displayed-and-browser-does-not-redir/document.md)
