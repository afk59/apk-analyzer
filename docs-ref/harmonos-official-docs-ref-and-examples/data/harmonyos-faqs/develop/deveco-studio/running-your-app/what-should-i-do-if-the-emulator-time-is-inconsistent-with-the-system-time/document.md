# What should I do if the Emulator time is inconsistent with the system time?

**Symptom**

After the Emulator runs for a period of time, the displayed time may be different from the current system time.

**Solution**

Enable automatic time synchronization in **Settings**. The time will be automatically updated when the network is connected. You can also manually set the time. The time will be synchronized after the Emulator is restarted.
