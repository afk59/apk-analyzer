# What are restrictions on using third-party C/C++ libraries on the Windows x86 Emulator?

The x86 Emulator supports the debugging and running of x86 C/C++ third-party libraries. For non-x86 third-party libraries, see [tpc\_c\_cplusplus](https://gitcode.com/openharmony-sig/tpc_c_cplusplus).
