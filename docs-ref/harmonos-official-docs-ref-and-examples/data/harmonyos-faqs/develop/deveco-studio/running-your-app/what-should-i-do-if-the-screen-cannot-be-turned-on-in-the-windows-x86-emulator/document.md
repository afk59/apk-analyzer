# What should I do if the screen cannot be turned on in the Windows x86 Emulator?

**Symptom**

When the Windows x86 Emulator is started for the first time after DevEco Studio is updated, the Emulator screen cannot be turned on.

**Solution**

Clear the user data and restart the Emulator. For details, see [Starting and Stopping the Emulator](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-emulator-start-and-close).
