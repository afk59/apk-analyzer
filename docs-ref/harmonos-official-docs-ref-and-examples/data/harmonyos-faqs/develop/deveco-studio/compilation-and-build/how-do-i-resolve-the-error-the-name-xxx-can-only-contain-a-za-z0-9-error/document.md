# How do I resolve the "Error: the name 'XXX' can only contain \[a-zA-Z0-9\_\]" error?

**Symptom**

The error message "Error: the name 'XXX' can only contain \[a-zA-Z0-9\_\]" is displayed during compilation.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/AWxRq3EsSBCnEL2m1YA6Jg/en-us_image_0000002194158636.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=8DCD738AD3FC2C6325ACF296A0BE3F14C0FF5FAF30B2ABD1E8258D076BCBB42E)

**Solution**

Check whether the file name contains characters other than letters, digits, and underscores (\_).
