# How do I resolve the "module.json5 file not found." error?

**Symptom**

The **module.json5** file could not be found.

**Possible Causes**

The module directory does not contain the **module.json5** file.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/3kwk9-sySUWNm6EFREXKJQ/en-us_image_0000002229604093.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062620Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=CF67F9CC98263B493F3E7C2E493C3274223474A36F021BF11E5E822971D00705)

**Solution**

For a project developed in the stage model, make sure each module directory contains the **module.json5** file.
