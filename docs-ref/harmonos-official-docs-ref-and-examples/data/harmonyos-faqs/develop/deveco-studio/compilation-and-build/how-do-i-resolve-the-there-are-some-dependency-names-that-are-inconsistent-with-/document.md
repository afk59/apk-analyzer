# How do I resolve the "There are some dependency names that are inconsistent with the actual package names." error?

**Symptom**

The dependency name does not match the package name.

**Possible Causes**

The specified dependency name does not match the name defined in the **oh-package.json5** file of the corresponding dependency package.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/ew5X-4UPT2yY_p7UQeX0Fg/en-us_image_0000002229758445.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062620Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=A3D71CDE75E60A9ED2ACFC2875FFCB8F165B57969B8B55C47040DFE3E56670B1)

**Solution**

Change the dependency name to match the name defined in the **oh-package.json5** file of the corresponding dependency package.
