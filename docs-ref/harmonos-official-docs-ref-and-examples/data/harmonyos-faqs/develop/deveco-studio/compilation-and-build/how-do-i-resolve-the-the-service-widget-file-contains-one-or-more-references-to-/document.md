# How do I resolve the "The service widget file contains one or more references to HSPs" error?

**Symptom**

The "The service widget file contains one or more references to HSPs" error is reported during compilation.

**Possible Causes**

The service widget file contains one or more references to HSPs.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/-LeuRQPrRfaD30d-AsN2tw/en-us_image_0000002229758293.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B48A15E30E585A2504E3513B72C7F51631996361B3B6031D2CF6D130601B4392)

**Solution**

Delete all the references to HSPs from the service widget file.
