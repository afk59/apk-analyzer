# How do I build a debug or release version without modifying build-profile.json5 file?

1.  When you build a project in the **Build** window, **Build Hap(s)** is set to **debug** mode and **Build App(s)** is set to **release** mode by default. You can also select the debug or release mode as required.
2.  You can select the build mode in DevEco Studio. The selected mode overrides the default mode.
