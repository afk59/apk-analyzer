# How do I resolve the "debug is different" build error?

**Symptom**

When an application is packaged, the message "debug is different" is displayed.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/gP_mr3WMR3itolMNzU2jaQ/en-us_image_0000002229758605.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=787B0F043E1267EB4748B17822596C3E8365789BD5094D5D3A9A4BA13AE4289A)

**Solution**

Based on the module names indicated in the warning message, check whether the **debug** field is consistent between modules, especially between local modules and externally referenced modules.

1\. The **debug** field is automatically generated by the compilation and build tool and saved in the **module.json** file of the HAP/HSP, as shown in the figure below. Make sure the field is consistent across all modules.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/955uyIJsQPmLZ6JLX_I23g/en-us_image_0000002229604117.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=464DE5A83C472673DBFFC20CB5C86A990242A97F09FB9321546D873B7980E7B7)

2\. Set **Build Mode**, based on which the compilation and build tool generates the **debug** flag.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/G9LcmAxSTHiCCoMFrR-Zfg/en-us_image_0000002194318344.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=72F704A736E97CE8405144C4ABBC47C6336F924BD2A386812ABDE8F74FEC1FB4)
