# How do I sign a new module online?

Procedure:

1.  [Connect a real device to DevEco Studio](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-run-device). The figure below shows the UI when DevEco Studio is connected to a device.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/Mnfd7iF6TOmqedE47-PFTQ/en-us_image_0000002229604037.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062617Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F001A93D90A9EF2F3FC6B09B9DD26B4621C3C5C80D6A849AE8D35FC670288CDB)
    
2.  Choose **File** > **Project Structure...** > **Project** > **Signing Configs** and select **Automatically generate signature**. If your project is a HarmonyOS project, also select **Support HarmonyOS**. If you have not logged in, click **Sign In** to complete signing.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/-txicN9bRlalT4tuMuCUBw/en-us_image_0000002229758513.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062617Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=CD4AC226B366E93306922A7A4BCF5DEDF07B3B6963AEAB1F74F85B4BB5C0EF7A "Click to enlarge")
    
    After signing is complete, the page shown below is displayed.
    
    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/8Ytdc5JQT9eYk7yd30ly7w/en-us_image_0000002194318264.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062617Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=598DCA46B06349755B9F9F3332E8530DF0BCFDF808C43EFCE455786FAD736B5F "Click to enlarge")
