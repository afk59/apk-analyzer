# How do I resolve the "arkts-no-any-unknown" and "Cannot find module 'xx' or its corresponding type declarations" errors?

**Symptom**

The error messages "arkts-no-any-unknown" and "Cannot find module 'xx' or its corresponding type declarations" are displayed during compilation.

**Possible Causes**

The module could not be found due to case sensitivity. This issue often occurs when both types of errors appear in images. It only occurs on Linux, not on Windows or macOS.
