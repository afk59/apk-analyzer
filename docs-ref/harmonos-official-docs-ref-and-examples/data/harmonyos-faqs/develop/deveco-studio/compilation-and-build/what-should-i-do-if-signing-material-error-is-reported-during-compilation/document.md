# What should I do if "Signing material error" is reported during compilation?

**Symptom**

DevEco Studio compilation fails and the error is reported as follows.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/EdOqnFzPQKWg-biw95EUjg/en-us_image_0000002229604197.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062617Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=2AFB5624146897446D7DEBA78CF21163EDCC7B1E8A9644E926BB523CABA7E44D "Click to enlarge")

**Solution**

Delete the metafile in the **.hvigor** directory in drive C, and then sign and compile the file again.
