# How do I resolve the "The inferred type of 'xxx' cannot be named without a reference to 'xxx'. This is likely not portable. A type annotation is necessary." error?

**Symptom**

The error message "The inferred type of 'xxx' cannot be named without a reference to 'xxx'. This is likely not portable. A type annotation is necessary" is displayed during compilation.

**Possible Causes**

The .d.ts declaration file generated by the HSP does not contain type annotations because the types are not specified in the original file.

**Solution**

Add type annotations at the location where the error occurs.
