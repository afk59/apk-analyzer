# How do I resolve the "Local dependency in parameterFile does not exist." error?

**Symptom**

The "Local dependency in parameterFile does not exist." error is reported during compilation.

**Possible Causes**

The path specified for **parameterFile** does not exist.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/o4hMNfOQQoOJfjkYoS_N0g/en-us_image_0000002194318024.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062620Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=248A78BEAEFD2E2F78B155ABA0F265AF75EE6F516F36F0DEE011339B2B8EB56C)

**Solution**

Make sure the path specified for **parameterFile** exists and its case matches the actual file path.
