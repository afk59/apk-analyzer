# How do I resolve the "input module releaseType is different" build error?

**Symptom**

When an App Pack is packaged, if the error message "input module releaseType is different" is displayed, check whether the release types of the input modules are the same.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/_z3h8ZRUTvGPSVhxdWVprw/en-us_image_0000002194318432.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062619Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=F2DC9314EBE9215DA827A30892EA0735045AC8C6D2759EA76147DA7E6DF2FB3E)

**Solution**

Based on the module names indicated in the warning message, check whether the **apiReleaseType** field is consistent between the modules.

The **apiReleaseType** field is automatically generated by the compilation and build tool and is saved in the **module.json** file of the HAP/HSP. Make sure the field is consistent across all modules. If there is an inconsistency, you need to repackage each module of the application with the same version of the SDK, and then package the App Pack.
