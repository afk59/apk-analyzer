# What should I do if "no such file or directory, realpath 'xxx'" is reported during compilation?

**Symptom**

The error "no such file or directory, realpath 'xxx'" is reported during compilation in DevEco Studio.![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/nfZVVSn-TPOmGOYIyKjMrQ/en-us_image_0000002229758637.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062618Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=DEC65797B501D8CE27D6DF37E733951F9EE8973BF94DABEB172E2C797D99790E)

**Solution**

"no such file or directory" is a common error message, indicating that the specified file or directory cannot be found in the current project. The possible causes are as follows:

1.  The path where the error is reported does not exist.
2.  The file or directory is incorrect, including the file name, directory name, and letter case.
3.  The project does not have required permissions to access the file or directory.
