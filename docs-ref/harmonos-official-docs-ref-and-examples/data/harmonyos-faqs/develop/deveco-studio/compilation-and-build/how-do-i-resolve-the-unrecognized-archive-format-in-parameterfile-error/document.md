# How do I resolve the "Unrecognized archive format in parameterFile" error?

**Symptom**

The "Unrecognized archive format in parameterFile" error is reported during compilation.

**Possible Causes**

The local dependencies configured using **parameterFile** are neither directories nor .har or .tgz files.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/spOSuVaLRfilGyt8h53b5A/en-us_image_0000002194318392.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062620Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=928F5F1E0699FC8A14E67E4389B9962B3DECB714CFBFE5F623E6833659479C65)

**Solution**

Update the local dependencies to module directories or .har or .tgz files.
