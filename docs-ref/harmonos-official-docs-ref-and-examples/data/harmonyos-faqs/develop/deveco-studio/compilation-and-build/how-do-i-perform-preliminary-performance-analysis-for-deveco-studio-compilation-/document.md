# How do I perform preliminary performance analysis for DevEco Studio compilation and build?

Build Analyzer can visualize important information in the compilation and building process for you to analyze and check performance issues.

After application build is complete, you can open the **Build Analyzer** window in any of the following ways:

-   On the toolbar at the bottom, click the **Build Analyzer** window.
-   Click ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/XN2ttfw2TzmH51QWzNnR4g/en-us_image_0000002229758897.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062618Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=1450B8FAD256015F56CAE0AA33678701622C51C632E5A1C1723F735A623A1F04) in the left pane to open the **Build Analyzer** window.
-   When you open **Build Analyzer** for the first time after the build is complete, the build analysis overview is displayed, as shown in the following figure.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/2q5uLwyoQhuhJuor9OlBVg/en-us_image_0000002229604409.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062618Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E4ABD223C7A29C52E1DFA840F1B2CFCAF562EC1B5BC89D07B29791F99FB10E84 "Click to enlarge")

To view the build task timeline graph, choose **Tasks** from the drop-down list box. The build history, build task timeline graph, build logs, and log details are displayed in different blocks on the page, as shown in the following figure.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/u7hiLTRiRV-uYFVnVGuNzQ/en-us_image_0000002194159012.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062618Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=500C9814D4B2BBCE671BD1E40D5B26DE70D2C279BDA46FF6AD78D6CE1EE2A577 "Click to enlarge")
