# What should I do if an error is reported when the signature is generating?

**Symptom**

An error is reported when the signature is generating.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/RuS4phXQTpiY6DWIfguNxw/en-us_image_0000002229604377.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062618Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=997DC6D088E3857DA08686642DB1E0EC39DDF65A7D0EA49505025DDAE5C6334B)**Solution**

You can delete the local **material** directory from the signature file path corresponding to the **profile** file (\*.p7b) or **Certpath** file (\*.cer) provided on the signing page and restart DevEco Studio for signing.
