# How do I set the pixel values for the Previewer in DevEco Studio?

**Symptom**

The Previewer in DevEco Studio currently supports phone, PC/2-in-1, and foldable devices, but it does not intuitively display the screen width and height in pixel values for these devices.

**Solution**

You can use the **New Profile** feature in the Previewer, which allows you to set the screen size and DPI.
