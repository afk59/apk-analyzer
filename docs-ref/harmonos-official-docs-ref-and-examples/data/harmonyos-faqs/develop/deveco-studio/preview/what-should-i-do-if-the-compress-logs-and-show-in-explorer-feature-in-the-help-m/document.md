# What should I do if the Compress Logs and Show in Explorer feature in the Help menu does not work during preview?

**Symptom**

When multiple projects are opened and previewed at a time, using **Compress Logs and Show in Explorer** in the **Help** menu may fail because certain logs are in use.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/ftuIb2p0R--AKqMAqmdGyA/en-us_image_0000002229603945.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062616Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=0F5C8A724B9B596205569E42C9687B87A5B847BCB45D7E6041825685C7A592AA)

In such cases, an error message is displayed in the lower right corner, as shown in the following figure.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/P1N5S4sXQVu9nQZGnj-h0g/en-us_image_0000002229758417.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062616Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=01CCB9F523A384BD0C77AAA515A45F330E5AEAB9707A7301C5A2E18E65F1EFBE)

**Solution**

Close the previewed projects, or restart DevEco Studio and do not open the Previewer. Then compress logs again.
