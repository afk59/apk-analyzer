# What should I do if "No app with the specified package name is found under the team." is displayed during software package upload?

**Symptom**

What should I do if "No app with the specified package name is found under the team." is displayed on the page for uploading a software package?

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/1OUIr4HSSzS_tNQAyz8bOw/en-us_image_0000002541844403.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062625Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=C1F0797675DACC0DE762A99A2D10C8B0F663E5793353C42A56EA743E7E3211B0)

**Solution**

This is because the current account does not have an application with the corresponding package name in AppGallery Connect. Log in to AppGallery Connect using the current account, create an application, and then open the page for uploading the software package again.
