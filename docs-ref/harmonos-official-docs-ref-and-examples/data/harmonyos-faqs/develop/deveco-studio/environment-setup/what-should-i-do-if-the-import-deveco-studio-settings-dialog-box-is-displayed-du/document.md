# What should I do if the "Import DevEco Studio Settings" dialog box is displayed during runtime?

**Symptom**

This issue may occur in the following scenarios:

Scenario 1: The **Import DevEco Studio Settings** dialog box is displayed when DevEco Studio is running for the first time.

Scenario 2: After the DevEco Studio cache is cleared on the local host, the **Import DevEco Studio Settings** dialog box may be displayed when you download, install, and run the DevEco Studio again.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e0/v3/8yLX8UPvRIywadluE-eBgQ/en-us_image_0000002474225988.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062615Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=12A7155C76A3948E7386394C05E87A671CA1D911AD88AF559401874D561E0C2A)

**Solution**

Solution 1: Retain the default option **Do not import settings**.

Solution 2: Select **Config or installation directory** and upload the configuration package (settings.zip).

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/LTNfWoD-QryRlSx5jHtZ_Q/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062615Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=3BDED61772BCE7E1517766850F6FA9D14297E8A8EDAE7C867E6DF1D7B162B3EE)

-   Click **File** > **Manage IDE Settings** > **Export Settings...** to export the configuration items, including the Ark plugin. You can import the configuration items when running the DevEco Studio again.
-   The configuration items that can be exported vary according to the DevEco Studio version.
