# How do I configure the currently opened file to be automatically highlighted in the project directory?

**Question**

When a file is opened, it would be convenient if the editor could automatically highlight the file's location in the project directory on the left. How can this be achieved?

**Answer**

Click **Select Opened File** in the upper right corner of the project directory. The currently opened file is then automatically highlighted in the project directory.
