# How do I use the ArkTS code template in DevEco Studio?

Using code templates during the development process can improve development efficiency. In DevEco Studio, you can view existing supported code templates under **File** > **Settings** > **Editor** > **Live Templates** and also add custom templates.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/bMnCXd6DSFKVrxmL4RHzWA/en-us_image_0000002194318448.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062615Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=52262364D9BD3C4B16FFF360BDD7305E62CC7353AB958B50C6869290643A2AA3 "Click to enlarge")

Click the expand button to view the details of the existing templates, and click the plus sign in the upper right corner to add a custom template.

    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/C77T0GIlThuLOpVsaQMoAw/en-us_image_0000002229604229.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062615Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6687327B21CFA144D061D1741ACEF76FB97EF91F3CC5727539AD84DD81531C16 "Click to enlarge")
