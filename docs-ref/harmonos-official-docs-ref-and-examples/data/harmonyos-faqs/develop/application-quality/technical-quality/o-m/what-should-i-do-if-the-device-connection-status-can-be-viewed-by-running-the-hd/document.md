# What should I do if the device connection status can be viewed by running the hdc shell command, but the DevEco Studio connection status flickers and shows no device?

The DevEco Studio tool cannot identify the device. Please see [What should I do if the device cannot be identified](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/hdc#what-should-i-do-if-the-device-cannot-be-identified), or run the **hdc kill -r** command to restart the hdc and try again.
