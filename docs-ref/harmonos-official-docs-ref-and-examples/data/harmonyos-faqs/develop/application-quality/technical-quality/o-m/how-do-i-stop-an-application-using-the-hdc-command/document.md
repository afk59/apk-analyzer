# How do I stop an application using the hdc command?

Run the following command to stop an application:

hdc shell aa force-stop <Bundle Name>

If the message "force stop process successfully" is displayed, the application is stopped successfully.

Refer to the sample code below.

hdc shell aa force-stop com.example.myapplication
