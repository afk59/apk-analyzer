# What should I do if there are three devices that cannot be identified in a single device manager?

**Symptom**

When a single device is connected, three additional devices are displayed and cannot be identified.

**Possible Causes**

The driver is incompatible or damaged.

**Solution**

1.  Use Zadig to install the driver as a **WinUsb Device**. For details, see [What should I do if a device cannot be identified by hdc?](../../../../deveco-studio/debugging-your-app/what-should-i-do-if-running-the-hdc-list-targets-command-results-in-empty-after-/document.md)
