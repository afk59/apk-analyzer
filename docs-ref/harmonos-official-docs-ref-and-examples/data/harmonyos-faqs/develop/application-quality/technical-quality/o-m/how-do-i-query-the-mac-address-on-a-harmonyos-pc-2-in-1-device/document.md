# How do I query the MAC address on a HarmonyOS PC/2-in-1 device?

**Symptom**

When the option for querying the MAC address is not found in **Settings** or **About**, the following steps can be performed:

1\. Open **Settings** on your device.

2\. Go to **About device** or **About phone**.

3\. Click **Status**.

4\. Find **WLAN MAC address** or **Bluetooth address**.

If the MAC address cannot be found, refer to the user manual of the device or contact the customer service of the device manufacturer.

**Solution**

The MAC address cannot be directly viewed in a HarmonyOS PC/2-in-1 device. You need to run the **hdc shell ifconfig** command to obtain the MAC address.
