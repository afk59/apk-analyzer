# What are the common hdc commands for exporting and importing files?

**hdc file recv**: exports a file from the mobile phone.

**hdc file send**: imports a file to the computer.

**hdc list targets**: obtains the connected mobile phones.

**hdc shell power-shell setmode 602**: sets the screen of the phone to steady on.

**ps -ef|grep com.huawei.hmos.ouccom.ohos.updateapp**: checks the OUC process.

**ps -ef|grep updater\_sa command**: checks the DUE process.
