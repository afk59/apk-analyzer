# What should I do if "FreeChannelContinue handle->data is nullptr" is displayed after a command is executed in hdc?

Logs in earlier versions are not properly printed. The log printing level has been corrected in later versions. Upgrade the hdc tool to 3.1.0a or later by referring to the [hdc Commands](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/hdc#hdc-commands).
