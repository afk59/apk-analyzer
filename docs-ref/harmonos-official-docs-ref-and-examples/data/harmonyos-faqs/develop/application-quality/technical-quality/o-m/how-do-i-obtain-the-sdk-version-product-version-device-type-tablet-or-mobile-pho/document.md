# How do I obtain the SDK version, product version, device type (tablet or mobile phone), and build version of a device?

Use the **deviceInfo** module of **@kit.BasicServicesKit** to obtain the information about the device where the application is located.

-   **deviceInfo.sdkApiVersion**: indicates the SDK version.
-   **deviceInfo.displayVersion**: indicates the product version.
-   **deviceInfo.deviceType**: indicates the device type (tablet or mobile phone).
-   **deviceInfo.buildVersion**: indicates the build version.

For details, see [@ohos.deviceInfo (Device Information)](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-device-info).
