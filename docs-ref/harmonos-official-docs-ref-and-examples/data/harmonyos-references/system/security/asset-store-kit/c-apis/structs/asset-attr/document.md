# Asset\_Attr

#### Overview

Defines an asset attribute, which consists of a tag and a value in the form of a key-value (KV) pair.

**Since**: 11

**Related module**: [AssetType](../../modules/assettype/document.md)

**Header file:** [asset\_type.h](../../header-files/asset-type-h/document.md)

#### Summary

#### \[h2\]Member Variables

| Name | Description |
| :-- | :-- |
| uint32\_t tag | Name of the asset attribute. The tag (the key in the KV pair) uniquely identifies an attribute. |
| [Asset\_Value](../asset-value/document.md) value | Defines the value of the asset attribute. |
