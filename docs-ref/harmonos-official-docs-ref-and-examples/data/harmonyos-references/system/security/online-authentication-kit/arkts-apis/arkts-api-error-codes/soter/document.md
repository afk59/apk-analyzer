# SOTER

#### 401 Invalid Input Parameter

**Message**

Parameter error.

**Description**

This error code is reported when the input parameter does not meet the requirements.

**Possible causes**

1\. An input parameter is not specified.

2\. Input parameter verification fails.

**Solution**

1\. Check whether the value of **KeyType** is valid.

2\. Check whether the length of input parameters is valid.

#### 801 Device Type Error

**Message**

Device type error.

**Description**

This error code is reported when the device type does not support Online Authentication Kit.

**Possible causes**

The device type is emulator.

**Solution**

Use a device of a supported type.

#### 1014500001 Abnormal Service

**Message**

The service is abnormal.

**Description**

This error code is reported when the SOTER service is abnormal.

**Possible causes**

The SOTER service is abnormal.

**Solution**

1\. Check the network connection.

2\. Restart the system.
