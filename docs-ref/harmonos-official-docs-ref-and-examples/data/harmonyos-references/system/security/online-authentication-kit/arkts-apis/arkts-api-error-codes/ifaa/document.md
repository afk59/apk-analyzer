# IFAA

#### 401 Invalid Input Parameter

**Message**

Parameter error.

**Description**

This error code is reported when the input parameter does not meet the requirements.

**Possible causes**

The input parameter does not meet the requirements.

**Solution**

1\. Check whether the input parameter is empty.

#### 801 Device Type Error

**Message**

Device type error.

**Description**

This error code is reported when the device type does not support Online Authentication Kit.

**Possible causes**

The device type is emulator.

**Solution**

Use a device of a supported type.

#### 1006100001 System Interruption

**Message**

System Interruption.

**Description**

This error code is reported when the system is interrupted.

**Possible causes**

The running environment is abnormal.

**Solution**

1\. Restart the system.

2\. Try your operation again.

#### 1006100002 Abnormal Service

**Message**

The service is abnormal.

**Description**

This error code is reported when the IFAA service is abnormal.

**Possible causes**

The IFAA service is abnormal.

**Solution**

1\. Try your operation again.

2\. Restart the system and try again.
