# SuperPrivacyMode

#### 1006200001 General Error

**Message**

general error.

**Symptom**

A general error occurred in the Super Privacy API.

**Possible causes**

During a Super Privacy API call, an error occurred when a system API is called.

**Solution**

Try again first. If the retry fails, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/) for assistance.

#### 1006200002 Internal Error

**Message**

internal error.

**Symptom**

An internal error occurred in the Super Privacy API.

**Possible causes**

An internal error occurred in Super Privacy mode, leading to data reading failure.

**Solution**

Try again first. If the retry fails, [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/) for assistance.

#### 1006200005 Super Privacy Mode Not Supported by the Device

**Message**

not support super privacy.

**Symptom**

The current device does not support the Super Privacy mode.

**Possible causes**

The current device does not support this function.

**Solution**

Use this mode on a device that supports this function. For details, please refer to [Restrictions](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/devicesecurity-getsuperprivacymode#section19314125019324) in the development guide.
