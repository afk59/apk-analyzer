#### Enum Description

#### \[h2\]CryptoSymCipher\_ParamsType

enum CryptoSymCipher\_ParamsType

**Description**

Enumerates the types of symmetric encryption and decryption parameters.

**Since**: 12

| Enum Item | Description |
| :-- | :-- |
| CRYPTO\_IV\_DATABLOB = 100 | Parameters such as **iv**. |
| CRYPTO\_AAD\_DATABLOB = 101 | Additional authentication data in GCM mode. |
| CRYPTO\_TAG\_DATABLOB = 102 | Output tag of the encryption operation, which is used for integrity check. |
