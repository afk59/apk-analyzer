# UsbDDK

#### Overview

Provides USB DDK APIs to open and close USB interfaces, perform non-isochronous and isochronous data transfer over USB pipes, and implement control transfer and interrupt transfer, etc.

**System capability**: SystemCapability.Driver.USB.Extension

**Since**: 10

#### Files

| Name | Description |
| :-- | :-- |
| [usb\_ddk\_api.h](../../header-files/usb-ddk-api-h/document.md) | Declares the USB DDK APIs used by the USB host to access USB devices. |
| [usb\_ddk\_types.h](../../header-files/usb-ddk-types-h/document.md) | Provides the enumerated variables, structures, and macros used in USB DDK APIs. |
