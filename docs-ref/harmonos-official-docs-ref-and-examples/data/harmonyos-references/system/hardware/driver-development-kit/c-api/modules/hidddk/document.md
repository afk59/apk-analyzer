# HidDdk

#### Overview

Provides HID driver development kit (DDK) functions, including those for creating a device, sending events to a device, and destroying a device.

**System capability**: SystemCapability.Driver.HID.Extension

**Since**: 11

#### Files

| Name | Description |
| :-- | :-- |
| [hid\_ddk\_api.h](../../header-files/hid-ddk-api-h/document.md) | Declares the HID DDK functions for accessing an input device from the host. |
| [hid\_ddk\_types.h](../../header-files/hid-ddk-types-h/document.md) | Defines the enum variables and structs used in the HID DDK. |
