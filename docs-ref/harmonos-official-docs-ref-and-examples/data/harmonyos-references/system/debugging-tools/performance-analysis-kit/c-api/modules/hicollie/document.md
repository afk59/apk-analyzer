# HiCollie

#### Overview

Provides the APIs for detecting service thread jank and stuck events. The following capabilities are supported:

(1) Register a periodic detection task for application service thread stuck events.

(2) Register a callback for the detection of application service thread jank events.

(3) Report application service thread stuck events.
