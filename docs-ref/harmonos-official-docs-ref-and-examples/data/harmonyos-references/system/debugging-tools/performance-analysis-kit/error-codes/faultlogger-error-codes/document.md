#### 10600001 Service Faulty or Not Started

**Error Message**

The service is not started or is faulty.

**Description**

This error code is reported when the service is not started or an unknown error occurs.

**Possible Causes**

The hiview service is not started.

**Procedure**

Retry the operation.
