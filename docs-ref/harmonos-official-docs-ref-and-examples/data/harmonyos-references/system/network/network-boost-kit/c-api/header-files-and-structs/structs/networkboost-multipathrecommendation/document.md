# NetworkBoost\_MultiPathRecommendation

#### Overview

Defines multi-network concurrency suggestion information, which is used to notify about multi-network concurrency suggestion changes after the multi-network concurrency suggestion change event callback is registered.

**Start version**: 6.0.2(22)

**Related module**: [NetworkBoost](../../../modules/networkboost/document.md)
