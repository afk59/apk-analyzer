# GSNode (3DGS Rendering Object)

The **GSNode** class is inherited from [Node](../../../../arkgraphics-3d/arkts-apis/graphics3d/scenenode/document.md#node). It represents a 3D Gaussian Splatting (3DGS) rendering object, helping you operate 3DGS models.

**System capability**: SystemCapability.Graphics.SpatialRender

**Start version**: 6.0.1(21)

#### Modules to Import

import { spatialRender } from '@kit.SpatialReconKit';

#### Instruction

GSNode is equivalent to [Node](../../../../arkgraphics-3d/arkts-apis/graphics3d/scenenode/document.md#node). For details about the usage, please refer to [Node](../../../../arkgraphics-3d/arkts-apis/graphics3d/scenenode/document.md#node).
