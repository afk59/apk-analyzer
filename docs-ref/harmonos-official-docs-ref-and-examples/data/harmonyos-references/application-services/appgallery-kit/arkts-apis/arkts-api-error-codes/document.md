#### 1009300003 Identity Verification Error

**Message**

The identity check error.

**Description**

An error occurs during identity verification.

**Possible causes**

1\. The value of **sourceId** cannot be obtained during the registration of an attribution source.

2\. The value of **destinationId** cannot be obtained during the registration of a conversion event.

3\. The information about the ad ecosystem partner has not been registered on the cloud platform of the app attribution service, or the information has been deleted.

**Solution**

1\. Release relevant apps on AppGallery.

2\. Register information about the ad ecosystem partner on the cloud platform of the app attribution service.

#### 1009300004 Failed to Verify the Signature

**Message**

The sign check error.

**Description**

Failed to verify the signature.

**Possible causes**

1\. The character string used for generating a signature does not comply with the rule.

2\. The public key does not match the private key.

3\. The value of **signature** contains more than 800 characters.

**Solution**

1\. Check whether the character string used for generating a signature complies with the rule.

2\. Check whether the public and private keys match.

3\. Check the value length of the **signature** parameter.

#### 1009300115 Too Much Data Set for Postback in adTechId

**Message**

Too many postbacks setting to the testing environment.

**Description**

Too much data is set in **adTechId** for postback.

**Possible causes**

1\. The overload protection check is activated when the API for setting attribution postback is called, and the number of data records that need to be posted back for debugging purposes in a single **adTechId** exceeds 5.

2\. The number of records to be posted back exceeds 100.

**Solution**

1\. For a single **adTechId**, the number of **postbackInfo** records to be posted back for debugging purposes should not exceed 5.

2\. Limit the number of records for postback to a maximum of 100.
