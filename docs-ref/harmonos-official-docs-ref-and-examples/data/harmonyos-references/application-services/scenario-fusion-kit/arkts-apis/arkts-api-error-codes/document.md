#### 1009601001 Invalid Business Account ID

**Message**

Invalid service account id.

**Description**

Invalid business account ID.

**Possible causes**

1.The input business account ID is incorrect or has expired.

2.The business account is in frozen state.

**Solution**

Ensure that the input business account ID is correct and the business account is in effective state.

#### 1009601002 User Has Not Signed In to HUAWEI ID

**Message**

The user has not logged in with HUAWEI ID.

**Description**

The user has not signed in with their HUAWEI ID.

**Possible causes**

The user has not signed in with their HUAWEI ID.

**Solution**

Ensure that the user has signed in with their HUAWEI ID.

#### 1009601003 Request Failed to Be Sent to Business Touch Cloud

**Message**

Request server failed.

**Description**

Failed to send the request to Business Touch Cloud.

**Possible causes**

An error occurred on the Business Touch Cloud side.

**Solution**

Try again or [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/).

#### 1009601004 Unable to Connect to the Network

**Message**

Network connection error.

**Description**

Network connection failed.

**Possible causes**

The mobile network is not connected, or another network exception occurred.

**Solution**

Check the network connection.

#### 1009601005 Other Exception

**Message**

Other error.

**Description**

An unknown exception occurred.

**Possible causes**

The system is abnormal or API calls are too frequent.

**Solution**

Try again or [submit a ticket online](https://developer.huawei.com/consumer/en/support/feedback/#/).
