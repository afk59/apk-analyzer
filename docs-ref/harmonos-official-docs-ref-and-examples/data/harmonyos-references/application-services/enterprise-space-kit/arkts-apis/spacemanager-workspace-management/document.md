# spaceManager (Workspace Management)

The spaceManager module provides unified workspace management capabilities, including creating a workspace, removing a workspace, and subscribing to a workspace event, satisfying enterprises' workspace management requirements and users' workspace usage needs.

**Start version**: 6.0.0(20)

#### Modules to Import

import { spaceManager } from '@kit.EnterpriseSpaceKit';
