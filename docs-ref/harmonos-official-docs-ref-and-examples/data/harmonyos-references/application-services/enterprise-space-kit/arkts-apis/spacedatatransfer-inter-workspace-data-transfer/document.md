# spaceDataTransfer (Inter-workspace Data Transfer)

This module provides the capabilities of delivering inter-workspace transfer policies as well as setting and obtaining review information for [MDM](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/mdm-kit) apps that focus on enterprise security control.

These capabilities are available only for enterprise security control-focused MDM apps that have obtained the required permissions.

**Start version**: 6.0.0(20)

#### Modules to Import

import { fileTransfer } from '@kit.EnterpriseSpaceKit';

#### policyPush

policyPush(policyContext: string): void

Configures a unidirectional or bidirectional inter-workspace transfer policy, to be specific, policy about whether data transfer is allowed between personal workspaces and enterprise workspaces.

**Required permission**: ohos.permission.ENTERPRISE\_FILE\_TRANSFER\_AUDIT\_POLICY\_MANAGEMENT or ohos.permission.FILE\_TRANSFER\_OPERATION

**System capability**: SystemCapability.EnterpriseSpace.SpaceDataTransfer

**Start version**: 6.0.0(20)

**Parameters**:

| 
Name

 | 

Type

 | 

Mandatory

 | 

Description

 |
| :-- | :-- | :-- | :-- |
| 

policyContext

 | 

string

 | 

Yes

 | 

Unidirectional or bidirectional inter-workspace transfer policy content. The value contains one level-1 node (**config**) and five level-2 nodes (**inEnable**, **incoming\_check**, **outEnable**, **outgoing\_check**, and **checkpoint\_config**). Each node handles a distinct function, collectively forming a complete policy configuration. The nodes are described as follows:

-   **inEnable**: indicates whether an enterprise workspace is allowed to receive files.
-   **incoming\_check**: check rule for data file transfer from a personal workspace to an enterprise workspace. The parameter value must be a string. Its usage will be detailed later.
-   **outEnable**: indicates whether an enterprise workspace is allowed to transfer files outbound.
-   **outgoing\_check**: check rule for data file transfer from an enterprise workspace to a personal workspace. The parameter value must be a string. Its usage will be detailed later.
-   **checkpoint\_config**: information about the check app, including the app bundle name, component name, parameters, and check function code. The parameter value must be a string. Its usage will be detailed later.
-   **approvalpoint\_config**: information about the review point, including the app bundle name and component name.

 |

**Details about level-2 nodes**

-   **inEnable**: indicates whether an enterprise workspace is allowed to receive files. The value **1** indicates yes and the value **0** indicates no.

-   **outEnable**: indicates whether an enterprise workspace is allowed to transfer files outbound. The value **1** indicates yes and the value **0** indicates no.
