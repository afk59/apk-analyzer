# AnimationFillMode

#### AnimationFillMode

Defines the post-animation state.

**Model restriction**: This API can be used only in the stage model.

**Atomic service API**: This API can be used in atomic services since API version 4.1.0(11).

**System capability**: SystemCapability.Map.Core

**Start version**: 4.1.0(11)

| 
Name

 | 

Value

 | 

Description

 |
| :-- | :-- | :-- |
| 

FORWARDS

 | 

0

 | 

Retains the final frame after the animation completes.

 |
| 

BACKWARDS

 | 

1

 | 

Reverts to the initial frame after the animation completes.

 |
