# AnimationRepeatMode

#### AnimationRepeatMode

Defines the animation replay mode.

**Model restriction**: This API can be used only in the stage model.

**Atomic service API**: This API can be used in atomic services since API version 4.1.0(11).

**System capability**: SystemCapability.Map.Core

**Start version**: 4.1.0(11)

| 
Name

 | 

Value

 | 

Description

 |
| :-- | :-- | :-- |
| 

RESTART

 | 

0

 | 

Restarts the animation from the beginning after it completes.

 |
| 

REVERSE

 | 

1

 | 

Plays the animation in reverse from the end after it completes.

 |
