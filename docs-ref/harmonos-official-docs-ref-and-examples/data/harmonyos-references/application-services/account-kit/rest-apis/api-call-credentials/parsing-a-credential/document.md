# Parsing a Credential

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/EKc7HKQWS1iAHS93nQW-SQ/caution_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062501Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=B6D454EE0C1AEF73DBE829E162C7EE205C17901FB6A22CD5F07022AE6469A501)

To ensure secure network access, use the TLS 1.2 protocol and the specified cipher suites. If your app server accesses Account Kit using TLS 1.0, TLS 1.1, or unsupported cipher suites, the connection may fail.

For details about TLS 1.2 and the specified cipher suites, see [TLS Protocol and Cipher Suites](../../common-description/document.md#section1329115361128).

#### Function

-   This API is used to authenticate the obtained access token.
-   This API also parses the access token through the Account Kit server to obtain the client ID, UnionID, OpenID, scope, and other information.

#### Scenario

The app has obtained an access token and needs to parse it to retrieve information such as the client ID, UnionID, OpenID, and scope.

#### Restrictions

Ensure that the network on the caller side is normal.

#### Sample Code

The Java sample code is as follows. Before running it, [configure the sample code environment](../../common-description/document.md#section444143185314). (Place this sample code and the **CallUtils** utility class in the same directory. If not, manually add the corresponding **import** statement to the sample code.)

import com.alibaba.fastjson2.JSONObject;
import lombok.extern.slf4j.Slf4j;
import org.apache.http.NameValuePair;
import org.apache.http.client.entity.UrlEncodedFormEntity;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.message.BasicNameValuePair;
import java.io.IOException;
import java.util.ArrayList;
import java.util.List;

/\*\*
 \* Parse a credential.
 \*/
@Slf4j
public class GetTokenInfoAPIDemo {
    public static void main(String\[\] args) throws IOException {
        // URL of the API for parsing credentials.
        String url
                = "https://oauth-api.cloud.huawei.com/rest.php?nsp\_fmt=JSON&nsp\_svc=huawei.oauth2.user.getTokenInfo";
        // Replace it with the access token of a user-level or app-level credential you obtained.
        String accessToken = "_<Access Token>_";
        JSONObject result = getClientTokenInfo(accessToken, url);
        // Parse the result to obtain type.
        Integer type = result.getInteger("type");
        // Parse the result to obtain scope.
        String scope = result.getString("scope");
        // Parse the result to obtain client\_id.
        String clientId = result.getString("client\_id");
        // Parse the result to obtain **expire\_in**.
        Integer expireIn = result.getInteger("expire\_in");
        // Parse the result to obtain **project\_id**.
        String projectId = result.getString("project\_id");
        // Parse the result to obtain **open\_id**.
        String openId = result.getString("open\_id");
        // Parse the result to obtain union\_id.
        String unionId = result.getString("union\_id");
    }

    private static JSONObject getClientTokenInfo(String accessToken, String url) throws IOException {
        HttpPost httpPost = new HttpPost(url);
        List<NameValuePair> request = new ArrayList<>();
        request.add(new BasicNameValuePair("access\_token", accessToken));
        request.add(new BasicNameValuePair("openid", "OPENID"));
        httpPost.setHeader("Content-Type", "application/x-www-form-urlencoded");
        httpPost.setEntity(new UrlEncodedFormEntity(request));
        // For custom exception handling, use api CallUtils#remoteCall(HttpUriRequest, BiFunction<CloseableHttpResponse,String,E>).
        return CallUtils.toJsonObject(CallUtils.remoteCall(httpPost));
    }
}
