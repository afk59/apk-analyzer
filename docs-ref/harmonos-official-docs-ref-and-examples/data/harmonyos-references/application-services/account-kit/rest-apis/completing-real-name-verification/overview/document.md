# Overview

Account Kit allows you to obtain and verify real-name information. Using its APIs, you can guide users through authorization, after which the app server can access or verify this information.

#### Use Cases

-   **Obtaining Real-Name Information**
    
    After user authorization is obtained, your app server calls the Account Kit server to obtain the real-name information associated with a HUAWEI ID.
    

-   **Verifying Real-Name Information**
    
    After user authorization is obtained, your app server calls the Account Kit server to verify the user's real-name information.
