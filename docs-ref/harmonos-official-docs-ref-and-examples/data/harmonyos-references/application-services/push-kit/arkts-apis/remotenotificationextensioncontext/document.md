# RemoteNotificationExtensionContext

**RemoteNotificationExtensionContext** is the context of [RemoteNotificationExtensionAbility](../remotenotificationextensionability/document.md), which inherits from [ExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/extensioncontext/document.md).

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Start version**: 4.1.0(11)

#### Module Import

import { RemoteNotificationExtensionContext } from '@kit.PushKit';

#### RemoteNotificationExtensionContext

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Device behavior differences**: For versions earlier than 5.1.0(18), this attribute is supported on phones, tablets, and PCs/2-in-1 devices, but does not work on other devices. For version 5.1.0(18) or later, this attribute is supported on phones, tablets, PCs/2-in-1 devices, and wearables, but does not work on other devices.

**Start version**: 4.1.0(11)

This class inherits from [ExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/extensioncontext/document.md) and no content is added.
