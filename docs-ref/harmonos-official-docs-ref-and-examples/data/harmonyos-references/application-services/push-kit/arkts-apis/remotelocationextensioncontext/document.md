# RemoteLocationExtensionContext

**RemoteLocationExtensionContext** is the context of [RemoteLocationExtensionAbility](../remotelocationextensionability/document.md), which inherits from [ExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/extensioncontext/document.md).

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Start version**: 4.1.0(11)

#### Module Import

import { RemoteLocationExtensionContext } from '@kit.PushKit';

#### RemoteLocationExtensionContext

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Device behavior differences**: This attribute is supported on phones, tablets, and PCs/2-in-1 devices, but does not work on other devices.

**Start version**: 4.1.0(11)

This class inherits from [ExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/extensioncontext/document.md) and no content is added.
