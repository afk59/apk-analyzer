# VoIPExtensionContext

**VoIPExtensionContext** is the context of **VoIPExtensionAbility**, which inherits from [UIExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/uiextensioncontext/document.md).

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Start version**: 4.1.0(11)

#### Module Import

import { VoIPExtensionContext } from '@kit.PushKit';

#### VoIPExtensionContext

**Model restriction**: The attributes can be used only in the stage model.

**System capability**: SystemCapability.Push.PushService

**Device behavior differences**: This attribute is supported on phones and tablets, but does not work on other devices.

**Start version**: 4.1.0(11)

This class inherits from [UIExtensionContext](../../../../application-framework/ability-kit/arkts-apis/dependent-elements-and-definitions/application/uiextensioncontext/document.md) and no content is added.
