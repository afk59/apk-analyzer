# Service Notification

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/nZpt5yB0RJ-eKTjEI5lHIg/notice_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062518Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=DB725571B6577478EB9AD1504C2303318F7F0CC50582F4815FA8880DBA7BA46F)

To ensure network security, the service notification API supports only TLS1.2 and later versions. Apps cannot use protocols earlier than TLS1.2 or unspecified cipher suites to send messages.

#### Function

This REST API is used by atomic services to deliver subscription messages.

#### Restrictions

-   The service notification capability is supported on phones and tablets.

-   The sending frequency control rule varies depending on the subscription type:
    -   One-time subscription: After a user's subscription, an atomic service can send the corresponding subscription message at any time.
    -   Long-term subscription: After a user's subscription, an atomic service can send multiple notifications within the subscription period and frequency specified in the template. (This is officially supported since HarmonyOS 6.0.)
-   Currently, this API does not support the message receipt function.

## 82500002 Failed to Obtain the Template

**Message**

Service notification msg send template get error.

**Description**

Failed to obtain the template.

**Possible causes**

The template ID in the request is incorrect. As a result, the corresponding template information cannot be found.

**Solution**

View template details and modify the template ID.

## 82500003 Invalid Project Information

**Message**

Service notification msg send project info error.

**Description**

The project information is invalid.

**Possible causes**

1.  No project information is found based on the project ID in the request URL.
2.  The app ID is in the blocklist.
3.  The service notification function is not enabled for the atomic service.

**Solution**

Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and verify the request parameters as prompted by the response.

1.  Verify that the project ID in the URL is correct.
2.  Verify that the app ID is not in the blocklist.
3.  Enable service notifications for the atomic service.

## 82500004 Risk Control Error

**Message**

Service notification msg send risk check error.

**Description**

Risk control error.

**Possible causes**

The template parameters contain prohibited parameters.

**Solution**

Verify that the template parameters do not contain prohibited parameters as prompted by the response.

## 82500005 Message Delivery Error

**Message**

Service notification msg send push error.

**Description**

Failed to deliver the message.

**Possible causes**

1.  The number of delivered messages exceeds the upper limit.
2.  The request body size exceeds the default value.
3.  The user has not subscribed to the message.
4.  Push Kit is not enabled for the atomic service.

**Solution**

Rectify the fault as follows:

1.  If the number of delivered messages exceeds the upper limit, initiate an account-based subscription request to increase the number of subscription times.
2.  If the request body size exceeds the default value, reduce the request body size and deliver the message again.
3.  If the user has not subscribed to the message, initiate an account-based subscription request.
4.  If Push Kit is not enabled for your atomic service, sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) and enable Push Kit.

## 82500006 OpenID Verification Failure

**Message**

Service notification msg send openId check error.

**Description**

OpenID failed the verification.

**Possible causes**

The OpenID of the recipient is incorrect.

**Solution**

Use the OpenID reported by the device or request the Account Kit server to [obtain the OpenID in user information](../../../account-kit/rest-apis/obtaining-user-information/document.md), and then send the message again.

## 82500007 Secondary Text Construction Error

**Message**

Service notification msg send subtitle build error.

**Description**

An error occurred when constructing the secondary text.

**Possible causes**

The carried parameters do not match the template parameters.

**Solution**

Verify the [template parameters](#section53501738161116) as prompted by the response.

## 82500008 Template Message Construction Error
