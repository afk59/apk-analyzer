# OHAVSession

#### Overview

The module defines the C APIs of the playback control module.

You can use OHAVSession to access AVSession as a provider. For details about the development guide and samples, see [AVSession Provider](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-ohavsession-developer).

**System capability**: SystemCapability.Multimedia.AVSession.Core

**Since**: 13
