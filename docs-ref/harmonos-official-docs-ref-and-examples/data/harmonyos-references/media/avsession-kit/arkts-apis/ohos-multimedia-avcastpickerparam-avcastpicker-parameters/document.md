# @ohos.multimedia.avCastPickerParam (AVCastPicker Parameters)

**avCastPickerParam** provides the enumerated values for the [@ohos.multimedia.avCastPicker](../../arkts-components/ohos-multimedia-avcastpicker-avcastpicker/document.md) component states.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/WmFBHuSYTxqCNR4C5UNEVQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062424Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6095BCE6223F07B63F18B92BD2B8C4C3928587450AA20ADD9CA8192D630607A5)

The initial APIs of this module are supported since API version 11. Newly added APIs will be marked with a superscript to indicate their earliest API version.

#### AVCastPickerState

Enumerates the states of the **AVCastPicker** component.

**Atomic service API**: This API can be used in atomic services since API version 12.

**System capability**: SystemCapability.Multimedia.AVSession.AVCast

| Name | Value | Description |
| :-- | :-- | :-- |
| STATE\_APPEARING | 0 | The component is displayed. |
| STATE\_DISAPPEARING | 1 | The component disappears. |

#### AVCastPickerStyle12+

Enumerates the styles of the **AVCastPicker** component.

**Atomic service API**: This API can be used in atomic services since API version 12.

**System capability**: SystemCapability.Multimedia.AVSession.AVCast

| Name | Value | Description |
| :-- | :-- | :-- |
| STYLE\_PANEL | 0 | Panel style. |
| STYLE\_MENU | 1 | Menu style. |

#### AVCastPickerColorMode12+

Enumerates the color modes of the **AVCastPicker** component.

**Atomic service API**: This API can be used in atomic services since API version 12.

**System capability**: SystemCapability.Multimedia.AVSession.AVCast

| Name | Value | Description |
| :-- | :-- | :-- |
| AUTO | 0 | Follows the system mode. |
| DARK | 1 | Dark mode. |
| LIGHT | 2 | Light mode. |
