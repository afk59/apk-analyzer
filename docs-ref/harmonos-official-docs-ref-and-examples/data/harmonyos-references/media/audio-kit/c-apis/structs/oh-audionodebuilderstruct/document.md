# OH\_AudioNodeBuilderStruct

typedef struct OH\_AudioNodeBuilderStruct OH\_AudioNodeBuilder

#### Overview

The struct describes a builder for nodes used in audio creation. It allows you to create an [OH\_AudioNode](../oh-audionodestruct/document.md) object, define the data formats for input and output nodes, and configures the callback interface for input nodes.
