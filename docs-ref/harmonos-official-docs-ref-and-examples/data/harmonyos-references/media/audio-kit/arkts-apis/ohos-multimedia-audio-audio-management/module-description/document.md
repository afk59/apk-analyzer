# Module Description

The module provides basic audio control capabilities, including volume adjustment, device management, data capture, and rendering.

This module provides the following common audio-related functions:

-   [AudioManager](../interface-audiomanager/document.md): audio manager.
-   [AudioRenderer](../interface-audiorenderer/document.md): audio renderer, used to play Pulse Code Modulation (PCM) audio data.
-   [AudioCapturer](../interface-audiocapturer/document.md): audio capturer, used to record PCM audio data.
