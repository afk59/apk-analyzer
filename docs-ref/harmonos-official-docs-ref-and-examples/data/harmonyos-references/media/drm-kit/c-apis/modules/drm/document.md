# Drm

#### Overview

The Digital Rights Management (DRM) module provides APIs for digital rights protection.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [DRM Development (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/drm-c-dev-guide)
-   [DRM Playback with AVCodec (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/drm-avcodec-integration)

**Since**: 11

#### Files

| Name | Description |
| :-- | :-- |
| [native\_drm\_common.h](../../header-files/native-drm-common-h/document.md) | Declares the DRM data types. |
| [native\_drm\_err.h](../../header-files/native-drm-err-h/document.md) | Declares the DRM error codes. |
| [native\_mediakeysession.h](../../header-files/native-mediakeysession-h/document.md) | 
Declares the MediaKeySession APIs.

The APIs can be used to generate media key requests, process responses to media key requests, listen for events, obtain content protection levels, check media key status, and remove media keys.

 |
| [native\_mediakeysystem.h](../../header-files/native-mediakeysystem-h/document.md) | 

Declares the MediaKeySystem APIs.

The APIs can be used to check the support for a DRM solution, create a media key session, obtain and set configurations, obtain DRM metrics, obtain the content protection level, generate media key system requests, process responses to media key system requests, listen for events, and manage offline media keys.

 |
