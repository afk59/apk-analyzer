# Module Description

The module provides APIs for album management, including creating an album and accessing and modifying media data in an album.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/BbmTuoQkRdGsZdYjsD8tVQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062442Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=6C36C86A0CE8D6E4465F39E6B2880117D67E3C26E98C3F7F1846B1CC6331C55C)

The initial APIs of this module are supported since API version 10. Newly added APIs will be marked with a superscript to indicate their earliest API version.
