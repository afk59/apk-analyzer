# MediaAssetManager

#### Overview

The module provides APIs for managing media assets.

For details about the development guide and sample, see [Requesting Media Assets Using MediaAssetManager (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-ndk-mediaassetmanager-for-request-resource).
