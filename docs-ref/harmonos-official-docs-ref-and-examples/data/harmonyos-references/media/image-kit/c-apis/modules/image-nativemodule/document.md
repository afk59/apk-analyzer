# Image\_NativeModule

#### Overview

The module provides image processing capabilities, including encoding and decoding an image and obtaining image data from the native layer.

The APIs of this module do not need to be imported through the JS interface. You can directly use the NDK to develop the features.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [Using Image\_NativeModule to Decode Images](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-source-c)
-   [Using Image\_NativeModule to Decode Pictures](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-source-picture-c)
-   [Using Image\_NativeModule to Receive Images](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-receiver-c)
-   [Using Image\_NativeModule for PixelMap Operations](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/pixelmap-c)
-   [Using Image\_NativeModule to Encode Images](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-packer-c)
-   [Using Image\_NativeModule to Encode Pictures](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-packer-picture-c)
