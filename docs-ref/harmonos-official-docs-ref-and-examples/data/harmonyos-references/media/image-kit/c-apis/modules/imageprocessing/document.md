# ImageProcessing

#### Overview

The ImageProcessing module provides the APIs for image processing, including Color Space Conversion (CSC) and metadata generation.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [Image Scaling](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-scaling)
-   [Image Dynamic Metadata Generation](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-dynamic-metadata-generation)
-   [Image Color Space Conversion](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-csc)
-   [Converting a Single-Layer HDR Image to a Dual-Layer Image](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/hdr-single-to-dual)
-   [Converting a Dual-Layer HDR Image to a Single-Layer Image](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/hdr-dual-to-single)
