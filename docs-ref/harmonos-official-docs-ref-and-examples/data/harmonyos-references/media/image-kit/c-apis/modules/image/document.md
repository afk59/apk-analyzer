# Image

#### Overview

The module enables access to image APIs.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [Image Decoding](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-decoding-native)
-   [Image Encoding](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-encoding-native)
-   [Image Transformation](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-transformation-native)
-   [PixelMap Operations](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-pixelmap-operation-native)
-   [Image Receiving](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/image-receiver-native)

**Since**: 8

#### Files

| Name | Description |
| :-- | :-- |
| [image\_mdk.h](../../header-files/image-mdk-h/document.md) | Declares the APIs used to access the image rectangle, size, format, and component data. |
| [image\_mdk\_common.h](../../header-files/image-mdk-common-h/document.md) | Declares the common enums and structs used by the image APIs. |
| [image\_packer\_mdk.h](../../header-files/image-packer-mdk-h/document.md) | Declares the APIs used to pack an image or a PixelMap into a buffer or file. |
| [image\_pixel\_map\_mdk.h](../../header-files/image-pixel-map-mdk-h/document.md) | Declares the APIs used to lock, access, and unlock a pixel map. |
| [image\_pixel\_map\_napi.h](../../header-files/image-pixel-map-napi-h/document.md) | Declares the APIs used to lock, access, and unlock a pixel map. |
| [image\_receiver\_mdk.h](../../header-files/image-receiver-mdk-h/document.md) | Declares the APIs used to obtain image data from the native layer. |
| [image\_source\_mdk.h](../../header-files/image-source-mdk-h/document.md) | Declares the APIs used to decode an image source into a PixelMap. |
