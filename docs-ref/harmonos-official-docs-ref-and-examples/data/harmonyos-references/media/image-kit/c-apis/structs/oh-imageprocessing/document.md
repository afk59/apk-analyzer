# OH\_ImageProcessing

typedef struct OH\_ImageProcessing OH\_ImageProcessing

#### Overview

The OH\_ImageProcessing struct provides its declaration.

To use it, first declare a null pointer of OH\_ImageProcessing, and then initialize it by calling [OH\_ImageProcessing\_Create](../../header-files/image-processing-h/document.md#oh_imageprocessing_create). This function creates an image processing instance. Multiple instances can be created for different image processing tasks.
