# OhosImageSourceDelayTimeList

struct OhosImageSourceDelayTimeList {...}

#### Overview

The struct describes the delay time list of an image source. The delay time list is obtained by calling [OH\_ImageSource\_GetDelayTime](../../header-files/image-source-mdk-h/document.md#oh_imagesource_getdelaytime).

**Since**: 10

**Related module**: [Image](../../modules/image/document.md)

**Header file**: [image\_source\_mdk.h](../../header-files/image-source-mdk-h/document.md)

#### Summary

#### \[h2\]Member Variables

| Name | Description |
| :-- | :-- |
| int32\_t\* delayTimeList | Pointer to the starting address of the image source delay time list. |
| size\_t size = 0 | Size of the image source delay time list. |
