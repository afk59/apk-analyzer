# OhosImageRegion

struct OhosImageRegion {...}

#### Overview

The struct describes the region of an image source to decode. It is a member variable of [OhosImageDecodingOps](../ohosimagedecodingops/document.md).

**Since**: 10

**Related module**: [Image](../../modules/image/document.md)

**Header file**: [image\_source\_mdk.h](../../header-files/image-source-mdk-h/document.md)
