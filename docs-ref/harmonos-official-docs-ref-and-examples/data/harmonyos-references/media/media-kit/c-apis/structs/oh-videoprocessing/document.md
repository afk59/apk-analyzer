# OH\_VideoProcessing

typedef struct OH\_VideoProcessing OH\_VideoProcessing

#### Overview

The struct describes an object for video processing.

You should define a null pointer for **OH\_VideoProcessing** and use [OH\_VideoProcessing\_Create](../../header-files/video-processing-h/document.md#oh_videoprocessing_create) to create a video processing instance. Before creation, ensure that the pointer is null. You can create different video processing instances with different processing types.
