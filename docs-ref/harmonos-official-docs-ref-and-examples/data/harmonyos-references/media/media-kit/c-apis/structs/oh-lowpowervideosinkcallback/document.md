# OH\_LowPowerVideoSinkCallback

typedef struct OH\_LowPowerVideoSinkCallback OH\_LowPowerVideoSinkCallback

#### Overview

The struct contains a set of callback function pointers for the LowPowerVideoSink.

To ensure the normal running of the LowPowerVideoSink, you must register the instance of this struct with the [OH\_LowPowerVideoSink](../oh-lowpowervideosink/document.md) instance and process the information reported by the callback functions.
