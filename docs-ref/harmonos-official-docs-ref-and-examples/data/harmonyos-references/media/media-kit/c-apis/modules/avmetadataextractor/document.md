# AVMetadataExtractor

#### Overview

The module provides the APIs for extracting metadata from media assets.

You can refer to the corresponding development guide and samples based on your development requirements: [Using AVMetadataExtractor to Obtain Metadata (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-ndk-avmetadataextractor-for-media).

**System capability**: SystemCapability.Multimedia.Media.AVMetadataExtractor

**Since**: 18
