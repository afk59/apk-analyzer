# AVRecorder

#### Overview

The module provides the APIs for requesting the recording capability.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [Using AVRecorder to Record Audio (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-ndk-avrecorder-for-audio-recording)
-   [Using AVRecorder to Record Videos (C/C++)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/using-ndk-avrecorder-for-video-recording)
