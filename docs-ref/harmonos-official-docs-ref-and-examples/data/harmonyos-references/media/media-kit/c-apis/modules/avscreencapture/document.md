# AVScreenCapture

The module provides APIs for screen capture.

You can refer to the corresponding development guide and samples based on your development requirements.

-   [Using AVScreenCapture to Capture Screens and Obtain Streams](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/avscreencapture-c-basic-process)
