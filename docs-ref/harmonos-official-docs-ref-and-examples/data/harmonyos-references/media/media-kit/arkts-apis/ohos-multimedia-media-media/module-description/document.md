# Module Description

The multimedia subsystem provides a set of simple and easy-to-use APIs for you to access the system and use media resources.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/uWevmNg9S4qAeAbceQlWhw/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062437Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=E185CDF1F4DB4D5881C15E4BCC0E808B7C36315B4331369E23C0F8389F257AEA)

The initial APIs of this module are supported since API version 6. Newly added APIs will be marked with a superscript to indicate their earliest API version.

This subsystem offers the following audio and video services:

-   Audio and video playback ([AVPlayer](../interface-avplayer/document.md)9+)
    
-   Audio and video recording ([AVRecorder](../interface-avrecorder/document.md)9+)
    
-   Video transcoding ([AVTranscoder](../interface-avtranscoder/document.md)12+)
    
-   Obtaining audio and video metadata ([AVMetadataExtractor](../interface-avmetadataextractor/document.md)11+)
    
-   Obtaining video thumbnails [AVImageGenerator](../interface-avimagegenerator/document.md)12+
    
-   Screen capture ([AVScreenCaptureRecorder](../interface-avscreencapturerecorder/document.md)12+)
