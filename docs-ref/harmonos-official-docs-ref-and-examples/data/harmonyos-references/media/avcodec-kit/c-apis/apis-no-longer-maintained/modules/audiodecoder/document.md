# AudioDecoder

#### Overview

The AudioDecoder module provides the functions for audio decoding.

**System capability**: SystemCapability.Multimedia.Media.AudioDecoder

**Since**: 9

**Deprecated from**: 11

**Development suggestions**: All APIs of the current module have been deprecated. You can use [AudioCodec](../../../modules/audiocodec/document.md) instead. For details about the API mappings before and after the deprecation, see the API reference.
