# AVDemuxer

#### Overview

The AVDemuxer module provides the APIs for extracting [samples](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/audio-video-demuxer) from media streams.

For details about the development guide and sample, see [Media Data Demultiplexing](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/audio-video-demuxer).

**System capability**: SystemCapability.Multimedia.Media.Spliter

**Since**: 10
