# AVMuxer

#### Overview

The AVMuxer module provides the functions for audio and video multiplexing.

For details about the development guide and sample, see [Media Data Multiplexing](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/audio-video-muxer).

**System capability**: SystemCapability.Multimedia.Media.Muxer

**Since**: 10
