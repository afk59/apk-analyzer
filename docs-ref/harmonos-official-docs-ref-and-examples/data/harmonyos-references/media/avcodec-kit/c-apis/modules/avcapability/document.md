# AVCapability

#### Overview

The AVCapability module provides the functions for querying the codec capability.

For details about the development guide and sample, see [Obtaining Supported Codecs](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/obtain-supported-codecs).

**System capability**: SystemCapability.Multimedia.Media.CodecBase

**Since**: 10
