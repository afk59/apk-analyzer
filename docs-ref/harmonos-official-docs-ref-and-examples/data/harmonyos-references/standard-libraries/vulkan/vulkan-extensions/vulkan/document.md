# Vulkan

#### Overview

The module provides Vulkan capabilities extended by HarmonyOS, enabling the creation of a Vulkan Surface with OHNativeWindow and access to OH\_NativeBuffer and its properties.

**System capability**: SystemCapability.Graphic.Vulkan

**Since**: 10
