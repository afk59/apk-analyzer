# MindSpore

#### Overview

Provides APIs related to MindSpore Lite model inference. The APIs in this module are non-thread-safe.

**System capability**: SystemCapability.Ai.MindSpore

**Since**: 9

#### Files

| Name | Description |
| :-- | :-- |
| [context.h](../../header-files/context-h/document.md) | Provides context-related APIs for configuring runtime information. These APIs are non-thread-safe. |
| [data\_type.h](../../header-files/data-type-h/document.md) | Declares tensor data types. |
| [format.h](../../header-files/format-h/document.md) | Declares tensor data formats. |
| [model.h](../../header-files/model-h/document.md) | Provides model-related APIs for model creation and inference. These APIs are non-thread-safe. |
| [status.h](../../header-files/status-h/document.md) | Provides the status codes of MindSpore Lite. |
| [tensor.h](../../header-files/tensor-h/document.md) | Provides tensor-related APIs, which can be used to create tensors and modify tensor information. These APIs are non-thread-safe. |
| [types.h](../../header-files/types-h/document.md) | Provides the model file types and device types supported by MindSpore Lite. |
