# ArkTS API Error Codes

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/_tzWipSXQsqTZ9IhOjK8lA/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062521Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=7B1611F4B93D9CBF031720F82B701ABBC761191191A3F547A704E50BAF2B2BF8)

This topic describes only module-specific error codes. For details about universal error codes, please refer to [Universal Error Codes](../../../../api-reference-overview/universal-error-codes/document.md).

#### 1022400010 Parameter Error

**Message**

Parameter error.

**Description**

The input parameter is incorrect.

**Possible causes**

The value of the input parameter is beyond the supported range or specifications.

**Solution**

Ensure that the input parameter is correct and try again.

#### 1022400011 Privacy Agreement Not Accepted

**Message**

Privacy agreement not accepted.

**Description**

The privacy statement is not accepted.

**Possible causes**

The Celia privacy statement is not accepted.

**Solution**

Ensure that the Celia privacy agreement is accepted when Celia is launched after the agent button is tapped.

#### 1022400012 HUAWEI ID Not Signed In

**Message**

HUAWEI ID not signed in.

**Description**

No HUAWEI ID is signed in.

**Possible causes**

No HUAWEI ID is signed in.

**Solution**

Ensure that a HUAWEI ID is used to sign in to the device.

#### 1022400013 Network Error

**Message**

Internet error.

**Description**

Network error.

**Possible causes**

The device is not connected to the network or under poor network conditions.

**Solution**

Ensure that the network connection works properly and try again.

#### 1022400014 Internal Error

**Message**

Internal error.

**Description**

Internal error.

**Possible causes**

Internal connection failed. The current Celia version does not support this function.

**Solution**

Ensure that the latest Celia app is downloaded from Huawei AppGallery and used.
