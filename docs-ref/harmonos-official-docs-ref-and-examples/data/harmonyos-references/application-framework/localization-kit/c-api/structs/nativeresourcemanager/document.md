# NativeResourceManager

#### Overview

Represents the native **ResourceManager**. This class encapsulates the native implementation of the JavaScript **ResourceManager**. The pointer to **ResourceManager** can be obtained by using [OH\_ResourceManager\_InitNativeResourceManager](../../header-files/raw-file-manager-h/document.md#oh_resourcemanager_initnativeresourcemanager).

**Since**: 8

**Related module**: [rawfile](../../modules/rawfile/document.md)
