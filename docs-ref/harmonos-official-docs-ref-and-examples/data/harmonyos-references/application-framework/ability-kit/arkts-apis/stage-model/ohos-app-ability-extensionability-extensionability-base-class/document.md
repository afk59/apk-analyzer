# @ohos.app.ability.ExtensionAbility (ExtensionAbility Base Class)

ExtensionAbility is the base class for scenario-specific ExtensionAbilities. It inherits from [Ability](../ohos-app-ability-ability-ability-base-class/document.md), with no property or method added. You cannot directly inherit from ExtensionAbility. For details about the inheritance relationship of each ability, see [Inheritance Relationship](../ohos-app-ability-ability-ability-base-class/document.md#ability-inheritance-relationship).

The initial APIs of this module are supported since API version 9. Newly added APIs will be marked with a superscript to indicate their earliest API version.

The APIs of this module can be used only in the stage model.

#### Modules to Import

import { ExtensionAbility } from '@kit.AbilityKit';

**Atomic service API**: This API can be used in atomic services since API version 11.

**System capability**: SystemCapability.Ability.AbilityRuntime.AbilityCore
