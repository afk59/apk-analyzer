# CustomizeData

The CustomizeData module provides custom metadata.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/8Unfe3yiQ1KZ7uwgn5LtCA/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062212Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=44D66D617D579E585E5F2AEE03BCF8C64BDE6135E00C1C3CBFAA927C96393540)

The initial APIs of this module are supported since API version 7. Newly added APIs will be marked with a superscript to indicate their earliest API version.

The APIs of this module have been deprecated since API version 9. You are advised to use [Metadata](../../../dependent-elements-and-definitions/bundlemanager/metadata/document.md) instead.

#### CustomizeData(deprecated)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/PzkbWK7FSLaaNODFZPNOJQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062212Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=AF1269B01F76E335645AF508C8F4DB5597A4789182049DFAC5AC45F73707A732)

This API has been supported since API version 7 and deprecated since API version 9. You are advised to use [Metadata](../../../dependent-elements-and-definitions/bundlemanager/metadata/document.md#metadata-1) instead.

**System capability**: SystemCapability.BundleManager.BundleFramework

| Name | Type | Read-Only | Optional | Description |
| :-- | :-- | :-- | :-- | :-- |
| name | string | No | No | Key that identifies a data element. |
| value | string | No | No | Value of the data element. |
| extra8+ | string | No | No | Custom format of the data element. The value is an index to the resource that identifies the data. |
