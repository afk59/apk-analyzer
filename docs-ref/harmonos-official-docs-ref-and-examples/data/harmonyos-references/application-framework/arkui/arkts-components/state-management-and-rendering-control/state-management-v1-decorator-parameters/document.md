The initial APIs of this module are supported since API version 11. Newly added APIs will be marked with a superscript to indicate their earliest API version.

#### ProvideOptions

[@Provide](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-provide-and-consume) configuration options for controlling whether @Provide can be overridden. For details, see [Support for the allowOverride Parameter](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-provide-and-consume#support-for-the-allowoverride-parameter).

**Widget capability**: This API can be used in ArkTS widgets since API version 11.

**Atomic service API**: This API can be used in atomic services since API version 11.

**System capability**: SystemCapability.ArkUI.ArkUI.Full

| Name | Type | Read-Only | Optional | Description |
| :-- | :-- | :-- | :-- | :-- |
| allowOverride | string | No | Yes | Whether @Provide can be overridden. By default, overriding is not supported. |
