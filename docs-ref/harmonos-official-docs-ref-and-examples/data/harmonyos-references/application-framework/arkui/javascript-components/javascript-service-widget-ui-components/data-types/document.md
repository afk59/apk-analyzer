The APIs of this module are supported since API version 8. Updates will be marked with a superscript to indicate their earliest API version.

#### Length Type

| Name | Type | Description |
| :-- | :-- | :-- |
| length | string | number | 
Size unit. When the type is **number**, the unit is px. When the type is **string**, the pixel unit must be explicitly specified. Currently, the following pixel units are supported:

\- **px**: logical size unit.

\- **fp**: font pixel unit, which varies according to the system font size. This unit is only available for text components.

 |
| percentage | string | Unit in percentage, for example, **'50%'**. |

#### Color Type

| Name | Type | Description |
| :-- | :-- | :-- |
| color | string |Color enumeration | 
Color information.

The string format is as follows:

\- 'rgb(255, 255, 255)'

\- 'rgba(255, 255, 255, 1.0)'

\- HEX format: '#rrggbb', '#aarrggbb'

\- Enumeration format: 'black','white'

The enumeration format is not supported in the JS script.
