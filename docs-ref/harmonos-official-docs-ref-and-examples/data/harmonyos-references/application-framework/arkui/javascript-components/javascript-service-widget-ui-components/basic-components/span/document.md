# span

The **<span>** component is a child component of [<text>](../text/document.md) and is used as a text modifier.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/QnUPmRDpQwua47PeXxwe6g/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062301Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=714A005A700701842EDA9F99038EBC993FBCC5A9F1C015B2078A2372709BBF01)

The APIs of this module are supported since API version 8. Updates will be marked with a superscript to indicate their earliest API version.

#### Child Components

The child component **[<span>](#)** is supported.

#### attributes

The [universal attributes](../../universal-components/universal-attributes/document.md) are supported.

#### Styles

| Name | Type | Default Value | Mandatory | Description |
| :-- | :-- | :-- | :-- | :-- |
| color | <color> | \- | No | Font color of the modified text. |
| font-size | <length> | 16px | No | Font size of the modified text. |
| font-style | string | normal | No | Font style of the modified text. For details, see **font-style** of the [**<text>**](../text/document.md#styles) component. |
| font-weight | number | string | normal | No | Font weight of the modified text. For details, see **font-weight** of the [**<text>**](../text/document.md#styles) component. |
| text-decoration | string | none | No | Text decoration of the modified text. For details, see **text-decoration** of the [**<text>**](../text/document.md#styles) component. |
| font-family | string | sans-serif | No | Font family, in which fonts are separated by commas (,). Each font is set using a font name or font family name. The first font in the family or the specified [custom font](../../universal-components/custom-font-styles/document.md) is used for the text. |
