# clock

The **<clock>** component provides a clock face.

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/GR2StzSES2qcviBorhLBcg/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062301Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=951D5CA9AF6FC5863DDD0F89B7D6982D734E552006EB49CEC3AF24F4F85A46E3)

The APIs of this module are supported since API version 8. Updates will be marked with a superscript to indicate their earliest API version.

#### Child Components

Not supported

#### Attributes

In addition to the [universal attributes](../../universal-components/universal-attributes/document.md), the following attributes are supported.

| Name | Type | Default Value | Mandatory | Description |
| :-- | :-- | :-- | :-- | :-- |
| clockconfig | ClockConfig | \- | Yes | 
Image resources and styles used by this **<clock>** component, including one set for the daytime (6:00 to 18:00) and one set for the nighttime (18:00 to 6:00 of the next day).

Each set of resources contains four images for the clock face, hour hand, minute hand, and second hand, respectively. Each set of styles is used for specifying number colors for the daytime and nighttime.

This attribute is mandatory for the daytime. If you do not set this attribute for the nighttime, the daytime images are reused at the nighttime.

Object members cannot be dynamically updated. However, You can dynamically update the object.

You are advised to use PNG images.

SVG images are not supported.

 |
| showdigit | boolean | true | No | 

Whether to draw clock face numbers based on **clockconfig**.

If you set this attribute to **true**, ensure that **digitRadiusRatio** and **digitSizeRatio** parameters of **clockconfig** match the clock face.

The numbers generated by the **<clock>** component support multiple number formats in different locales.

 |
| hourswest | number | \- | No | 

Time offset of the clock to the Coordinated Universal Time (UTC). The local time zone is UTC minus **hourswest**.

The value range is \[-12, 12\]. For example, the value **\-8** means UTC+8. If this parameter is not set, the current system time zone is used.

 |

**Table 1** ClockConfig

| Name | Type | Default Value | Mandatory | Description |
| :-- | :-- | :-- | :-- | :-- |
| face | <string> | \- | Yes | 
Path of clock face images used in the daytime.

The clock face resources must be square images that contain the clock scale, and the clock face area must be an inscribed circle of the image or a concentric circle of the inscribed circle. If the clock face area is a concentric circle of the inscribed circle, you need to change the **digitRadiusRatio** and **digitSizeRatio** values accordingly.

 |
| hourHand | <string> | \- | Yes | 

Path of hour hand images used in the daytime.

\- The height of the hour hand images must be the same as that of the clock face images.

\- You are advised to set the aspect ratio of the hour hand images to **0.062**.

\- The rotation center of the hour hand must be the same as the center (diagonal intersection point) of the hour hand images.

\- To specify the hour hand resources for the nighttime, set **hourHandNight**.

 |
| minuteHand | <string> | \- | Yes | 

Path of minute hand images used in the daytime.

\- The height of the minute hand images must be the same as that of the clock face images.

\- You are advised to set the aspect ratio of the minute hand images to **0.062**.

\- The rotation center of the minute hand must be the same as the center (diagonal intersection point) of the minute hand images.

\- To specify the minute hand resources for the nighttime, set **minuteHandNight**.

 |
| secondHand | <string> | \- | Yes | 

Path of second hand images used in the daytime.

\- The height of the second hand images must be the same as that of the clock face images.

\- You are advised to set the aspect ratio of the second hand images to **0.062**.

\- The rotation center of the second hand must be the same as the center (diagonal intersection point) of the second hand images.

\- To specify the second hand resources for the nighttime, set **secondHandNightSrc**.

 |
| digitColor | <color> | #FF000000 | No | Text color on the clock face during the daytime (6:00 to 18:00). |
| digitColorNight | <color> | Same as that of **digitColor** | No | 

Text color on the clock face during the nighttime (18:00 to 06:00 of the following day).

\- If this attribute is not set, the value of **digitColor** is used as the value of **digitColorNight**.

In this case, you should ensure the text color of the nighttime clock face matches the color of the nighttime clock face images (stored in **faceNight**).

 |
| faceNight | <string> | \- | No | 

Path of clock face images used in the nighttime.

If this parameter is not set, the path of clock face images for the daytime is used as the value of this parameter.

 |
| hourHandNight | <string> | \- | No | 

Path of hour hand images used in the nighttime.

If this parameter is not set, the path of hour hand images for the daytime is used as the value of this parameter.

 |
| minuteHandNight | <string> | \- | No | 

Path of minute hand images used in the nighttime.

If this parameter is not set, the path of minute hand images for the daytime is used as the value of this parameter.

 |
| secondHandNight | <string> | \- | No | 

Path of second hand images used in the nighttime.

If this parameter is not set, the path of second hand images for the daytime is used as the value of this parameter.

 |
| digitRadiusRatio | number | 0.7 | No | 

Distance between the center of the clock face numbers and the center of the clock face circle/Half of the side length of the clock face image.

\- The value range is (0, 1\].

\- This parameter is used to calculate the distance between the numbers on the clock face and the center of the clock face circle.

\- This parameter ensures that the same set of clock face images have the same relative position in components of different sizes. You do not need to change the position for components of different sizes.

\- If this parameter is set to **1**, the numbers may exceed the clock face area. In this case, you should change the **digitRadiusRatio** value based on the clock face size.

 |
| digitSizeRatio | number | 0.08 | No | 

Font size of the watch face numbers/Side length of the watch face

\- The value range is (0, 0.142\].

\- This parameter is used to calculate the font size of clock face numbers relative to the size of the clock face.

\- This parameter ensures that the same set of clock face images have the same relative size in components of different sizes. You do not need to change the font size for components of different sizes.

 |

#### Styles

In addition to the [universal styles](../../universal-components/universal-styles/document.md), the following styles are supported.

| Name | Type | Default Value | Mandatory | Description |
| :-- | :-- | :-- | :-- | :-- |
| font-family | <string> | sans-serif | No | Font family used for clock face numbers, in which fonts are separated by commas (,). Each font is set using a font name or font family name. The first font in the family or the font specified by a custom font style is used for the text. |

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/nbSOg2mgSVelIT57JkDBOQ/note_3.0-en-us.png?HW-CC-KV=V1&amp;HW-CC-Date=20260410T062301Z&amp;HW-CC-Expire=86400&amp;HW-CC-Sign=9EF0F8F21F8BDD7E8DEAD8A92712220AE3C2DF07DC8FCA57F7FB9F353A5727A2)

The **<clock>** component keeps the aspect ratio of the display area to **1**. The side length of the final square display area is **min(width, height)**. The square display area is centered in the component (**width** x **height**).
