# OH\_NativeXComponent Native XComponent

#### Overview

Describes the surface and touch event held by the ArkUI XComponent, which can be used for the EGL/OpenGL ES and media data input and displayed on the ArkUI XComponent. For details, see [Custom Rendering (XComponent)](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/napi-xcomponent-guidelines).
