# ArkUI\_TouchTestInfoItem

typedef struct ArkUI\_TouchTestInfoItem ArkUI\_TouchTestInfoItem

#### Overview

Defines touch test information items. The touch test information items contain information about subcomponents involved in a touch test. You can obtain the subcomponent information via the [OH\_ArkUI\_TouchTestInfoItem\_GetXXX](../../header-files/ui-input-event-h/document.md#oh_arkui_touchtestinfoitem_getx) APIs.
