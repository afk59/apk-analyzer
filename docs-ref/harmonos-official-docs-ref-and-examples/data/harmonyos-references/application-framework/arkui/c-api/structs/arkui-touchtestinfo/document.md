# ArkUI\_TouchTestInfo

typedef struct ArkUI\_TouchTestInfo ArkUI\_TouchTestInfo

#### Overview

Defines touch test information.

This event is dispatched only if the user registers the [NODE\_ON\_CHILD\_TOUCH\_TEST](../../header-files/native-node-h/document.md#arkui_nodeeventtype) event using [registerNodeEvent](../arkui-nativenodeapi-1/document.md#registernodeevent). The touch test information includes the touch test policy, IDs of subcomponents involved in a hit test, and list of touch test information items.
