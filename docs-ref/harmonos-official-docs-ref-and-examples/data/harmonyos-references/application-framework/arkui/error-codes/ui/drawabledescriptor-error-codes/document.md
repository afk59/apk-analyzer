This topic describes only module-specific error codes. For details about universal error codes, see [Universal Error Codes](../../../../../api-reference-overview/universal-error-codes/document.md).

#### 111001 Internal Error

**Error Message**

resource loading failed.

**Description**

This error code is reported when resource loading fails.

**Possible Causes**

The path does not exist, the resource does not exist, or the file is corrupted.

**Solution**

Check whether the resource exists or whether the file is corrupted.
