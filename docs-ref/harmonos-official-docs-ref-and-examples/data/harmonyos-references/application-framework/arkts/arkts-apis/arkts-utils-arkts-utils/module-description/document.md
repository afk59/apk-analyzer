# Module Description

This module provides the following ArkTS utilities:

-   [ArkTSUtils.locks](../arktsutils-locks/document.md): asynchronous lock.
-   [ArkTSUtils.ASON](../arktsutils-ason/document.md): ASON.
-   [SendableLruCache](../sendablelrucache-k-v/document.md): SendableLruCache buffer.

The initial APIs of this module are supported since API version 12. Newly added APIs will be marked with a superscript to indicate their earliest API version.

This module can be imported only to ArkTS files (with the file name extension .ets).

#### Modules to Import

import { ArkTSUtils } from '@kit.ArkTS'
